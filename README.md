# 中小企業向けビジネスアシスタント（Small Business 日本版）

Anthropic の [knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)
に含まれる small-business プラグインをもとに、日本の中小企業向けに全面的に
書き換えたものです。

日本の中小企業・個人事業主の経営を Claude が手伝うためのプラグインです。
資金繰り、経理、営業、マーケティング、顧客対応、採用の 44 のスキルと、
ふだんの言葉で頼めるルーター（案内係）が入っています。

覚えることは何もありません。「給料日までにお金が足りるか不安」「お客様が怒っ
ている」「誰がまだ払ってない？」と、そのまま Claude に話しかけてください。
最適なスキルを選んで、順を追って進めます。どのスキルも、実行する前に必ず
止まります。あなたの「はい」なしに、送信・投稿・支払い・帳簿への書き込みは
一切行われません。

> **重要**: このプラグインは中小企業の業務を支援するものであり、税務・会計・
> 法務・労務の専門的助言を提供するものではありません。出力はすべて、ご自身で
> （必要に応じて顧問税理士・社会保険労務士・弁護士などの専門家とともに）確認
> のうえご利用ください。

## はじめかた

1. プラグインをインストールします。Claude Code では:

   ```bash
   claude plugin marketplace add barorin/small-business-jp
   claude plugin install small-business-jp@small-business-jp
   ```
2. **「初期設定をして」** と話しかけてください。15 分の初期設定で、最初の
   2 つのツール（例: 会計ソフトとメール）を接続し、実データで一度動かして
   価値を確かめ、事業の概要を覚え、Web サイトからブランドカラーを取り込んで
   以後のレポートに反映します。
3. あとは、必要なことをそのまま伝えるだけです。

ツールをまだ接続していなくても、すべてのスキルが動きます。CSV のエクスポート、
貼り付けたメール、アップロードした PDF、あるいは会話だけでも構いません。
コネクタは深さを足すものであって、必須ではありません。

インストール前にすでに接続していたツールが、ご自身のコネクタ一覧と、この
プラグインの「コネクタ」タブの両方に表示されることがあります。同じツール
です。どちらの項目からでも動作し、認可されているほうを使います。両方を接続
する必要はありません。

## こんなふうに頼めます

**お金・資金繰り**

- 「支払いをまとめて」 · 「誰がまだ払ってない？」 · 「納税資金」 / 「支払調書」
- 「レポートを作って」 · 「毎週のレポートを定例で」

**営業・成長**
- 「見込み客を探して」 · 「誰に電話すべき？」 · 「架電リスト」
- 「この営業メールを書いて」 · 「パイプラインを埋めたい」 · 「休眠顧客を掘り起こして」
- 「この案件の見積書」 / 「提案書」 / 「入札」 · 「CRM を整理して」

**マーケティング**
- 「マーケは効いてる？」 · 「週次の成長ブリーフ」
- 「投稿を作って」 · 「このブリーフを実行して」 · 「広告」 · 「SEO」
- 「何を推すべき？」

**顧客・評判**
- 「お客様は何と言ってる？」 · 「お客様が怒っている」
- 「注文を見て — 問題になりそうなものは？」

**業務・人**
- 「メールを整理して」 · 「ブリーフをして」 · 「月曜ブリーフ」
- 「発注」 / 「在庫」 · 「求人票を書いて」 · 「応募者を選考して」
- 「この契約書を見て」 · 「補助金」 / 「入札案件」

**自分仕様にする**
- 「ブランドを更新して」 — リンク一つで、すべてのページに自社の色とロゴ
- 「これを自動化して」 — 繰り返す作業を名前付きスキルに
- 「基幹システムとつなげて」 — 公式コネクタのないツールを接続

## 対応している日本の実務

- **消費税・インボイス制度** — 受領した請求書の登録番号を確認し、免税事業者
  からの仕入れは経過措置（80% → 2026 年 10 月から 50%）の区分で仕訳します。
- **法定調書・支払調書** — 外注費や報酬の支払先を会計データから集計し、
  5 万円超の支払先と源泉徴収額を整理して、1 月 31 日の提出に備えます。
- **決算・納税資金** — 法人の法人税等・消費税、個人事業主の所得税・予定納税
  の目安を出し、顧問税理士に渡す資料にまとめます。
- **給与・労務** — 勤怠データを 36 協定・割増賃金・有給の観点で検証し、
  給与計算ソフトに投入する前のチェックシートと給与仕訳を作ります。
- **売掛金の督促** — 「ご確認のお願い」から「最終のご連絡」まで、日本の
  ビジネスメールの作法で段階的に。振込手数料や支払サイトのずれも考慮します。
- **求人・採用** — 職業安定法の必須記載事項を満たす求人票、公正な採用選考、
  内定通知書と労働条件通知書。
- **契約書** — 取適法（旧・下請法）とフリーランス新法の 60 日ルール、
  収入印紙、契約不適合責任、準拠法・管轄などを論点として整理します。
- **補助金・公募** — jGrants、ミラサポplus、官公需情報ポータルを起点に、
  GビズID の取得日数や事後精算の立替まで含めて Go/No-Go を判断します。

## 安全のしくみ

- **すべてに承認ゲート。** 明示的な「はい」なしに、送信・投稿・支払い・
  帳簿やシステムへの書き込みは行われません。請求書のコーディングと支払いは
  別々の承認です。給与は準備までで、振込はあなたがネットバンキングで行います。
- **数字を作らない。** 読めない数字は「読めない」と報告し、推測しません。
- **個人情報を出さない。** マイナンバー、生年月日、自宅住所、口座番号は
  出力に一切含めません。
- **データはあなたのもの。** スキルは実行に必要なものだけを読み、あなたが
  承認したものだけを書きます。

## リポジトリの構成

このリポジトリは、プラグイン 1 つだけを載せたマーケットプレイスです。
すべて Markdown と JSON で、ビルドは不要です。

```
small-business-jp/
├── .claude-plugin/
│   ├── marketplace.json   # マーケットプレイス定義（source: "./"）
│   └── plugin.json        # プラグインのマニフェスト
├── .mcp.json              # コネクタ（MCP サーバー）の定義
├── shared/                # 複数のスキルが参照する共通ルール
└── skills/                # 44 のスキル（各 SKILL.md と reference/）
```

コネクタを差し替えるときは `.mcp.json` を、業務の進め方を変えるときは
該当スキルの `SKILL.md` と `reference/` を編集してください。
