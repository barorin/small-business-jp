# 出力テンプレート

すべてのパルスが従う正確な構造。セクションの順序を入れ替えない。セクションを省くのは、そのコネクタがデータを返さなかったときだけ — 空の見出しを残さない。

`{{二重波括弧}}` の変数はプレースホルダー — 計算した値で置き換える。矢印の約束: ▲ 増、▼ 減、▬ 横ばい（変化 1% 未満）。矢印のあとに必ず差分の値を示す。

金額は円（`../../../shared/currency-and-locale.md`）。文中は `620万円` のような万円表記でよく、表と金額列は全桁 `6,240,000円`。売上は税込／税抜を明記する。決済サービスが外貨で精算する場合（Stripe の USD 入金など）は換算せず `USD 1,200` と ISO コード前置で書く。`¥` や `JPY 1,200` は本文に使わない。

## 書式のルール

1. **金額**: 円。文中は `624万円`、`1.3億円` のような万円・億円表記でよい。表と金額列は全桁 `6,240,000円`。同じ表の中で混ぜない。小数は使わない。記号（`¥`、`$`）は使わない。外貨は `USD 1,200` と ISO コード前置。
2. **パーセント**: 推移は小数一桁（例: 「▲ 8.3%」）、それ以外は整数。
3. **日付**: 本文は `9月17日（水）` のように読みやすく、年が要るときは `2026年9月17日`（`../../../shared/currency-and-locale.md`）。メタデータは ISO（`2026-09-17`）。時刻は JST。
4. **矢印の間隔**: `▲ 20万円` であって `▲20万円` ではない。
5. **長さ**: 一枚を目指す。最大二枚。セクションが膨らんだら文を引き締める。
