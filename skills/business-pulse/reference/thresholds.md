# しきい値

パルスの各セクションの 🔴／🟡／🟢 の判定ライン。中小企業向けの既定値だ — 経営者の実際の目標と計画に合わせて編集する。

`# TODO: 経営者に確認` の印が付いたしきい値は、最初のパルス出力の冒頭に注記を出し、経営者が調整すべきだと分かるようにする。

金額のしきい値は円（`../../../shared/currency-and-locale.md`）。「3万円」は 3万円そのものだ。これらは注目のラインであって法定基準ではなく、事業の規模に合わせて経営者が動かしてよい。日数は暦日で数える。銀行休業日（土日祝、12月31日〜1月3日）は督促や振込のタイミングの判断に使い、超過日数を止める理由にはしない。

## お金

**手元資金の余裕**（現預金 ÷ 月間の固定費）
- 🟢 4か月分以上  # TODO: 経営者に確認
- 🟡 2〜4か月分
- 🔴 2か月分未満

**売上の推移（前月比）**
- 🟢 0% 以上（横ばいか成長）
- 🟡 -5% 〜 0%
- 🔴 -5% 未満

**売掛金の滞留**
- 🟢 31日以上の請求書がない
- 🟡 期日から 31〜60日の請求書がある
- 🔴 期日から 60日超の請求書がある、または 61日以上の区分が売掛金全体の 10% 超

**期日超過の名指し**: 期日を 30日超えた請求書は、件数に含めるだけでなく、パルスの中で必ず名指しする。

**未仕訳の明細**（銀行・カード明細のうち仕訳されていないもの）
- 🟢 10件以下
- 🟡 11〜30件
- 🔴 30件超 — 現預金と売上を「暫定値」と明記する

**今週の支払予定**（給与＋仕入先振込＋借入返済＋税金）÷ 手元資金
- 🟢 30% 未満
- 🟡 30〜50%
- 🔴 50% 超 — 給与日と大口の振込が同じ週に重なる月に起きやすい

## 顧客 — 売上・注文・問い合わせ

**直近 7日間の売上推移（vs その前の 7日）**
- 🟢 0% 以上
- 🟡 -10% 〜 0%
- 🔴 -10% 未満

**決済の失敗**
- 🟡 3万円超の失敗が一件でもある
- 🔴 15万円超の失敗が一件でもある、または週に 3件以上の失敗

**問い合わせの未返信**（メール、Zoho Desk）: 24時間超 未返信 → 🟡。48時間超 未返信、または優先度 High が未対応 → 🔴

**口コミ**: Googleビジネスプロフィールの新しい口コミが ★3以下 → 必ず名指しで要対応に載せる。返信の下書きは `review-reputation` の領分。

## 要対応

数値のしきい値はない — メールや Slack のエスカレーションやクレームはすべて出す。深刻さは文脈次第。出して、判断は経営者に委ねる。

---

## 全体ステータスの集約

パルス全体のステータスは、最も悪いセクションのステータスにする。上書き: 個別のリスクが特定の顧客を金額と 7日以内の期限つきで名指ししているなら、セクションの色に関わらず 🔴 に集約する。

---

## いつ調整するか

使い始めて 4週間後に見直す。既定値は保守的な出発点だ — 健全な事業ではいつも 🟢 に見えるだろう。経営者が実際に動きたい地点を映すように引き締める。決算月の前後（3月決算なら 3〜5月）は納税と決算のための支出で「今週の支払予定」が 🔴 になりやすいので、その時期だけ別のラインを置いてもよい。
