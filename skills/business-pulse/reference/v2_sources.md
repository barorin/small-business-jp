# 追加ソース

同じパルスに入る、もう二本の脚。パルスは変わらず、接続されているものから組み、自然に縮退する。

---

## Shopify

EC の事業者にとって、これは「自分の一日を描いているパルス」と「そうでないパルス」の違いだ。

| 取得するもの | 入るセクション |
|---|---|
| 今日と直近 7日間の注文と売上 | 顧客 — 売上・注文 |
| 出荷状況 | 要対応 — 約束した期日を過ぎた未出荷は、パルスの中で最も手を打ちやすい項目 |
| 返金と返品 | 要対応 |
| 動いている商品の在庫僅少アラート | 要対応 |

約束した期日を過ぎた未出荷の注文は、上のほうに置く。時間に敏感で、クレームに変わり、他のどのセクションもそれを出さない。ひかり珈琲焙煎所のように EC が売上の 2〜3% でも、出荷遅れの注文は一件ずつ名指しする — 金額ではなく、待っている人がいるからだ。

## 会計ソフト — freee会計、マネーフォワード クラウド会計、弥生会計

接続されているものが手元資金・売上・売掛金の「正」で、パルスは経営者の経理担当や顧問税理士が見ている数字を報告する。会計ソフトは同格だ（`../../../shared/connector-neutrality.md`）: どれも他より優先されない。海外製の会計ソフト（Xero、Zoho Books、NetSuite など）を使う事業者も同格。同じ指標、同じセクション。ツール名だけが変わる（`data_sources.md`）。

**会計ソフトが二つ接続されている: 両方読み、合計は一つから。** どちらが「正」かを聞き、付録にそう書き、現預金・売上・売掛金の合計はそちらから取る。もう一方は、それだけが固有に持つものだけを供給する。

## 二重計上のルール

パルスは売上を四つの場所で見る可能性がある: 会計ソフト、決済サービス、ネットショップ、POS。

**売上のソースを一つ選び、どれかを言う。** 足し合わせると数字が膨らむ — ときに倍以上に — そしてそれに気づいた経営者は、パルス全体を信用しなくなる。

順序: まず会計ソフト（接続されているもの。二つなら経営者が名指しした「正」）、次に決済サービス、次にネットショップ。選んだソースより下のものはすべて内訳を供給する — チャネル別、商品別、精算のタイミング — 合計ではなく。

```
売上 — 1,340万円（月初来、税抜）（出所: マネーフォワード クラウド会計。商品構成は Shopify）
```

### 一つのソースの中でも二重計上は起きる

ソースを一つに絞るだけでは足りない。会計ソフトの得意先別・取引先別のレポートは、親と子を持つ取引先について二つの行を返すことがある: 親のサマリー行と、同じ数字を持つ別の合計行だ（`../../../shared/ledger-report-traps.md` 罠3）。マネーフォワードの補助科目付き試算表（`with_sub_accounts: true`）も同じ形をしている: 勘定科目の行（合計）と補助科目の行（取引先別の内訳）の両方が返る。

だから、それらの行から直接組んだ順位付けでは取引先が二度現れる — 一度は自分の名前で、一度は科目の合計として — そして、そこから計算した集中度はすべて過大になる。

順位付けや合計の前に、合計を示す行を落とす。取引先別に読むなら補助科目の行だけ、科目の残高を読むなら科目の行だけを使う。補助科目や現場・案件別の管理をしている帳簿では確実に起きる誤りで、設備工事のような業種ではそれがほとんどだ。

## 定期のプリセット

| プリセット | いつ | 形 |
|---|---|---|
| 月曜 | 週の始まり | 完全なパルス。前を向く。何が来るか、何に手を打つべきか |
| 金曜 | 週の終わり | 振り返り。何が動き、何が決まり、何がずれたか |

同じスキル、違う枠組み。

**この二つは本当に別の文書だ。** 月曜は今週の予定と、手を打つべき最重要の一件から始めるべきだ。金曜は、予想に対して実際に何が起きたかから始めるべきだ。月曜ブリーフのように読める金曜の振り返りは、曜日を間違えて送られた月曜ブリーフだ。

月曜が祝日なら火曜の朝に回し、「今週」は火曜始まりで読む。年末年始・ゴールデンウィーク・お盆の明けは、休み中に溜まった要対応（未返信、出荷遅れ、着金ずれ）から始める。

頻度の提案は、経営者が役に立ったと感じたパルスのあとに一度だけ。二度聞かない。**このプラグインにスケジューラはない**（`../../../shared/chain-seams.md`）: 実行環境に本物の定期実行があればそれを作り、なければ Google カレンダーの繰り返し予定を提案する。「設定しました」は、本当に何かが設定されたときにだけ言う。
