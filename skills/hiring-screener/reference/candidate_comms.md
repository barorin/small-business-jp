# 応募者への連絡

応募した人全員に返事が届く。経営者の声で下書きし、承認を得てからだけ送る。

下書きの前に[共有のボイスプロファイル](../../../shared/voice-profile.md)を読む。社用車 4 台の設備会社から大企業の人事部のような採用メールが届くと作り物に見え、応募者は気づく。定型の「お祈りメール」に頼りすぎず、経営者の言葉で書く。

---

## なぜ全応募者に返信するのか

中小企業にとってこれは礼儀ではなく評判管理だ。返事をもらえなかった応募者は人に話す。狭い業界や地域では、それが経営者が来年雇いたいまさにその人に届く。

しかも安い。3 種類の下書きで応募者全員をカバーできる。

---

## 書類選考通過・面接日程のご案内

短く。目的は日程を決めることで、まだ仕事を売り込むことではない。

含めるもの：選考を進めたいこと、面接の内容（誰と、何分、対面か電話・オンラインか）、具体的な候補日時を 2〜3 つ（JST で。Google カレンダーの `suggest_time` の結果は `list_events` で当日の実際の予定と突き合わせてから候補にする）、持参するもの — 免許・資格証、職務経歴書の原本など。

```
件名：【岡本設備工業】書類選考の結果と面接日程のご案内

佐藤 健太 様

お世話になっております。岡本設備工業の岡本です。
設備施工スタッフへのご応募ありがとうございます。ぜひ一度お話ししたいと思います。

面接は私が担当し、さいたま市の事務所で 45 分ほどです。
以下のいずれかでご都合はいかがでしょうか（日本時間）。
  7月29日（火）8:00 JST
  7月29日（火）14:00 JST
  7月31日（木）8:00 JST

第二種電気工事士の免状をお持ちでしたら、当日ご持参ください。

よろしくお願いいたします。
岡本設備工業 岡本
```

## 選考継続のご連絡（保留）

有力だが最初の順番ではない応募者向け。まだ選考中であることを正直に、日付とともに。

含めるもの：検討中であること、おおよその状況、結果を伝える具体的な日付。日付がこのメッセージの価値のすべてだ。

```
件名：【岡本設備工業】選考状況のご連絡

鈴木 彩 様

お世話になっております。岡本設備工業の岡本です。
お待たせしたままにならないよう、状況をお知らせします。
設備施工スタッフの選考は引き続き進めており、今週中に数名の方とお会いする予定です。
8月8日（金）までには結果が出ます。

結果はどちらの場合も、その日までに必ずご連絡します。

よろしくお願いいたします。
岡本設備工業 岡本
```

**そしてその日付に実際にフォローアップする。** 約束を破った保留メッセージは、何も送らないより悪い。送信の一部として、その日付をカレンダーに入れる。

---

## 選考結果のご連絡（不採用）

丁寧に、早く、正直に。この順で。

含めるもの：明確なお断り、時間を割いてくれたことへの感謝、それだけ。理由は不要で、創作した理由があってはならない。「今後のご活躍をお祈り申し上げます」だけの定型に頼らず、経営者の言葉で一言添える。

```
件名：【岡本設備工業】選考結果のご連絡

伊藤 翔 様

お世話になっております。岡本設備工業の岡本です。
設備施工スタッフへのご応募と、書類をご準備いただいた時間に感謝します。

慎重に検討しましたが、今回は他の方で進めることにしました。
ご応募いただいたこと自体、ありがたく思っています。

なお、ご提出いただいた書類は選考終了後に責任をもって破棄します。

よろしくお願いいたします。
岡本設備工業 岡本
```

**早いほうが優しいより勝る。** 2 週間の沈黙は、3 日目の明確なお断りよりはるかに多くの信頼を経営者から奪う。判断が確定した時点で、すぐに不採用の連絡を送る。

---

## 不採用の理由

**創作しない。** 実際はそうでないのに「より経験のある方で進めることにしました」と書くのは、応募者が確かめられることもある嘘で、しかも広まる類の嘘だ。

**本当で具体的な理由は、それが本当に役に立ち事実であるときは贈り物になる：**

```
一点だけお伝えしますと、今回は第二種電気工事士の資格の有無が決め手でした。
取得されましたらぜひご一報ください。年に数回は募集しています。
```

正直で、行動につながり、良い人を手放さずに済む。

**理由が事実ではなく判断であるときは、一般的な言い方にとどめる。** 丁寧で曖昧なほうが、具体的で争いの余地があるより良い。使ってはいけない情報の一覧に触れる理由は、褒め言葉としてであっても決して書かない。

---

## 内定のご連絡

正式な内定通知書・労働条件通知書は `job-post-builder` のひな形から作り、`onboarding.md` の手順で回す。ここで下書きするのはそれに添えるメールだ。

含めるもの：内定の旨、入社希望日、返答の期限、同封（添付）する書類、入社手続きで用意してもらうものの予告。賃金などの条件は本文に書かず、労働条件通知書で示す。

```
件名：【岡本設備工業】採用内定のご連絡

佐藤 健太 様

お世話になっております。岡本設備工業の岡本です。
先日は面接にお越しいただきありがとうございました。
選考の結果、設備施工スタッフとして採用内定をお出ししたく、ご連絡します。

内定通知書と労働条件通知書を添付しました。内容をご確認のうえ、
8月15日（金）までにご返答をいただけますと幸いです。
入社日は 9月1日（月）を考えていますが、ご都合があればお知らせください。

よろしくお願いいたします。
岡本設備工業 岡本
```

**内定は法的には労働契約の成立とみなされることが多い。** 経営者が条件の数字を確認する前に送らない。

---

## 特殊なケース

**社内の応募者や紹介された応募者。** 経営者が自分で直接伝えたいかもしれない。下書きの前に聞く。

**経験・資格が十分すぎる応募者。** それ自体は不採用の理由ではない — 会話の材料だ。判断せず、経営者にフラグする。

**以前にも応募した人。** その旨を記録する。二度目の応募は本気の関心の表れで、経営者は知りたいはずだ。

**不採用通知への怒りの返信。** 自動では何も下書きしない。経営者に見せ、返信するかどうか自体を経営者に決めてもらう。

---

## 承認

**すべてのメッセージとすべてのカレンダー招待は、送信前に見せる。** 例外はなく、経営者の目を通さない一括送信もない。

まとめて件数付きで提示し、40 通の承認が 40 回ではなく 1 回の判断で済むようにする：

```
ご承認をいただき次第、送信できます：
  面接のご案内 3 通 — 佐藤 健太、鈴木 彩、高橋 大輔（候補日時は下記）
  選考継続のご連絡 2 通 — 8月8日（金）まで — 渡辺 圭、山本 由香
  選考結果のご連絡（不採用）31 通 — 阿部、井上、加藤、木村、小林、…（全員の一覧は下記）
  確認の質問メール 4 通 — 「判定不能」の組 — 中村、林、松本、森

送信前に、どれか本文を読みますか？
```

**不採用を含め、宛先を全員名前で挙げる。** 「31 通」という件数だけでは検証できず、承認のステップの意味は、経営者が間違った組に入っている名前に気づけることにある。氏名は応募書類の表記とふりがなをそのまま使い、同姓の応募者はフルネームで区別する。

宛先を間違えた不採用通知は取り消せない。面接のご案内を受け取るはずだった人に不採用通知が届くのは、経営者が何年も忘れない類の失敗だ。

**メールのコネクタがなければ**、同じまとめの一覧が成果物だ：全メッセージの全文に宛先のラベルを付け、経営者が貼り付けて送れる状態にする。それは何も劣化していない — 文章を書くことと仕分けることが仕事だったのだから。
