# 公正な採用選考

制約、それが排除するもの、そしてその中で応募書類をどう読むか。

---

## ルール

**採点基準に対してだけ採点する。** 求人票に書かれた技能・経験・勤務条件。それ以外は点数に一切入れない。

理由は二つあり、どちらも重要だ。

**この仕事の大半で、それは法律と行政指針だ。** 性別による選考の差別は男女雇用機会均等法で、年齢制限は労働施策総合推進法で原則禁止（例外事由に当たる場合だけ、求人票に理由を明示して可）、障害を理由とする差別は障害者雇用促進法で禁止されている。国籍、本籍、家族、住居、思想信条による選考は厚生労働省の「公正な採用選考」の指針で排除すべきとされ、応募書類の個人情報は個人情報保護法と職業安定法により選考目的の範囲でしか使えない。人事部門のない中小企業の経営者こそ、最も矢面に立ち、最も弁明の備えがない。

**より良い候補者リストになる。** 現場で最も強い職人は、しばしば山の中で最も体裁の悪い履歴書を出してくる。見た目に費やした 1 点は、その人が仕事をできるかどうかに費やされなかった 1 点だ。

---

## 使ってはいけない情報（明示）

採点、順位付け、コメントに使わず、並び順に影響させない：

| 情報 | 除外する理由 |
|---|---|
| 氏名・ふりがな | 出身、性別、国籍の代理指標 |
| 年齢、生年月日、卒業年、「若くて長く働けそう」という読み | 年齢による差別そのもの。JIS 様式の履歴書の生年月日欄は見ない |
| 性別、履歴書の写真 | 均等法で保護され、仕事とは無関係。写真の印象は採点に入れない |
| 住所、居住地域、通勤時間の推測 | 出身・階層の代理指標。通勤できるかは応募者自身が判断する |
| 学校名や知名度 | 家庭の経済力の代理指標で、現場の実力の予測力は弱い |
| 勤務先の知名度・企業規模 | ロゴではなく、そこで書かれた仕事を採点する。大手は加点にならず、小さな工務店は減点にならない |
| 職歴の空白 | 介護、病気、出産・育児、留学、会社都合の離職。何の根拠でもない |
| 履歴書の体裁、仕事に関係しない誤字 | 学歴の代理指標。職務が文書作成を含むときだけ数える |
| 日本語の文章の巧拙、外国人らしい言い回し | 国籍の代理指標。職務が言語能力を明示的に求めない限り無関係 |
| 現在・前職の給与 | 既存の賃金格差を引き継ぐ。希望条件は条件提示の段階で経営者が確認する |
| 本籍・出生地、家族構成・家族の職業、住居の種類、生活環境 | 本人に責任のない事項。厚労省の指針で採用選考に使わないとされる |
| 宗教、支持政党、思想、尊敬する人物、購読紙、労働組合活動 | 本来自由であるべき事項。同じく指針で排除 |
| 賞罰欄、業務と関係のない前歴 | 業務上の必要性がある場合（運転免許の欠格など）だけ、経営者が弁護士・社労士と扱う。このスキルは扱わない |
| 「社風に合う」「雰囲気」「うちの人間っぽい」 | 吟味されていない好みが隠れる場所 |

**経営者がこれらのどれかでふるいにかけてほしいと言ったら、率直に一度だけ断り、正当な形を提案する。** 「空白期間で落とすことはできませんが、面接で聞くことはできます — その質問を下書きしましょうか？」 が、たいてい経営者が本当に求めていたものだ。

**SNS で身辺を調べない。** 応募者の X や Instagram を見に行くのは身元調査に当たり、上の表の情報がまとめて流れ込む。求人票の要件と応募書類だけで判断する。

## 匿名化の手順

採点の前に、読みに影響すべきでないものを取り除く。小さな手順だが効果は大きい。情報が紙面にないほうが、制約を守るのは簡単だからだ。

取り除く、または脇に置く：氏名・ふりがな、連絡先、写真、生年月日・年齢、性別、住所、卒業年、学校名、配偶者・扶養家族の欄、通勤時間、健康状態、本籍、そして仕事と関係のない個人的な記述。

残す：職種名、勤務先、在籍期間の長さ、書かれた業務内容、扱った機器・ツール・システム、免許・資格、明記された勤務可能な条件。

採点は匿名化した版で行う。身元が戻ってくるのは順位付けが終わり、経営者が応募者を一人の人として見る段階になってからだ。

**勤務先名は、いくらか情報を帯びていても見えるままにする** — 会社名のない職務経歴書は読めないし、そこで書かれた仕事こそが要点だ。判断はそこでの仕事についてであり、看板についてではない。

**応募書類は選考目的にだけ使い、選考が終わったら返却または破棄する**（個人情報保護法、職業安定法）。別の求人のために勝手に取っておかない。取っておきたいなら本人の同意を得る、と経営者に伝える。

## 根拠の抜き出し

採点基準の項目ごとに、応募書類の中でそれに触れている行を見つけ、引用する。

```
項目：業務用空調機（パッケージ・ビル用マルチ）の経験（重み 35）
点数：3
根拠：「商業施設 6 拠点で業務用パッケージエアコン 40 台超の保守・修理を担当、
      ダイキン・三菱電機製、2021 年〜2025 年」 — 応募者 7、現職
```

**引用した根拠のない点数は、選考ではなく印象だ。** 引用こそが、順位を経営者に、理由を尋ねてきた応募者に、後で見直す誰かに、説明できるものにする。

**体裁を読み飛ばす。** 「店舗のエアコンを直していた」と「商業施設ポートフォリオの空調設備のライフサイクル管理を担当」は同じ仕事を指しているかもしれない。仕事を採点する。

**書類に書かれていなければ、ダッシュにする。** 推測しない。「商業施設で働いていたのだから、たぶんパッケージ機の経験もあるだろう」は、良い方向にも悪い方向にも、偏りを裏口から招き入れる類の推測そのものだ。

## 「判定不能」の区分

必須項目、または重みの大きい項目がダッシュになった応募者はすべてここに入る。不採用の山ではない。

たいてい、2 行のメール一通で判断がつく：

```
佐藤 健太 様

お世話になっております。岡本設備工業の岡本です。
選考を進める前に一点だけ確認させてください。
第二種電気工事士の免状はお持ちでしょうか。ご応募書類からは読み取れませんでした。

よろしくお願いいたします。
岡本設備工業 岡本
```

**履歴書を書くのが下手な人は、仕事が下手な人ではない。** この区分こそ、応募者管理システムを持つ大企業より中小企業が採用で勝てる場所で、書類の書き方の問題でそれを失うのは本物の損失だ。

---

## 過程を見せる

経営者が見る応募者には、項目ごとの点数と、その裏にある引用が全員分ついてくる。

これは三つの働きをする：経営者が漠然とではなく具体的に反論できる、理由を尋ねてきた応募者に過程を説明できる、そして引用するものが何もない点数はすぐに見えるので、順位付けが正直に保たれる。

---

## それでも経営者が決めること

このスキルは順位付き・根拠付きのリストを作る。誰も採用しない。

経営者は、どの履歴書にもどの採点基準にも載っていない文脈を持っている — 信頼している人からの紹介、その人が今の班にどう収まるか、面接で見たもの。それは経営者の仕事であり、そのままであるべきだ。ここでの価値は、夜 10 時に 40 通の PDF を仕分ける代わりに、根拠のそろった 5 人に判断を使えることだ。
