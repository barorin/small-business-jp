# 事業者プロファイル

一度作り、以降のすべてのステップが読む。これがないと、どの検索も当てずっぽうで、どの Go/No-Go も遅い。

---

## 持つもの

**基本情報と登録**

| 項目 | なぜ重要か |
|---|---|
| 正式名称と事業形態 | 申請要件は常にここで決まる（株式会社／合同会社／個人事業主／NPO 法人） |
| 法人番号 | ほぼすべての申請で必要。公開情報なので出力してよい |
| 資本金と常時使用する従業員数 | 中小企業・小規模事業者の定義の判定に使う。従業員の数え方は制度ごとの定義で |
| GビズIDプライムの有無と管理者 | jGrants と多くの電子申請の入口。未取得なら取得所要日数が締切に直結する |
| 全省庁統一資格・自治体の入札参加資格と有効期限 | 失効した資格は即失格 |
| 適格請求書発行事業者の登録の有無 | インボイス特例（加点・上限の引き上げ）の判定と、経費の消費税の扱い |
| 許認可（建設業許可 など）と経審の点数・等級 | 工事の入札は許可と経審が入口。業種固有の登録もここ |

**分類**

日本標準産業分類での業種。中小企業の定義は業種で基準が変わる（製造業その他 資本金 3 億円以下または従業員 300 人以下、卸売業 1 億円・100 人、小売業 5,000 万円・50 人、サービス業 5,000 万円・100 人。小規模事業者は製造業その他 20 人以下、商業・サービス業 5 人以下 — いずれも公募要領の定義で確認）。そして各種の認定・宣言：経営革新計画、経営力向上計画、事業継続力強化計画、先端設備等導入計画、パートナーシップ構築宣言、賃上げ表明、健康経営優良法人、えるぼし・くるみん など。

**認定と宣言は、プロファイルでもっとも効く項目だ。** 加点項目として採択率を直接動かし、優先枠や補助率引き上げの入口になる。多くは取得に数週間から数か月かかるので、公募が出てからでは間に合わない。

**体力**

年商、決算書 2 期分（多くの制度で必須の添付）、従業員数、事業所の所在地、保険の種類と限度額、金融機関との関係と借入枠（立替資金の出所）、認定経営革新等支援機関との関係（確認書の発行元）、商工会議所・商工会の会員かどうか、そして帳簿・証憑の管理が実績報告に耐えるか。

**事業**

事業内容と、それを裏付ける数字：主要な商品・サービス、売上構成、顧客層と商圏、雇用、直近の投資と成果。実際の数字を実際の出所とともに。

**人**

経営者と主要な従業員の実際の資格・経歴・経験年数（管工事施工管理技士、電気工事士、焙煎の受賞歴 など）。NPO 法人なら役員構成。

## 過去の申請書 — 本当の資産

過去の申請書と提案書（採択・不採択問わず）は、今後のどの下書きにとっても唯一最大の入力だ。

**集める** — Google Drive、Microsoft 365、またはアップロードから。事業者のものと確認できたストアを、事業者名で検索して（`../../../shared/tenant-scope.md`）。一件ごとに索引を付ける：制度名（所管・事務局）、公募回と案件番号、申請日、申請額、結果、所見や開札結果があればそれも。

**再利用できる部品を取り出す：**

- 会社概要と沿革の定型文
- 事業内容の説明（事業ごと）
- 経営者・主要従業員の経歴
- 実績の記述（契約・補助事業ごと）
- 経営状況の分析（強み・弱み・機会・脅威）、数値目標、収益計画、実施体制図
- 経費明細の積算と標準の費目
- 連携先・推薦者の一覧（商工会議所、認定支援機関、金融機関、取引先）

**不採択のほうが採択より教えてくれる。** 「実績の節が弱い」という所見は何を作り直すかを正確に教えてくれるのに、たいていの事業者は不採択通知を綴じて二度と読まない。

## 最新に保つ

期限のある項目は、誰も見ていなければ申請を静かに失格させる：

- **GビズIDプライム** — 有効期限があり、管理者の異動で使えなくなる
- **入札参加資格** — 定期受付は 2〜3 年ごと。失効が多い
- **建設業許可・経審** — 許可は 5 年更新、経審は毎年（有効期間 1 年 7 か月）
- **決算書** — 直近 2 期分。決算が確定したら差し替える
- **認定・宣言** — 経営革新計画は 3〜5 年、経営力向上計画は 3〜5 年、事業継続力強化計画は 3 年。パートナーシップ構築宣言は内容の見直しを
- **保険証券** — 年 1 回

それぞれの期限を、60 日以上の余裕を持ってカレンダーに入れる。申請日に発覚した GビズIDや参加資格の失効が、勝てたはずの申請を終わらせてきた。

## 二つの事業者の形

**小規模の製造・小売業。** ひかり珈琲焙煎所 — カフェ 4 店舗と卸、Shopify の EC を持つ焙煎所、従業員 25 名、12 月決算、神戸市。焙煎機の更新で補助金を探している。プロファイルの重心は業種の判定（焙煎は製造業、カフェは飲食サービス業）、従業員数（25 名は小規模事業者の定義を超えるので持続化補助金は対象外、ものづくり補助金の中小企業者には該当）、決算書、賃上げ表明、認定支援機関との関係。勝つ材料は、設備投資が売上と生産性をどう変えるかの数字だ。

**設備工事業。** 岡本設備工業 — 空調・給排水設備工事、従業員 8 名、3 月決算、さいたま市。IT導入補助金で施工管理ソフトを入れ、さいたま市の空調保守業務の入札を狙う。プロファイルの重心は建設業許可（管工事）、経審の点数と等級、さいたま市と埼玉県の入札参加資格、同種業務の実績、有資格者（管工事施工管理技士）、IT導入支援事業者との関係。勝つ材料は、同規模・同種の案件の実績だ。

**Go/No-Go は両者で大きく違う。** 補助金の即 No はたいてい事業者の定義（従業員数・業種）と補助対象経費。入札の即 No はたいてい参加資格・等級と実績の基準だ。事業者がどちらかを知ってプロファイルを作る。どの確認が申請をもっとも速く落とすかを決めるからだ。
