# 案件の情報源

案件がどこにあるか、そして毎日の一覧を読む価値のある数件までどうふるうか。

---

## 補助金（国）

**jGrants** — 経済産業省が運営する補助金の電子申請システム。公募中の補助金を制度名・所管・対象地域・締切で検索でき、申請もここで行う。**申請には GビズIDプライムが必要**で、取得には郵送で 1〜2 週間（マイナンバーカードのオンライン申請なら数日）。検索は誰でもできるので、まず一覧はここで取る。

**ミラサポplus** — 中小企業庁の総合支援サイト。補助金・給付金の制度ナビと、認定経営革新等支援機関の検索。制度の全体像をつかむのに向き、公募要領そのものは各事務局サイトへ。

**J-Net21（中小機構）** — 補助金・助成金・融資の横断検索。国と自治体の制度を一度に引ける数少ない場所で、自治体分の網羅性は完全ではない。

**中小企業庁・各省庁の公募ページと事務局サイト** — 小規模事業者持続化補助金、IT導入補助金、ものづくり補助金、中小企業省力化投資補助金、新事業進出補助金、事業承継・M&A補助金はそれぞれ事務局サイトを持ち、公募要領はそこが正だ。次回公募の予告、説明会の案内、補正予算による新設もここに出る。予告の先読みは、この一覧のどれよりも価値がある — 反応するのではなく準備できる唯一の手段だからだ。

---

## 助成金（厚生労働省）

**雇用関係助成金** — キャリアアップ助成金、業務改善助成金、人材開発支援助成金、両立支援等助成金、雇用調整助成金。補助金と違い、**要件を満たせば原則受給できる**（審査で競わない）が、多くは取り組みの前に計画届を出す必要があり、事後では受け付けない。窓口は都道府県労働局とハローワーク。

**申請代行は社会保険労務士の独占業務**（社労士法）。代行を頼むなら社労士に。労働保険の加入と保険料の納付、直近の解雇の有無が共通の入口要件で、給与計算の記録がそのまま証憑になる。

---

## 自治体・地域

**都道府県・市区町村の補助金** — 小さく、競争が少なく、国の制度より小規模事業者に合うことが多い。自治体サイトの「産業振興」「商工」ページと、自治体の中小企業支援センター（よろず支援拠点）に出る。

**商工会議所・商工会** — 持続化補助金の事業支援計画書（様式4）の発行元であり、自治体の補助金や地域の販路開拓事業の案内所でもある。会員でなくても持続化補助金の支援は受けられるが、日数がかかる。

**業界団体・地域金融機関** — 業界団体の補助事業、信用金庫・地方銀行が案内する制度融資と補助金のセット。関係で動くことが多く、競争より紹介で決まる。

## 公共調達

**官公需情報ポータルサイト（中小企業庁）** — 国・独立行政法人・自治体の入札情報を横断検索。業種、地域、発注機関、公告日で絞る。中小企業向けの配慮（少額随意契約、分離・分割発注）はここが出発点で、小規模事業者にもっとも価値のある絞り込みだ。

**調達ポータル（政府電子調達 GEPS）** — 各省庁の入札公告と電子入札。**全省庁統一資格**が必要で、審査には数週間かかる。

**各省庁・自治体の入札情報** — 自治体は独自の電子入札システムと入札参加資格（定期受付は 2〜3 年に 1 度が多く、随時受付があるかは自治体次第）を持つ。工事は建設業許可と経営事項審査（経審）の点数・等級が入口。事業者に関係する 2〜3 の発注機関は直接見に行く価値がある。

**元請の協力会社募集ページ** — 大手ゼネコン・設備会社・IT ベンダーは協力会社を募集している。小規模事業者が一貫して手薄にしている領域で、直接入札より勝率が高いことも多い。

## 毎日の一覧をふるう

毎日の一覧の要点は、そのほとんどが自社向けではないことだ。経営者に届く前にふるう。

**フィルタを、この順で — 安い確認から先に：**

1. **申請要件** — 事業形態、中小企業・小規模事業者の定義（資本金・従業員数）、創業年数。一覧の大半を即座に落とす
2. **業種と補助対象経費** — 自社の業種（日本標準産業分類）に当たるか、やりたい投資がその制度の対象経費か
3. **所在地** — 自治体の制度は本店・事業所の所在地で決まる
4. **金額** — 補助上限と補助率から自己負担を出し、立替できる規模か。下限（最低投資額）と上限の両方
5. **締切の実現性** — 4 日後が締切で GビズIDプライム未取得なら No。認定支援機関の確認書や商工会議所の事業支援計画書の発行日数も含める
6. **既存業者の有無** — 入札で満足している既存業者との再競争はたいてい No

**件数を報告する。** 何を捨てたかを経営者が見られるときにだけ、フィルタは信頼される：

```
官公需情報ポータル 7月24日: 公告 312 件
  → 47 件が管工事・設備保守
  → 19 件が埼玉県内
  → 11 件が入札参加資格の等級内
  → 4 件が締切に間に合う
  → 2 件を Go/No-Go の本審査に推薦

締切で除外: 5 件（いずれも 3 日以内）
規模で除外: 8 件（予定価格 2 億円超、経審の等級外）
```

**惜しい案件は週に一度、毎日ではなく見せる。** 除外の理由の繰り返しは経営情報だ — 経審の等級が週に 8 件を落としているなら、それは提起する価値のある経営判断であって、単なるフィルタの統計ではない。

## パイプラインの記録

触れたすべての案件を一か所に、状態付きで持つ：

| 状態 | 意味 |
|---|---|
| 予告 | 次回公募の予告や予算案の段階で、まだ公募されていない |
| 検討中 | 公募中、Go/No-Go を実施中 |
| 申請準備 | Go 判定済み、下書き中 |
| 申請済み | 提出済み。提出日と受付番号 |
| 採択 | 採択・落札 — 交付決定と採択後の義務がここから始まる |
| 不採択 | 不採択・落札できず。所見や開札結果があればそれも |
| 見送り | 申請せず、理由付き |

**見送りの理由がこの表でもっとも価値のある列だ。** ほぼすべての補助金は毎年、多いものは年に数回公募され、来年の判断は根拠がすでに書いてあるので一晩ではなく 90 秒で済む。

**不採択の理由は取りに行く。** 補助金は理由が開示されないことが多いが、持続化補助金なら商工会議所の経営指導員の所見、認定支援機関の見立てが聞ける。入札は開札結果（落札者・落札額）が公表され、総合評価方式なら評価点の開示を求められることが多い。実際の評価が見える唯一の場所で、たいていの小規模事業者はそれを飛ばす。

## 頻度

**毎日** 官公需情報ポータルや自治体の電子入札のように公告の多い一覧。速さがすべての差になる。

**週に一度** 補助金・助成金と大半の公共調達。公募は数か月単位で動き、毎日見ても大半の日は何もない。

**四半期に一度、予告を確認する。** 各制度の次回公募の予告、国の補正予算・当初予算の概要は、小規模事業者が公募に追われるのではなく先回りする手段で、四半期に一度で捕まえられる。
