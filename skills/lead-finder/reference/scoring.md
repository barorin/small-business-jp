# 採点

構成要素は三つ。点数は経営者がリストに取り組む順番を決める。順番こそがリストの主目的だ。

```
総合点 = (適合度 × 0.4) + (シグナル × 0.4) + (到達しやすさ × 0.2)
```

各要素は 0〜10。シグナルの重みは意図的に適合度と同じにしてある — 相性は良くても何も起きていない会社は飛び込み電話であり、飛び込み電話は経営者がすでにうまくいっていないやり方だ。

---

## 適合度 — 40%

`icp_method.md` のプロフィール（業種・規模・エリア）にどれだけ近いか。

| 点数 | 意味 |
|---|---|
| 9〜10 | プロフィールの条件をすべて満たす |
| 7〜8 | 中核の条件は満たし、副次的な軸が一つ外れる |
| 5〜6 | ありえるが、重要な何かが欠けている |
| 3〜4 | 隣接 — シグナルが強いときだけ入れる価値がある |
| 0〜2 | 入れない |

プロフィールに逆パターン（「従業員 10人未満は離れる」）があれば、それに当てはまる会社は他が何であれ上限 4 とする。

---

## シグナル — 40%

今まさに何かが起きている証拠。見込み客リストと名簿の違いはここにある。

| シグナル | 点数 | 意味 |
|---|---|---|
| 新店舗・新拠点、増床、建築計画のお知らせ | 10 | 支出中で、既存の業者では手が回らないかもしれない |
| 経営者が売るものに関係する職種の求人 | 9 | 予算はすでに承認済み |
| 代表者交代・事業承継・役員変更 | 8 | 新しい決裁者は取引先を見直す |
| 資金調達、M&A、大型受注、補助金の採択 | 8 | お金と新しい需要が同時に来る |
| 現在の業者に対する最近の低評価口コミ | 8 | 現在進行形の不満。たいてい手に入る中で最も温かいシグナル |
| 季節・決算期が購買サイクルに合う | 6 | 時期は良いが、特定のきっかけはない |
| Web サイトやブランドの刷新 | 5 | 投資はしているが、需要の証拠としては弱い |
| 何も見つからない | 2 | 失格ではなく、ただ冷たいだけ |

**シグナルには日付と情報源が要る。** 「拡大中」は噂だ。「3月14日に 2 店舗目の開店を PR TIMES で発表」は今週電話する理由になる。

シグナルを創作しない。きっかけを捏造した見込み客リストは、最初の一本で経営者の信用を壊し、二度とこのスキルを信じてもらえなくなる。

---

## 到達しやすさ — 20%

経営者が決裁者の前にどれだけ直接出られるか。

| ルート | 点数 |
|---|---|
| 紹介してくれる共通の顧客・知人がいる | 10 |
| 決裁者の名前があり、確認済みの直接連絡先（名刺交換済み、Web 公開）がある | 8 |
| 決裁者の名前はあるが、連絡先は推定で未確認 | 6 |
| 名前はあるが、決裁者ではない | 4 |
| 代表電話・問い合わせフォームのみ | 3 |
| 連絡ルートが見つからない | 1 |

**紹介ルートは探す価値がある。** 対象の会社を、経営者の既存顧客リスト、同じ団体・組合、商工会議所の部会、重なるエリアと突き合わせる。紹介経由は飛び込みの何倍も成約しやすく、経営者は自分がすでに持っている紹介ルートの数を一貫して過小評価している。

---

## 点数の見せ方

順位と理由を見せる。計算は見せない。経営者は加重式を見たいのではなく、なぜこの会社が 3 番なのかを知りたい。

**悪い例:**
```
大宮ビル管理株式会社 — 総合点 8.4
```

**良い例:**
```
3. 大宮ビル管理株式会社 — 管理棟数 6 棟、本社から 18 km。
   3月14日に 7 棟目（大宮西口ビル）の管理受託を自社サイトで公表。
   現在の空調保守業者には今期 Google マップで星 2 の口コミが 3 件。
   担当: 田中 美咲 様（施設管理部長）、直通番号は確認済み。
```

点数は同じ。電話されるのは片方だけだ。

---

## 同点と足切り

同点はシグナルの新しさで決める。先週のきっかけは、前の四半期のきっかけに勝つ。

4 点未満はリストに載せない。目標件数に届かせるために弱い行を入れるのは、順位を無意味にする最短の道であり、順位こそが製品だ。
