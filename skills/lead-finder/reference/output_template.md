# 出力テンプレート

チャット要約が先、XLSX が次、CRM への書き込みは承認の後だけ。

---

## チャット要約

```
## 見込み客リスト — <件数> 社

<プロフィールがどうだったか、一文で。>

### まずこの会社から

1. **<会社名>** — <規模、所在地> · <シグナル。日付と情報源付き>
   <担当者名、役職、連絡ルート>
2. ...

<10 社まで。>

### このリストについて

貴社の顧客 <n> 社から作成。プロフィール: <一行>。
情報源: <Apollo | Web リサーチ>。<件数> 社が基準を満たし、他に <n> 社が
見つかったが適合が弱く除外。

<全件は列をすべて含めた XLSX で添付。>
```

チャットには 10 社が適量だ。リストが使えるかどうかを判断する前に、経営者が実際に読む量がこれだ。

---

## 実例

```
## 見込み客リスト — 47 社

貴社の上位顧客は、管理棟数 3〜15 棟の商業ビル管理会社で、30 km 圏内、
紹介で来た会社です — 件数の大半を占める戸建ての緊急修理ではありません。

### まずこの会社から

1. **大宮ビル管理株式会社** — 管理棟数 6 棟、18 km · 3月14日に 7 棟目
   （大宮西口ビル）の管理受託を自社サイトで公表。現在の空調保守業者には
   今期 Google マップで星 2 の口コミが 3 件。
   田中 美咲 様（施設管理部長）· 直通番号は確認済み

2. **株式会社コーウィン商会** — 管理棟数 9 棟、11 km · 施設管理担当を
   募集中（Indeed、4月2日掲載）。貴社の顧客・株式会社桜木パートナーズと
   テナントが共通 — 紹介ルートの可能性あり。
   鈴木 健一 様（管理部 部長）· メールは推定、未確認

3. **浦和ビルディング株式会社** — 管理棟数 4 棟、23 km · 2月に 2 か所目の
   事務所を開設。
   担当者不明 — 代表電話のみ

### このリストについて

貴社の顧客 340 社から作成。プロフィール: 商業ビル管理会社、管理棟数
3〜15 棟、30 km 圏内、紹介経由、最初の仕事が保守契約。
情報源: Web リサーチ（Apollo 未接続）— 建築計画のお知らせ、不動産協会の
会員名簿、口コミサイト、求人媒体。
47 社が基準を満たし、他に 61 社が見つかったが適合が弱く除外。

全件は XLSX で添付。
```

3 行目に注目。担当者不明でも残し、正直にそう書く。経営者がすでに知っている相手かもしれない。

## XLSX の列

この順で。最初の 7 列が実際に使われ、残りは根拠だ。

| 列 | 備考 |
|---|---|
| 順位 | 1〜n |
| 会社名 | |
| 業種 | 業種・業態（プロフィールの軸と同じ粒度） |
| 今すぐの理由（根拠） | シグナルを一文で、日付付き |
| 決裁者（氏名・役職） | 氏名と役職、または「不明」 |
| 連絡ルート | メール、電話、問い合わせフォーム、または連絡先を見つける経路 |
| 連絡先の確度 | 確認済み · 推定 · 不明 |
| 適合度 | 0〜10 |
| シグナル | 0〜10 |
| 到達しやすさ | 0〜10 |
| 総合点（優先度） | |
| 規模 | 従業員数、拠点数、または売上の帯 |
| 所在地 | 市区町村と経営者の拠点からの距離 |
| 情報源 | きっかけの出どころ。リンクがあればリンク |
| 紹介ルート | 共通の顧客・知人がいれば |
| 備考 | 上に収まらなかったこと |

ヘッダー行を固定する。総合点の降順で並べる。点数は文字列ではなく数値の書式にする。

## CRM への書き込み

明示的な「はい」の後だけ。しかも、何が起きるかを正確に言ってから:

```
HubSpot に追加する準備ができました: 会社 47 件と担当者 39 件、タグは
「prospect-list-2026-07」。既存のレコードは一切変更しません。「進めて」と
言っていただければ作成します。
```

タグを名指しする。既存に触れないことを確認する。誤った一括登録は戻すのに何時間もかかり、経営者には自分で事前確認する手段がない。

断られたら、XLSX が納品物だ。それは完全な成果であって、部分的な成果ではない。

---

## 連絡先の確度は省略不可

すべての連絡先の行に確度を付ける。

- **確認済み** — アドレスや番号が、それを裏付ける情報源（名刺、Web サイトの公開情報、団体名簿）から来ている
- **推定** — 標準的なメール形式など、パターンから組み立てたもの
- **不明** — ルートが見つからない

推定アドレスへの一斉送信は、ドメインを迷惑メール扱いにさせる道だ。その損害は何か月も続き、経営者の本物の顧客メールにも及ぶ。さらに、推定アドレスは名刺交換も Web 公開もされていないため、特定電子メール法の例外に当たらない。営業メールのステップが扱いを分けられるよう、明記する。
