# 似た会社の探し方（ソーシング）

道は二つ。Apollo が接続されていればそれで、なければ Web リサーチで。どちらも本物のリストになる。

---

## Apollo がある場合

主要な経路。プロフィールの軸でフィルタし、担当者とシグナルを同じ一手で引き出す。

この規模で役立つフィルタ、おおよその価値順:

- 業種・細分類
- 従業員数の帯
- 経営者の拠点からの距離
- 使用中の技術（適合の根拠になる場合）
- 最近の採用活動
- 資金調達・株主の変更

担当者は氏名ではなく役職で引く。中小企業の決裁者として探す価値のある役職は、代表取締役、社長、専務、取締役、総務部長、管理部長、店長、施設管理責任者だ。役職名は業種によって大きく違う — 経営者の既存の連絡先がどう呼ばれているかを確認し、その役職で検索する。

**Clay** は Apollo と同格（`../../../shared/connector-neutrality.md`）: 接続されているほうで検索する。やり方は同じで道具が違うだけ — 似た会社は `find-and-enrich-company`、その会社の人は `find-and-enrich-contacts-at-company`。どちらも従量課金なので、検索前に見積クレジットを言う。**どちらも海外発のデータベースで、国内の中小企業の網羅率は限定的**だ。ヒットしなくても、その会社が存在しないことにはならない。

---

## Apollo がない場合 — Web リサーチ

遅くて小さいが、1 行ごとに実際に会社を見ているぶん質は高いことが多い。劣化した出力として扱わない。

### 一般的な情報源

- 業界団体・組合の会員名簿 — たいてい単独で最良の情報源
- 国税庁の法人番号公表サイト（所在地・商号での検索、新設法人の一覧）と、都道府県の許認可・登録業者の検索
- 商工会議所・商工会の会員名簿
- 帝国データバンク・東京商工リサーチの企業情報（有料。規模・評点の裏取り向き）
- Google マップと口コミサイト（業種・地域で絞る）
- 求人媒体（Indeed、求人ボックス、ハローワーク）— 採用中は成長中
- PR TIMES などのプレスリリース、地元紙・業界紙（新店舗、増床、受賞）
- 展示会の出展者一覧、自治体の入札参加資格者名簿
- 自社 Web サイトへの問い合わせ履歴と名刺交換の記録 — 経営者がすでに接点を持っている会社

### 業種別

| 業種 | 名簿のありか |
|---|---|
| 建設・設備 | 国土交通省の建設業者検索システム、建築計画のお知らせ看板、建設業協会・設備業協会の名簿 |
| 医療・介護 | 都道府県の医療機関検索、介護サービス情報公表システム、医師会・歯科医師会の会員名簿 |
| 飲食・小売 | 食べログ・ホットペッパーなどのグルメサイト、デリバリーサービスの掲載店、商店街・ショッピングモールの店舗一覧 |
| 士業・専門サービス | 弁護士会・税理士会・社労士会の会員検索、業界の表彰リスト |
| 製造業 | 工業会・工業団地の企業名簿、展示会の出展者一覧、サプライヤー検索サイト |
| NPO・公益法人 | 内閣府 NPO 法人ポータルサイト、公益法人の公開情報、助成財団の採択一覧 |
| 不動産管理 | 賃貸住宅管理業者の登録検索（国土交通省）、宅建業者名簿、不動産協会の会員名簿、物件掲載サイト |

**建築計画のお知らせと許認可・登録情報は、設備・建設業にとって最も過小評価されている情報源だ。** 公開されていて日付があり、届出そのものが購買シグナルになる。

### データ提供サービスなしで担当者を探す

- 会社サイトの会社概要・役員紹介・スタッフ紹介ページ
- 法人登記（登記情報提供サービス）に載る役員名
- 団体の会員名簿。担当者名が載っていることが多い
- 口コミへの返信。代表者の署名が入っていることが多い

担当者が見つからないときは、会社を残して担当者「不明」と記す。名前がないからといって良い適合度の会社を落とさない — 経営者がすでに知っている相手かもしれない。

### 個人情報保護法の一言

会社の代表電話や代表アドレスは個人情報ではないが、担当者の氏名とメールアドレスの組み合わせは個人情報だ。行ごとに **取得元** と **利用目的（営業のご案内）** を記録し、公開元が「営業目的の利用お断り」と明示している名簿は使わない。名簿業者から買う場合は、その業者がオプトアウト届出済みかを確認し、取得の経緯を残す。

## 何行にするか

目標は 40〜60 社。

500 行のかき集めは見栄えはするが無視される。経営者はどの 20 社から始めればよいか分からず、それを調べる手間が元の手作業を上回るからだ。理由の付いた 40 行なら、実際に取り組まれる。

プロフィールが本当に狭く、該当が 12 社しかないなら、12 社を出してそう言う。短くて正直なリストは問題ない。数合わせのために適合の弱い会社を足すと順位が壊れる。順位こそがこの納品物の価値そのものだ。

---

## 確認

行をリストに載せる前に、その会社がまだ存在し、まだプロフィールに合っていることを確かめる。名簿は古くなり、会社は閉じる。廃業した会社が載ったリストは、3 回目の不通で見捨てられる。

Web サイトが表示され、営業中に見えることを確認する。法人番号公表サイトで閉鎖・合併の履歴も一目で分かる。これは短時間で済み、使われるリストと削除されるリストの分かれ目になる。
