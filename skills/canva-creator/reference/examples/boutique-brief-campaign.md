# 実例: セレクトショップのブリーフ → キャンペーン

**事業:** セレクトショップ ルミエ — レディースのセレクトショップ、大阪市（南船場の実店舗＋Shopify のネットショップ。集客は Instagram と LINE公式アカウント）  
**Canva のプラン:** Teams（Enterprise ではない）  
**HubSpot のプラン:** Marketing Hub Professional  
**ブリーフの出どころ:** 販促戦略（content-strategy）スキルの出力（経営者が承認済み）

---

## 入力: 承認済みブリーフ（要約）

```
強く推す: ニットカーディガン（急伸中、前月比 +12%。今年の色展開が強み）
維持: ハイウエストデニム
季節の機会: 10月からの秋冬ピークに向けて、9月末に秋の新作を打ち出す
オファー: 秋の新作 2点お買い上げで小物 1点プレゼント（9月28日〜10月31日）
価格: ニットカーディガン 12,800円（税込）、ウールコート 35,800円（税込）
媒体: Instagram フィード、Instagram ストーリーズ、LINE公式アカウント
頻度: 週3回、月・水・金、18:00 JST（店舗客向けは夕方が既定）
声: あたたかく、話しかける調子、軽いユーモア。会社案内のような文章は禁止
```

## ステージ2: Canva アセットの生成（Pro／Teams の経路）

**テンプレート選択のやり取り:**

```
Claude: お使いの Canva ライブラリに、正方形投稿のテンプレートが 3 つあります：
  1. ルミエ 正方形 - 生成り  （最終編集 2026年8月）
  2. 秋の販促 - ベージュ    （最終編集 2026年7月）
  3. 商品紹介カード        （最終編集 2026年5月）
  フィード投稿はどれを使いますか？

経営者: 生成りの、1 番で。

Claude: 承知しました。フィード投稿はすべて「ルミエ 正方形 - 生成り」で
        進めます。見出しのフォントが Noto Sans JP になっているので、
        日本語もそのまま出ます。いまデザインの雛形を作ります —
        Canva 上で商品写真と文字を入れていただくリンクをお渡しするので、
        戻ってきたらこちらでエクスポートします。
```

*[デザインを作成。経営者が Canva 上で写真と文字を入れ、デザイン ID を戻す]*

**エクスポートの出力:**
```
プレビューをエクスポート中...

✓ 9月30日 フィード投稿      → https://canva.com/export/def456.png
```

*経営者: 「いい感じ。進めてください。」*

## ステージ3: キャプションの下書き

**9月28日 — Instagram フィード（秋の新作カーディガン発売）**
```
ようやく秋。ようやくカーディガンの出番です。

今年のニットカーディガン、届きました。色は 4 色。
軽くて、あたたかくて、そして — ちゃんとポケットがあります。

サイズが揃っているうちにどうぞ → プロフィールのリンクから。

#秋の新作 #ニットカーディガン #大阪セレクトショップ #ootd #ルミエ
```

**9月30日 — Instagram フィード（着回し）**
```
「今週 4 回着ました。反省はしていません。」

お客様からいただいた、カーディガンの本当の感想です。
正直、私たちも驚いていません。
1枚で 3 通り — デニムに、ワンピースに、シャツの上に。
着回しは 2 枚目からどうぞ。

#秋コーデ #着回し #大阪セレクトショップ #ルミエ
```

**10月2日 — Instagram ストーリーズ（オファー）**
```
秋の新作 2点で、小物 1点プレゼント

10月31日まで。店頭でもオンラインでも。

リンクスタンプから見る →
```

**法規の確認:** すべて自社アカウントによる自社商品の投稿で、第三者への対価を伴わないため、景品表示法のステマ規制が求める「PR」表記は不要（インフルエンサーへの提供品の投稿があれば、その投稿にだけ「PR」を入れる）。プレゼント企画は総付景品 — 取引価額 25,600円の 20% は 5,120円で、小物（ソックス 1,650円〜バッグチャーム 3,300円）は上限内。価格はすべて税込表示。「No.1」「最安」の表現なし。

*経営者は一か所だけ修正して承認: 「9月30日のキャプション — 最後に価格を入れて。『12,800円（税込）、詳しくはプロフィールのリンクから。』」*  
*キャプションを更新。*

## ステージ4: HubSpot への準備

**キャンペーンを作成:**
```
キャンペーン: 「ルミエ — 秋の新作 2026」
開始: 2026年9月28日 | 終了: 2026年10月31日
キャンペーン ID: 8a72c1f4...
```

**予約キュー（先頭 3 件）:**

| 予約時刻 | 媒体 | キャプションの先頭 | 状態 |
|----------|------|--------------------|------|
| 9月28日 18:00 JST | Instagram | 「ようやく秋。ようやくカーディガンの…」 | SCHEDULED |
| 9月30日 18:00 JST | Instagram | 「今週 4 回着ました。反省は…」 | SCHEDULED |
| 10月2日 18:00 JST | Instagram ストーリーズ | 「秋の新作 2点で、小物 1点プレゼント…」 | SCHEDULED |

`scheduledAt` はすべて `+09:00` 付きで、呼び出し時点より未来であることを確認済み。LINE公式アカウントの行（10月5日）は HubSpot のチャネルにないので、手動投稿用コピー（本文 200 字以内＋リンク 1 つ＋恒久画像 URL＋配信時刻）にまとめ、LINE Official Account Manager の予約配信に貼る形で渡す。

**経営者への最終メッセージ:**
```
キャンペーンを HubSpot に準備しました:
https://app.hubspot.com/content/12345/social/campaigns/8a72c1f4

投稿は時刻になると自動で公開されます。公開前なら、HubSpot 上でどの投稿も
取り消し・編集できます。LINE の配信は下の手動投稿用コピーを
LINE Official Account Manager の予約配信に貼ってください。
仕上げる前に直すところはありますか？
```

## メールの内容の例（テキストのみ — Canva なし）

メールの行は Canva を丸ごと飛ばす。Claude はステージ3で件名、プレヘッダー、
本文を平文で書き、経営者は送る準備ができたら自分のメールツールに貼る。

**カレンダーの行:**

| 日付 | 媒体 | テーマ | アセット種別 | 切り口 |
|------|------|--------|-------------|--------|
| 10月1日（木） | メール | 秋の新作のご案内 | メール（テキスト） | お客様の利点＋オファー |

**ステージ3の出力（インライン、Canva は関与しない）:**

```
件名: 秋の新作、店頭とオンラインで揃いました
プレヘッダー: 今年のカーディガンは 4 色 — 2点お選びいただくと小物を 1 点。

こんにちは、ルミエの佐藤です。

秋の新作のニットカーディガンが店頭に並びました。デニムにも、
ワンピースにも、シャツの上にも — 「今日は何を着よう」を
考えなくていい、そんな 1 枚です。

いくつかお伝えしておきたいこと:
  ・サイズは S〜L、色は 4 色
  ・ポケット付き（飾りではなく、本当に入ります）
  ・10月31日までに新作を 2 点お選びいただくと、小物を 1 点プレゼント

今週末、南船場の店舗（地下鉄 心斎橋駅から徒歩 5 分）でお待ちしています。
オンラインは下のリンクからどうぞ。

秋の新作を見る →

— 佐藤
セレクトショップ ルミエ
大阪市中央区南船場
このメールは店頭またはオンラインでご登録いただいた方にお送りしています。
配信停止はこちら
```

送信者名・住所・配信停止の方法を署名に入れているのは特定電子メール法の
表示義務。価格は本文では 12,800円（税込）のように税込で書く。

**ステージ4の引き渡し:**

```
SNS 投稿は HubSpot に予約として準備しました: [リンク]

10月1日のメールの文章は上に下書きしました — 送る準備ができたら、
お使いのメールツールに貼ってください。メールはこちらから準備しません。
送信側のツールで先に表示を確認していただくためです。
```
