# 出力テンプレート

毎回の実行で成果物は二つ: チャットのサマリー、次に XLSX ワークブック。サマリーが製品で、ワークブックは付録だ。

---

## チャットのサマリー

```
## <レポート名> — <期間>

<一文: このレポートが言っている最も重要なこと。>

**<指標1>** — <値>、<比較との差>
**<指標2>** — <値>、<比較との差>
**<指標3>** — <値>、<比較との差>

### 目立つ点

- <所見。具体的なレコードやグループを名指しし、数字を添える>
- <所見>
- <所見>

### 確認したいこと

- <判断が必要なことと、提案する次の一手>

<ワークブックを添付。タブ: サマリー、指標グループごとに 1 つ、生データ。>
```

所見は最大三つ。九つの箇条書きがあるサマリーは、手間の増えた表だ。

### 日本の中小企業でよく使う指標と表記

| 指標 | 計算式 | 表記の例 |
|---|---|---|
| 月商 | 当月の売上高（税抜） | 14,000,000円 |
| 粗利率 | (売上 - 売上原価) / 売上 | 38.0% |
| 売掛金回転日数 | 売掛金残高 / 売上高 × 期間の日数 | 42日 |
| 手元資金月数 | 現預金残高 / 月間の固定費 | 2.6か月 |
| 客単価 | 売上 / 客数（または注文数） | 1,240円 |
| リピート率 | 期間内の再購入客 / 全購入客 | 46% |
| 人件費率 | 人件費 / 売上高 | 31% |
| 労働分配率 | 人件費 / 粗利（付加価値） | 52% |

金額は `14,000,000円` の全桁表記（本文では `1,400万円` も可）で、税込／税抜を明記する。比率は小数 1 桁まで。分母が 0 なら 0% ではなく「算出不能」。

## 記入例

```
## 月曜の経営パック — 7月20日の週

高橋班だけが前年割れで、売上合計が横ばいになった原因はそこにあります。

**売上** — 3,240,000円（税抜）、前年同週比 +2%
**売掛金（期日超過）** — 934,000円、6件
**人件費率** — 31%、前週の 28% から上昇

### 目立つ点

- 高橋班は 458,000円、前年同週比 -22%。他の班はすべて前年超え。
- 人件費率が 9週ぶりに 30% を超えた。鈴木班の残業が主因。
- 株式会社コーウィン商会は 182,400円が 34日超過。5月12日以降の入金なし。

### 確認したいこと

- 高橋班の落ち込みは 4週連続で、一週だけの揺れではありません。四半期の主題になる前に、
  人員配置か受注の減少を確認する価値があります。

ワークブックを添付。タブ: サマリー、班別売上、売掛金の滞留、人件費の内訳、生データ。
```

サマリーが何をしているかに注目する: 班を名指しし、数字を出し、傾向の長さを述べ、次の一手を提案している。「売上はまちまち」では何も言っていない。

## XLSX ワークブック

タブの順番が重要だ — 経営者は最初のタブを開き、そこで止まることが多い。

1. **サマリー** — チャットのサマリーと同じ指標を、比較付きのきれいな表で
2. **指標グループごとに 1 タブ** — 班別売上、売掛金の滞留、人件費の内訳
3. **生データ** — 取得したものすべてを加工せず。経営者や顧問税理士が計算を検算できるように

ワークブックを使えるものにする書式のルール:

- ヘッダー行は太字で固定
- 金額は `#,##0"円"`、比率は `0.0%` — 生の小数のままにしない
- 差分は独立した列に。値のセルに詰め込まない
- 負の数は赤（または括弧）で、全タブ一貫して
- 各タブの末尾に、ソースと取得日時（JST）を書いたフッター行
- 税込／税抜をタブ名か見出しに明記する。一つのタブに混在させない

セルを手で組まず、スクリプトでワークブックを作る。速いし、来月もまったく同じに再実行できる。

## データが欠けているとき

指標を黙って省かない。行が欠けると、経営者が探し回るデータの不具合に読める。

```
**人件費率** — n/a（今回の実行では会計ソフトの給与関連科目を取得できませんでした）
```

それから、取得できなかったソースを末尾で一度だけ繰り返す:

```
今回取得できなかったもの: マネーフォワード クラウド会計の給与関連科目、Square（認証切れ）。
それ以外はすべて正常に取得しました。
```

「返ってこなかった」と「0 だった」は別物だ。全項目 0 の科目を返さない会計ソフト（`../../../shared/ledger-report-traps.md` 罠8）では、科目が存在して当期の動きがないなら 0円 と出し、ソース自体が落ちているなら n/a と出す。

## 途中期間

月初来の数字を丸ごとの前月と比べると、必ず急落に見える。同条件で比べるか、そう表示する:

```
**売上** — 9,870,000円、7月27日までの月初来（前月の同日まで: 9,140,000円、+8%）
```

途中期間を丸ごとの期間と並べて、そう言わないことは絶対にない。この一つの誤りが、問題のなかった数字で経営者を慌てさせてきた。
