# 求人票の構成ガイド

すべての求人票にこの構成を使う。目的は、仕事を理解したうえで自ら選んで応募する人を
集める求人票であって、人事の様式を埋めるだけのものではない。

---

## 推奨する構成

### 1. 冒頭の一文（2〜3文）
*なぜ*から始める — この募集がなぜあるのか、どんな課題を解くのか、会社が今どんな局面に
あるのか。応募者がスクロールの手を止めるのはここだ。

> 悪い例：「経験豊富な設備施工スタッフを募集しています。」
> 良い例：「さいたま市内の空調・給排水工事の受注が増え、現場を任せられる人がもう一人
> 必要です。段取りから引き渡しまで、自分の現場として持ってもらいます。」

### 2. 会社について（3〜4文）
短く、正直に、具体的に。何をしている会社で、誰に向けたサービスで、なぜそれが大事なのか。
流行り言葉は避ける。創業年数、施工実績、取引先の業種など、信頼につながる事実があれば
一文だけ入れる。

### 3. 仕事について（1段落）
入社 12 か月後にどうなっていれば成功かを書く。何を任され、何を仕上げ、何を変えているか。
これが次の業務内容の土台になる。

### 4. 業務内容（箇条書き 4〜7 項目）
動詞で始める。「〜を手伝う」ではなく「〜を担当する」で書く。網羅的な列挙は避け、最も
重要な 4〜7 項目に絞る。この欄は**職業安定法の必須記載事項**なので、「その他付随業務」
だけで済ませない。

### 5. 求める人物像（2 区分）
**必須：**
- 絞る。一行ごとにふるいになる。「これがない優秀な人を落とすか？」と自問し、答えが
  「いいえ」なら歓迎に回す。
- 「〜の経験がある」と書き、「〜に精通」は避ける。応募のハードルを下げ、かつ正確だ。
- 免許・資格は名称を正確に（普通自動車免許（AT 限定可）、第二種電気工事士 など）。

**歓迎（あれば尚可）：**
- あれば抜きん出るが、なくても落とさないもの。

### 6. 賃金・待遇（法定記載事項 — 省略不可）
賃金は月給・時給の額または幅で書き、**基本給・手当・固定残業代の内訳**を分ける（固定
残業代は時間数・金額・超過分の追加支給を明記）。賞与・昇給の有無、通勤手当、社会保険の
加入、年間休日数を並べる。**金額が提供されていなければ幅を創作せず、この欄を「掲載前に
要記入」と明示して未完成のまま渡す。** 原文の「なければ省く」は日本では使えない。

### 7. 応募方法
明快な一文。応募フォームのリンクかメールアドレス。手間をかけさせない。

## 職業安定法の法定記載事項（掲載前に全項目を確認する）

| 項目 | 書くこと |
|---|---|
| 業務内容 | 4 の箇条書き。**業務の変更の範囲**（将来担当し得る業務）も併記（2024年4月〜） |
| 契約期間 | 期間の定めの有無。有期なら期間・更新の有無・**更新上限**・**無期転換申込機会** |
| 試用期間 | 有無・長さ。期間中の労働条件が本採用後と異なるならその内容 |
| 就業場所 | 事業所の住所。**就業場所の変更の範囲**（転勤の有無、現場の地理的範囲） |
| 就業時間・休憩・休日 | 始業・終業、休憩、週休、年間休日数、時間外労働の有無 |
| 賃金 | 6 のとおり。基本給・手当・固定残業代の内訳 |
| 社会保険 | 健康保険・厚生年金・雇用保険・労災の加入 |
| 募集者名 | 会社名（法人格まで）。紹介・派遣なら雇用主を明示 |

雇用形態（正社員、契約社員、パート・アルバイト）は冒頭に明示する。業務委託は雇用では
ないので、求人票ではなく発注条件の明示（フリーランス新法）として別に扱う。

## 書き方の原則

**誰でも応募しやすい表現のチェックリスト：**
- 「即戦力」「体育会系」「バリバリ働ける」のような、内輪の合図や長時間労働をほのめかす
  語を避ける
- 経験で代替できるなら不要な学歴要件を書かない
- **性別を限定・想起させる表現を使わない**（「営業マン」→「営業スタッフ」、「主婦歓迎」→
  「家庭と両立したい方歓迎」）— 男女雇用機会均等法
- **年齢制限は原則不可**。例外事由（定年年齢を上限とする、長期勤続によるキャリア形成の
  ため若年者を無期雇用で募集する など）に当たるときだけ、理由を添えて書く
- 国籍を条件にしない。本籍・家族構成・宗教・思想・支持政党を応募条件に入れない
- 業界用語には一言説明を添え、平易な文にする

**長さ：** 本文 800〜1,500 字が目安。500 字未満は薄く、2,000 字を超えると読まれない。
ただし媒体の制限が優先だ — ハローワークの求人票は欄ごとに文字数が固定され、Indeed・
求人ボックス・engage は自由記述、タウンワークは短い定型が中心。

**媒体：** ハローワーク（無料）、Indeed、求人ボックス、engage、タウンワーク、マイナビ、
リクナビ、doda、Wantedly、自社サイト・SNS・紹介。掲載は経営者が行う。

**トーン：** 会社の声に合わせる。町の設備屋と上場企業では響き方が違う。迷ったら経営者に
聞くか、フェーズ2で見つけた既存の資料から推し量る。
