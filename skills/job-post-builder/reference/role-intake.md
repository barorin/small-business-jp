# 募集する仕事の聞き取り

調査や執筆を始める前に、フェーズ1で集めておくべきことのすべて。

本当に足りないものだけを、一問ずつではなく一つのまとまったメッセージで聞く。経営者が
すでにほとんどを話している — 「DocuSign で送って」のような希望も含めて — なら、抽出して
確認するにとどめ、聞き直さない。

**聞くのを避けるために項目を推測しない。** 賃金や資格についての誤った思い込みは、
一つの質問より高くつく。

---

## 項目

| 項目 | 何を得るか |
|---|---|
| 職種名 | 求人票に載せる正確な職種名 |
| 雇用形態 | 正社員、契約社員（有期）、パート・アルバイト、業務委託のどれか。業務委託なら求人票ではなく発注条件の明示（フリーランス新法）になるので、その場で伝える |
| 所属と役割 | 誰の下で、誰と働くか |
| 主な業務内容 | この人が日々担当する3〜5のこと |
| 必須の資格・経験 | 絶対条件：経験年数、特定の技能、免許・資格（例: 普通自動車免許、第二種電気工事士） |
| あれば尚可の資格・経験 | 望ましいが必須ではないもの |
| 就業場所と変更の範囲 | 事業所、現場直行直帰、在宅の可否。**将来の変更の範囲**（転勤の有無、他の業務への配置換えの可能性）も法定記載事項 |
| 就業時間・休日 | 始業・終業、休憩、週休、年間休日数、残業の有無、シフト制なら勤務パターン |
| 賃金 | 月給・時給の額または幅、固定残業代の有無（あるなら時間数と金額）、賞与・昇給の有無、通勤手当。法定記載事項なので必ず聞く。最低賃金との照合と既存従業員との均衡は経営者・社労士が確認するとフラグする |
| 試用期間・契約期間 | 試用期間の有無と長さ（3か月が多い）。有期なら契約期間、更新の有無、更新上限 |
| 社会保険 | 健康保険・厚生年金・雇用保険・労災の加入。週の所定労働時間で加入要件が変わるので、パートは労働時間と合わせて確認 |
| 既存の求人票・ひな形 | Google Drive、Microsoft 365、デスクトップに過去の版があるか聞く |
| 内定通知書の交付方法の希望 | 下記 |
| 選考の進め方 | 下記 |

## 内定通知書の交付方法の希望

書き始める前にフェーズ5と6の経路を確定させるため、フェーズ1で押さえる。

- **DocuSign で送る** — スキルが Chrome で DocuSign を開き、通知書をアップロードし、
  封筒を設定し、送信前の確認用に下書きとして保存する。労働条件通知書の電子交付は
  **本人が希望した場合に限る**ので、候補者の希望を確認済みかも聞く。
- **Word 文書のみ** — スキルは `.docx` として保存して止まる。郵送・手渡し・電子交付は
  経営者が行う。

## 選考の進め方

ここが肝心だ。面接ガイドは段階ごとに構成され、各段階に固有の質問セットが付く。聞くこと：

- 選考は何回・何段階か。
- 各段階は誰が担当するか。経営者、現場責任者、一緒に働く同僚、複数人。
- 各段階は何を見るか。仕事への向き合い方、技術の深さ、他部門との連携。
- 実技・課題（試し働き、作業サンプル、現場見学）はあるか。

経営者がまだ決めていなければ、職種のレベルと会社の規模に応じた妥当な既定を提案し、
確認してから進める。

### 従業員 25 名程度までの事業の既定

採用担当者も部門長の上司もいない。経営者が主導する2段階と実技を既定にする：

1. 20 分程度の電話または対面の一次面接
2. 実技・現場見学を兼ねた面接（試し働き）
3. 条件と入社日を詰める短い最終面談

### 従業員がもう少し多い会社の中堅担当者クラスの既定

| 段階 | 面接官 | 見るもの |
|---|---|---|
| 電話一次 | 採用担当（総務） | 意思疎通、最低限の適合、勤務条件の確認 |
| 部門責任者面接 | 部門責任者 | 業務の範囲、主体性、職種固有の深さ |
| 同僚面接 | 一緒に働くメンバー | 協働、仕事の進め方 |
| 実技・課題 | 現場の熟練者 | 技術・専門分野の深さ |
| 最終面接 | 経営者・役員 | 価値観、長期的な展望、条件の合意 |
