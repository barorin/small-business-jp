# 落とし穴

自信たっぷりに間違った成長助言を生む失敗パターン。経営者はこのパルスを見て本物の予算を動かすので、もっともらしい間違いはここでは金を失わせる。

---

## 落とし穴: 飽和しているチャネルへの増額を勧める

**なぜ重要か:** 広告費が増えながら獲得単価も上がっているなら、チャネルは届く相手を使い切りつつあるのであって、伸びているのではない。「効いているから、もっと使おう」は、このスキルが下しうる最も高くつく誤った判断だ。

### 悪い例

```
Meta広告から 47件のリード。29件から増加。予算を 50% 増やすことを推奨。
```

広告費は 9万円から 32万円に、獲得単価は 3,100円から 6,800円になった。件数が増えたのは広告費が増えたからで、効率は崩れている。

### 良い例

```
Meta広告の件数は増えたが、広告費が 3倍超になる間に獲得単価は 3,100円から 6,800円へ。
これは飽和であって、拡大ではない。予算は据え置き、増額の前にクリエイティブを直す —
あと 50% 足しても、おそらく 1件 9,000円のリードを買うことになる。
```

どちらの方向でも予算を勧める前に、必ず獲得単価を広告費と突き合わせる。

## 落とし穴: CRM の商談金額を売上として報告する

**なぜ重要か:** 加重パイプラインは見込みだ。本物の売上の隣に同じ書式で並べると、口座にある金のように読める。

### 悪い例

```
売上 — 2,140万円
```

実際は 860万円が請求済みで、1,280万円は進行中の商談。

### 良い例

```
売上 — 864万円（請求済み）
パイプライン — 進行中 1,280万円、加重 410万円（見込み。受注ではない）
```

見込みには毎回ラベルを付ける。経営者はこの数字で採用を決める。

---

## 落とし穴: 帰属をでっち上げる

**なぜ重要か:** キャンペーンの売上が追えないとき、推測で割り当てると、権威ある顔をした架空の回収率ができあがる。予算はその数字で動く。

### 悪い例

```
Meta広告の回収率: 3.4倍
```

その月の新規顧客がすべて Meta広告から来たと仮定して算出。

### 良い例

```
Meta広告: 広告費 32万円、リード 47件、1件 6,800円。売上の帰属は不明 —
CRM が成約した商談の流入元を記録していない。獲得単価は堅い。そのリードが
成約しているかが未解決の問い。流入元の記録をオンにすれば来月には答えが出る。
```

直し方つきの正直な空白は、自信ありげな偽の数字より役に立つ。

## 落とし穴: プラットフォームの数字と CRM の数字が食い違う

**なぜ重要か:** 広告プラットフォームは 60件の成果を主張し、CRM は 41件のリードを示す。これは正常だ — 計測期間も定義も違う。見栄えのよい方を選ぶと誤導する。

### 悪い例

大きい数字で、広告プラットフォームから来たからという理由で 60 を報告する。

### 良い例

```
広告プラットフォームは 60件の成果を報告。CRM が受け取ったリードのうち、流入元が
それになっているのは 41件。19件の差は通常の帰属の違い。CRM の数字を使う。
チームが実際に対応したのはそちらだから。
```

両方を報告し、差を名指しし、どちらをなぜ使ったかを言う。

## 落とし穴: 一つの商品が推移全体を支えている

**なぜ重要か:** 「売上 +12%」は広い健全さとして読まれる。一つの SKU がそのすべてを占め、残りの九つが横ばいか下落なら、事業は見出しが示すより脆い。

### 悪い例

```
売上 +12%。成長の仕組みは健全。
```

### 良い例

```
売上 +12%。ただし全部が一商品 — 夏のアイスコーヒーセットが +98万円。
ほかの商品はすべて横ばいか下落。見出しは本物だが、広がりはない。
```

最も動いた商品を除いても推移が残るかを必ず確認する。

---

## 落とし穴: ファネルの落ち込みを埋もれさせる

**なぜ重要か:** ファネルが最も失う段階は、たいてい手に入る中で最も価値の高い発見で、ほぼ常にどんな新キャンペーンより安く直せる。見出しの数字ではないから埋もれる。

### 悪い例

売上とチャネル構成で始め、段階ごとの転換率は途中の箇条書き一つで触れる。

### 良い例

一つの段階が流入の 70% 超を失っているなら、売上がどうであれ、それがパルス全体の見出しの一文になる。

---

## 落とし穴: 静かな月に三つの施策をひねり出す

**なぜ重要か:** パルスが毎回三つの緊急施策を出せば、経営者は施策が埋め草だと学び、読まなくなる。提案の信頼性こそが資産だ。

### 悪い例

```
1. 新しい広告チャネルの試験を検討する。
2. 価格を見直す。
3. 紹介制度を考える。
```

汎用で、パルスのどの数字にも根ざしていない。

### 良い例

```
1. 今週は急ぐことなし。仕組みは安定している。
   見ておく価値があるのは紹介の比率。何もしていないのに三か月連続で伸びている。
   来月、意図的に試す価値がある。
```

---

## 落とし穴: 経営者が使わないマーケティング用語

**なぜ重要か:** 読み手は経営者兼現場で、しばしば一人でマーケティング部門を兼ねている。ファネル用語は、パルスが他の誰かのために書かれたように感じさせる。

### 悪い例

```
トップオブファネルのベロシティは改善したが、MQL から SQL への転換は劣化した。
```

### 良い例

```
先月より新しい問い合わせは増えたが、本当の商談になったものは減った。
```

同じ発見。行動につながるのは一方だけだ。

## 日本固有の落とし穴

上の八つと同じ形で、日本の媒体・商習慣・暦が生む間違い。どれも数字の見た目は正しく、意味が違う。

### Yahoo!広告を忘れる

**なぜ重要か:** 日本の検索広告は Google 広告と Yahoo!広告の二本柱で、地域の「エアコン 修理」のような検索は Yahoo! 側にも相当量ある。Google 広告の CSV だけで「検索広告は好調」と書けば、検索の半分を見ていない。

**悪い例:** 「検索広告: 広告費 18万円、問い合わせ 31件。」 — Yahoo!広告の 14万円と 16件が入っていない。

**良い例:** 「検索広告: Google 広告 18万円で 31件、Yahoo!広告 14万円で 16件。合計 32万円で 47件。Yahoo! 側の問い合わせ単価は 8,750円で Google の 5,800円より高い — 予算配分の候補。」

「検索広告」と書くときは、両方を読んだか、片方しかないと明記する。

### LINE の友だち数を顧客数と混同する

**なぜ重要か:** LINE公式アカウントの友だち追加はクーポン目当ての一回限りが多く、ブロックも起きる。友だち数の増加を「顧客が増えた」と報告すると、リピートの数字が実態より良く見える。

**悪い例:** 「顧客基盤は +320人。LINE の友だちが 1,200人から 1,520人に。」

**良い例:** 「LINE の友だちは +320人（ブロック 110人を差し引いて純増 210人）。これは流入の勢いで、顧客数ではない。同じ期間の Shopify のリピート購入者は 84人で横ばい。」

友だち数・フォロワー数は流入の指標として、購入者数はネットショップ・POS の数字として、別の行に書く。

### 税込と税抜を混ぜる

**なぜ重要か:** Shopify や Square の売上は税込、会計ソフトの売上高は税抜が普通で、広告費の CSV はプラットフォームによって違う。混ぜると前期比が 10% ずれ、ROAS が一割膨らむ。

**悪い例:** 「売上 — 1,320万円、前月比 +9%」 — 前月は会計ソフトの税抜、今月は Shopify と Square の税込を合算していた。

**良い例:** 「売上 — 1,200万円（税抜）、前月比 -1% · Shopify・Square の税込額は税抜に換算して比較」

すべての金額に税込／税抜のラベルを付け、パルス内で一つに揃える。

### 祝日週の前週比を推移として読む

**なぜ重要か:** 年末年始、GW、お盆、月曜が祝日の週は、問い合わせも売上も暦の理由で動く。前週比の急落を「仕組みの不調」と書けば、経営者は存在しない問題を直しに行く。

**悪い例:** 「問い合わせ数は前週比 -35%。検索広告の不調が疑われる。」 — GW を含む週だった。

**良い例:** 「問い合わせ数は前週比 -35%。ただし GW 週で、前年の GW 週と比べると +6%。仕組みに変化はない。連休明けの週で改めて判定する。」

連休を含む週は前年の同じ連休週と比べ、見出しでそう言う。

### Googleビジネスプロフィールの表示回数を検索と地図で合算する

**なぜ重要か:** 表示回数は Google 検索と Google マップで別に集計され、動き方も違う。合算すると、検索順位が落ちたのを地図の伸びが隠したり、その逆が起きたりする。

**悪い例:** 「Googleビジネスプロフィールの表示回数 12,400回、前月比 +3%。ローカル集客は安定。」 — 検索の表示は -22%、地図の表示は +31% だった。

**良い例:** 「Googleビジネスプロフィール: 検索の表示 -22%、地図の表示 +31%。行動（経路検索＋電話タップ）は -8%。検索側で順位が落ちている可能性 — 『さいたま市 エアコン修理』の順位を確認する。」

表示回数は検索と地図を別の数字として書き、行動（経路検索・電話タップ・サイトクリック）を添える。
