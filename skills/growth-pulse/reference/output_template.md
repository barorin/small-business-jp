# 出力テンプレート

一枚。ストーリーが先、数字がその下、最後に三つの一手。

---

## 構成

```
## グロースパルス — <期間>

<一文: この期間が集客と販促の仕組みについて実際に何を語っているか。>

### 今週の数字

**売上** — <金額（税込／税抜）>、<増減> · <チャネル別の内訳を一行で>
**リード（問い合わせ）** — <件数>、<増減> · <最多の流入元>
**受注率** — <割合>、<増減>
**広告の回収** — <広告費>に対して <倍率> · <獲得単価と推移>。分母は <そのチャネルが届く売上>
**評判** — <点数>、<増減> · <異議申し立てまたは離反の兆候>

### うまくいっていること

- <具体的に、数字つきで>

### うまくいっていないこと

- <具体的に、数字と考えられる原因つきで>

### 今週やる三つのこと

1. **<施策>** — <なぜ。数字を引いて> · <いくらの価値か>
2. **<施策>** — <なぜ> · <いくらの価値か>
3. **<施策>** — <なぜ> · <いくらの価値か>

<付記: 今回取得できなかった取得元があれば。>
```

データのないセクションは省く。空の見出しを印字しない。

---

## 記入例

```
## グロースパルス — 7月

問い合わせ数は今年最多で、ファネルはそれを見積り段階で取りこぼしている。

### 今週の数字

**売上** — 1,380万円（税抜）、6月比 +4% · 紹介・リピート 61%、検索広告 24%、Web 直接 15%
**リード（問い合わせ）** — 112件、6月比 +38% · 検索広告（Google 広告＋Yahoo!広告）が最多で 47件
**受注率** — 11%、19% から低下
**広告の回収** — 広告費 32万円に対して 2.1倍 · 問い合わせ単価 6,800円、11,000円から低下。分母は検索広告経由の受注 67万円で、全社売上 1,380万円ではない
**評判** — Google の口コミ ★4.4、横ばい · ★2 の新規口コミ 1件、内容は「折り返しが遅い」

### うまくいっていること

- 検索広告がこれまでで最も良い成績。問い合わせ単価は 42% 下がって 6,800円になり、
  件数はほぼ倍増。6月12日の広告文の差し替え（「さいたま市 即日対応」）が原因とみられる。
- 紹介経由の売上は広告費ゼロで +22%。

### うまくいっていないこと

- 問い合わせが 38% 増えて売上は 4% しか増えていない。ファネルが取りこぼしている:
  68件が見積り段階に進み、成約は 12件。この一段階に成長が消えた。
- 初回返信の中央値は 31時間。検索広告からの問い合わせは夜間や休日にも届き、
  翌営業日まで放置されている。

### 今週やる三つのこと

1. **見積り後のフォローを直す。** 先月、見積りを出した 56件がどこにも行かなかった。
   平均受注額 12万円なら、その四分の一を拾うだけで約 170万円。このページで最大の数字。
2. **問い合わせにもっと早く返す。** 1件 6,800円で買った問い合わせに、初回返信まで 31時間。
   当日中の返信は、どんな新キャンペーンより受注率を動かす可能性が高い。
3. **検索広告の予算は今の水準で据え置く。** 成果は出ているが、まだ増やさない —
   もう一か月分のデータで、件数を増やしても 6,800円が保てるかが分かる。

今回取得できなかった取得元: Yahoo!広告（未接続 — CSV をエクスポートしてもらえれば
次回から加えます）。
```

形に注目する。見出しは問題を名指しする。施策は金額で順位付けし、やりやすさでは付けない。三番目の施策は意図的な「まだ何もしない」で、これは本物の提案だ。

---

## 正直な答えが「安定」のとき

緊張感を演出しない。穏やかな月は穏やかに読めるべきだ:

```
## グロースパルス — 7月

大きな動きなし。売上、問い合わせ数、受注率はいずれも 6月から数ポイント以内で、
評判に変化はない。

...

### 今週やる三つのこと

1. **今週は急ぐことなし。** 仕組みは安定している。見ておく価値があるのは紹介の
   比率で、何もしていないのに三か月連続で伸びている — 来月、意図的に試す価値がある。
```

毎週三つの緊急施策をひねり出すパルスは、経営者に読むのをやめることを教える。

---

## 祝日週のとき

年末年始・GW・お盆を含む週の前週比は、仕組みではなく暦の話になる。見出しでそう言い、前年の同じ連休週と比べる:

```
GW を含む週なので前週比は -35% だが、前年の GW 週比では +6%。仕組みに変化はない。
```

---

## データが欠けているとき

一度だけ、最後に名指しし、何をすれば直るかを言う:

```
今回取得できなかった取得元: HubSpot（認証の期限切れ — 再接続すればファネルの
転換率が戻ります）、Google 広告（ここには未接続 — キャンペーンの CSV をエクスポート
してください）。
```

ブリーフの途中でコネクタのエラーを表に出さず、欠けた取得元が一言もなくセクションを黙って消すことも許さない。
