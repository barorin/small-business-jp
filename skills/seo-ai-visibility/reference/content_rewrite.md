# コンテンツの書き換え

顧客が読んで分かりやすく、機械が読んで正確に引用されるページの書き方。この二つは、SEO 業界が認めるよりずっと多くの場合、同じものだ。

経営者の名前で何かを書く前に、[共有ボイスプロファイル](../../../shared/voice-profile.md)を読む。制作会社が書いたように読めるページは、経営者が避けたいものそのものだ。

---

## 構成

1. **最初の 2 文で質問に答える。** ページが何についてであれ、すぐ言う。機械は冒頭を引用し、人は冒頭を読んで、答えがなければ離脱する。
2. **次に具体。** 料金、日数、含まれるもの、含まれないもの、対応エリア。
3. **次に文脈。** なぜ重要か、作業はどう進むか、何を期待できるか。
4. **明確な次の一手を一つ。** 電話、予約、相談。

多くの中小企業のページはこれを逆にやる — 会社沿革が 3 段落、それから答え、電話番号はフッターに。

---

## 引用されやすい文とは

| こう書く | こうではなく |
|---|---|
| 「点検は 8,800円（税込）から、所要時間は約 1 時間です。」 | 「充実のサービスを納得の価格で。」 |
| 「さいたま市の大宮区・浦和区・中央区・北区と、上尾市・川口市に伺います。」 | 「関東一円、幅広く対応。」 |
| 「緊急対応は年中無休、通常 2 時間以内に現場に到着します。」 | 「困ったときに迅速・確実に対応。」 |
| 「2009年創業。建設業許可（管工事業）埼玉県知事（般-6）第〇〇〇〇〇号。適格請求書発行事業者。」 | 「長年の信頼と実績。」 |

型：確かめられる具体的な事実を、完全な文で。形容詞は引用されない — 機械が検証できることも、顧客が行動できることも何も言っていないからだ。

「地域No.1」「最安値」「必ず直ります」は根拠がなければ書かない — 景品表示法の優良誤認・有利誤認にあたり得る。美容・健康・食品を扱う事業では効果・効能の表現に薬機法もかかるので、書き換えの前にフラグを立てる。

## title と meta description

**title** — 全角 30 文字前後、一意で、ページが何かを言い、検索される言葉（地域名＋サービス名）を先頭に置く。

```
悪い例：  ホーム | 岡本設備工業 | 2009年創業・信頼の空調パートナー
良い例：  さいたま市のエアコン修理・空調工事 | 岡本設備工業
```

**meta description** — 80〜120 文字、人が書いたように読め、クリックする理由を含む。

```
悪い例：  岡本設備工業は、法人・個人のお客様に高品質なサービスと納得の
          価格で空調ソリューションをご提供しています。
良い例：  さいたま市・上尾市・川口市のエアコン修理、空調設備の設置・保守。
          点検 8,800円（税込）から。緊急対応は年中無休。2009年創業。
```

半角カナと機種依存文字（①、㈱、℡）は title・description に入れない。「エアコン」「Wi-Fi」の表記はサイト全体で一つに揃える。書き直した title と description は、経営者が CMS に貼り付けられるよう、ページごとにコピー用ブロックで渡す。

## 質問ページ

顧客は今、声に出して質問する。だから本当の質問を軸に組んだページは、検索でも AI でも成績が良い。

経営者が実際に受けている質問を使う。メール、受信箱、見積依頼、口コミから拾う。でっち上げた FAQ は、でっち上げた FAQ のように読める。

```
## エアコンの点検はいくらかかりますか？

家庭用の標準的な機種で 8,800円（税込）です。動作確認、熱交換器の
清掃、冷媒量の確認、近く故障しそうな箇所の書面報告までを含みます。
所要時間は約 1 時間。同じ住所の 2 台目は 5,500円（税込）です。

## 緊急のとき、どのくらいで来てもらえますか？

営業時間内なら通常 2 時間以内、時間外は当日中に伺います。その時間に
間に合わない場合は、お待たせするのではなく電話の時点でそうお伝え
します。
```

短い答えを先に、次に詳細。そしてこのセクションを `FAQPage` schema でマークアップする。内容が本当に FAQ だからだ。

## 拠点・エリアページ

本物のローカルページか、作らないか。市区名を差し替えただけの 10 ページは重複コンテンツだ — 検索エンジンは割り引き、AI は何も学ばない。

エリアページがその存在に値するのは、その土地に固有の真実があるときだ：そこで手がけた建物の種類、事務所からの到着時間、地元の施工事例、その自治体特有の届出や条例。

その市について言うべき固有のことがなければ、代わりにメインの対応エリアページに列挙する。薄いページより良い結果になる。

## 正直さのルールが効く場所

**経営者が確認していない事実を決して書かない。** 書き換えは創作ではない。ページを機能させるのは具体的な詳細であり、それが「それらしい数字で穴を埋めたい」という絶え間ない圧力を生む。

やり方は、一括で、一度だけ聞くこと：

```
このページを正しく書くために、6 つ確認させてください：

1. 標準点検の料金 — サイトには 8,800円（税込）とありますが、今も同じですか？
2. 本当に約束できる緊急対応の到着時間
3. 伺う市区町村と、伺わない市区町村
4. 建設業許可番号の正式な表記
5. 創業年 — 会社概要は 2009年、フッターは 2011年になっています
6. 土曜の営業時間 — サイトと Google の掲載が食い違っています
```

それから書く。答えが返ってこないところは、推測ではなく見える空欄を残す：「料金 要確認」は経営者に渡してよいものだ。公開ページの上のでっち上げた料金は、そうではない。

---

## 長さ

目標の文字数はない。質問に答えるまで書き、そこで止める。

薄いページが失敗するのは、何にも答えていないからであって、短いからではない。400 字のページを埋め草で 2,400 字に水増しすれば、読み手にも機械にも悪くなる。
