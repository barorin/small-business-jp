# 診断チェックリスト

クロールで確認するすべての項目と、返ってきた所見の並べ方。

コネクタなしで、公開されているどんな Web サイトにも使える。ページを取得し、HTML を読み、そこにあるものを記録する。

---

## 取得するもの

| 対象 | 理由 |
|---|---|
| トップページ | title、主要な訴求、構造化データ、ナビゲーション |
| 各サービス・カテゴリページ | 顧客が検索する言葉で上位に出るべきページ |
| 店舗・拠点・対応エリアのページ | ローカル検索は、これらが存在し互いに区別できることに依存する |
| お問い合わせ・会社概要 | 営業時間、住所、対応エリア、許認可・資格が載る場所 |
| 特定商取引法に基づく表記（ネットショップ） | EC では法律上必須。事業者名・住所・電話・送料・返品条件が正しいか |
| ブログ・お知らせの最近の項目 | コンテンツが現在のものか、本当の質問に答えているか |
| `/robots.txt` | クローラーのルール。AI クローラーも含む |
| `/sitemap.xml` | そもそもページが発見可能か |
| `/llms.txt` | たいてい無い — それ自体が所見 |

到達できなかったものは名指しする。メインメニューからリンクされたページの 404 は、それ自体が所見だ。

日本語のみのサイトに hreflang は不要 — 多言語設定を勧めない。英語ページが本当にある場合だけ話題にする。

## 技術チェック

| 項目 | 合格の姿 |
|---|---|
| robots のルール | 検索や AI のクローラーをうっかり止める一括の Disallow がない |
| サイトマップ | 存在し、最新で、実在する URL を列挙し、robots.txt から参照されている |
| 常時 SSL（HTTPS） | サイト全体。http からのリダイレクトあり、混在コンテンツなし |
| JavaScript なしで描画される | 主要コンテンツが素の HTML レスポンスに含まれる |
| canonical タグ | 1 ページに 1 つ、意図的に統合する場合を除き自分自身を指す |
| スマホ表示 | スマホの幅で読め、タップできる。日本の検索流入は大半がスマホ |
| 表示速度（Core Web Vitals） | 通常の回線で主要コンテンツが数秒以内に見える。LCP・CLS が Google サーチコンソールで「不良」になっていない |
| 文字コード | UTF-8 が宣言され、文字化けしない。古い Shift_JIS のページが混在していない |
| リンク切れ | メインナビゲーションと、売上に直結するページにはゼロ |
| 重複コンテンツ | 10 の拠点ページで市区名だけを差し替えた同じ段落になっていない |

## ページ単位のチェック

| 項目 | 合格の姿 |
|---|---|
| title タグ | 存在し、一意で、全角 30 文字前後。ページが何かを言い、検索される言葉（地域名＋サービス名）を先頭に置く |
| meta description | 存在し、一意で、80〜120 文字。人が書いたように読める |
| H1 | ちょうど 1 つ、ページの内容と一致 |
| 見出しの順序 | H2・H3 が筋の通った入れ子。見た目で選ばれていない |
| 画像の alt テキスト | 画像を説明している。キーワードの羅列ではない |
| 内部リンク | 売上に直結するページにトップから 2 クリックで到達できる |
| 文字数 | 質問に答えるのに足りる量。目標数値はない — 薄さは症状であって病気ではない |
| 連絡先情報 | 名称・住所・電話番号が全ページで一致（NAP の統一） |
| 表記ゆれ | 「エアコン」と半角カナ、「Wi-Fi」と「WiFi」、「さいたま市」と「埼玉市」が混在していない。機種依存文字（①、㈱、℡）を使っていない |
| 地域名＋サービス名 | 顧客が実際に打つ組み合わせ（「さいたま市 エアコン修理」）が title・H1・本文に自然に入っている |
| 構造化データ | LocalBusiness、Product、FAQPage などの JSON-LD が、目に見える内容と一致している |

## コンテンツチェック

- 各ページは、顧客が実際に打つ、または声に出して聞く質問に答えているか？
- 顧客が必要とする事実 — 価格の目安、対応エリア、営業時間、含まれるもの — が平易に書かれているか、宣伝文の中に埋もれていないか？
- サイト内の別の場所と矛盾していないか？ 電話番号が 2 つあるのはよくあり、高くつく。
- 古くなっていないか？ 価格、スタッフ、対応エリア、コピーライトの年。
- 実際のサービスごとにページがあるか、それとも 1 ページにすべてを列挙しているか？
- 会社概要ページに、事業者名（法人格を含む正式名称）・所在地・代表者・設立年・許認可（建設業許可番号、古物商許可番号など）・適格請求書発行事業者の登録番号（T＋13 桁）が載っているか？ 機械も顧客もここで事業の実在を確かめる。
- 価格は税込の総額で表示されているか？（総額表示義務。「1,620円（税込）」のように書く）
- ネットショップに「特定商取引法に基づく表記」があり、送料・配送日数・返品条件が商品ページからたどれるか？

## サイト外チェック

| 情報源 | なぜ重要か |
|---|---|
| Googleビジネスプロフィール（MEO） | オーナー確認済み、完成、営業時間が正しい、カテゴリが適切、写真と投稿が最近のもの、口コミに返信している |
| 業界ディレクトリ・ポータル | 業種別の掲載（くらしのマーケット、ミツモア、食べログ、ホットペッパー、エキテン など）。AI も検索も読む |
| 口コミサイト | 存在と最近の投稿。星の数だけではない |
| ローカルサイテーション | 名称・住所・電話番号がサイトと一字一句一致。Yahoo!プレイス、Apple マップ、商工会議所の会員名簿、メーカーの施工店検索 |

掲載情報の食い違いは、検索でも AI でも事業が誤って説明される最大級の原因だ。

Yahoo! JAPAN は Google の検索エンジンを使っている — Google 向けの修正がそのまま効く。「Yahoo! 対策」を別の作業として提案しない。Bing は別のインデックスなので、Bing ウェブマスターツールへのサイトマップ送信だけは確認する。

## 採点

すべての所見を 2 つの軸で採点する。まず影響で並べる。

| 影響 | 意味 |
|---|---|
| 高 | 発見を完全に妨げる、または事業について誤ったことを述べている |
| 中 | ページの成績や、理解の正確さを下げる |
| 低 | 本当の改善だが、急がない |

| 手間 | 意味 |
|---|---|
| 小 | 1 ファイル、1 項目、1 時間以内 |
| 中 | ページの書き換え、または一括の修正 |
| 大 | 構造的 — 新しいページ、テンプレートの変更、制作会社への依頼 |

たいていの小規模サイトで成り立つ順序：

1. うっかり Disallow されたクローラーのブロック解除 — 影響 高、手間 小
2. JavaScript でしか描画されないコンテンツの修正 — 影響 高、手間はさまざま
3. 誤った事実・矛盾した事実の訂正 — 影響 高、手間 小
4. schema.org の構造化データの追加 — 影響 高、手間 小
5. llms.txt の公開 — 影響 中、手間 小
6. Googleビジネスプロフィール等のオーナー確認と完成 — 影響 高、手間 中
7. title と meta description の修正 — 影響 中、手間 小
8. 薄い、または答えていないコンテンツの書き換え — 影響 高、手間 大

## 診断の報告

本文には所見 5 件。残りは付録に。

```
岡本設備工業 — 検索・AI検索 露出診断
2026年7月27日 クロール · 14 ページ · okamoto-setsubi.example.jp

一行で言うと：サイトは人が読む分には問題ないが、robots.txt の 1 行で
AI クローラーがブロックされ、構造化データがどこにもないため、AI は
事業の基本的な事実を確認できない。

この 5 件を、順に直す：

1. robots.txt が GPTBot と ClaudeBot をブロック       影響 高 · 10 分
2. schema.org のマークアップがどのページにもない       影響 高 · 1 時間
3. 対応エリアが「埼玉県内」のみ — 市区名がない          影響 高 · 30 分
4. Googleビジネスプロフィールの営業時間が誤り           影響 高 · 15 分
5. llms.txt がない                                      影響 中 · 20 分

付録にあと 9 件。急ぎのものはない。

確認できなかったもの：/mypage の顧客ポータルはログインの先にある。
```

**総合スコアは出さない。** 一つの数字は、存在しない競合の数字との比較を招き、どの修正が重要かを隠す。
