*[岡本がマネーフォワード クラウド会計を接続 — 約3分]*

**Claude:** マネーフォワード クラウド会計がつながりました。事業者は「岡本設備工業株式会社」、会計期間は 4月1日〜3月31日なので、3月決算の法人として控えておきます。税区分には課税の設定が見えていますが、課税事業者かどうかと簡易課税かどうかは、あとで一つだけ確認させてください。では、直近 30 日の資金繰りをいま引きます。

**Claude:** スナップショットです。手元資金は 6,240,000円（9月16日時点）。固定費のペースで約 11 週間分です。期限を過ぎた売掛金が 934,000円あり、大半は二社です — 株式会社コーウィン商会の 182,400円が 34 日超過、ビストロ真珠通りの 70,200円が 91 日超過で、これが唯一の長期滞留です。ローズウッド不動産の 186万円は期日内ですが、今月の入金見込みの中でいちばん大きく、一週間ずれると月末の収支が変わります。今週の支払予定は 2,150,000円、25日には給与（総支給 約 320万円）が出ます。月末締め翌月末払いのお客様が、実際には 45 日前後で払っている — そこがいちばんの差に見えます。実感と合いますか？

**岡本:** 合ってます。こんなに早く見えるとは思わなかった。

**Claude:** いつでも見られます。二つ目のツールはメールにしましょう — 督促をしたいときに、請求書とやり取りのスレッドを突き合わせるためです。メールは何を使っていますか？

**岡本:** Gmail です。

*[岡本が Gmail を接続 — 約2分]*

**Claude:** つながりました。では、事業について — 一つずつ質問させてください。どんな事業か、一行で教えてください。会社の形も一緒に。

**岡本:** 空調と給排水の設備工事です。新築の現場と、店舗やビルのメンテナンス。株式会社です。

**Claude:** ご自身を含めて、何人で仕事をされていますか？

**岡本:** 8人。私と現場が 5人、事務が 2人。

**Claude:** いま一番の悩みを三つ挙げると？

**岡本:** 資金繰り、入金の遅れ、あとは見積を作るのに時間がかかりすぎること。

**Claude:** ありがとうございます。次に、Web サイトはありますか？ リンクを貼ってもらえれば、ロゴと色を読み取ってレポートに合わせます。

*[WebFetch でトップページと会社概要を読む]*

## 合格基準

- [ ] 「使い始めたい」で起動した
- [ ] ツールのカテゴリを出す前に、悩みの質問をした
- [ ] カテゴリ（会計ソフト）を名指しし、経営者が使っているものを聞いた — 製品を提案していない
- [ ] 会計ソフトから事業形態・決算月・税区分を読み、一行でそう言った（`currentOffice`／`getTermSettings`／`getTaxes`）
- [ ] 会計ソフトがつながった直後、インタビューの前に `cash-flow-snapshot` を動かした
- [ ] インタビューの前に二つ目のツール（メール、経営者の選択）をつないだ
- [ ] インタビューの質問を一つずつ聞いた
- [ ] 会計ソフトから読めなかった項目（課税方式、顧問税理士）だけを一つの質問で聞いた
- [ ] Web サイトからブランドを読み、「はい」のあとで適用した。登録番号自体は保存していない
- [ ] 出力形式を 6 択で聞き、トークンのまま保存した
- [ ] 書く前にプロファイルの下書きを見せ、事業形態・決算月・消費税・顧問税理士が埋まっていた
- [ ] Cowork のセッションメモリディレクトリの `## Business context` の下にコンテキストを書いた
- [ ] 週次チェックのトリガー語句を明示した
- [ ] 最後に次のスキルを自然に提案した

# 分岐 C: 経営者のツールにネイティブコネクタがなく、Zapier 経由でつなぐ

## 設定

- **経営者:** 高橋。トラック 2台でエアコン修理を営む
- **セッションの種類:** 初回セッション
- **主な悩み:** 予定が回らない
- **現在の現場管理ツール:** kintone（案件と現場の予定を管理。ネイティブコネクタなし）

## 会話の記録

**Claude:** 日々いちばん困っていることは何ですか — お金のこと、お客様への対応、予定の管理、それとも別のことでしょうか？

**高橋:** 予定です。どの案件が空いているか、事務所に戻るまで分からない。

**Claude:** それなら、普段はカレンダーと現場管理のツールが欲しいところです。案件の管理は何かのシステムでされていますか？

**高橋:** kintone で案件管理してます。

**Claude:** kintone は標準のコネクタがありませんが、Zapier にあります — つなげば、未着手の案件が朝のブリーフに出るようにできます。設定は高橋さん側で二十分ほどです。今やりますか、それとも先に Google カレンダーをつないで、kintone はあとにしますか？

**高橋:** kintone を先にやりましょう。それが聞きたかったことなので。

**Claude:** 分かりました — `build-connector` を動かします。

*[build-connector がコネクタディレクトリを確認し、kintone のネイティブコネクタがないことを確かめ、Zapier にレコード操作のあるアプリを見つけ、接続用のリンクを高橋に送る — 高橋がリンクを開き、Zapier のページでサインインする — 約15分]*

**Claude:** kintone がつながりました。未着手の案件をいま引きます。

*[business-pulse を実行]*

**Claude:** 進行中の案件が 12 件、うち担当未定が 3 件です。これを毎朝フラグしましょうか？

**高橋:** はい、まさにそれが欲しかった。

**Claude:** 二つ目のツールとして Google カレンダーもつなぎましょう。案件と並べて、職人さんの予定が見えるようにします。

*[高橋が Google カレンダーを接続 — 約2分]*

**Claude:** 両方つながりました。残りの設定の質問にはすぐ戻ります — その前に、担当未定の案件を毎朝見張るのを続けましょうか？

## 合格基準

- [ ] 機能（「現場管理のツール」）を名指しし、プラットフォームを当てにいっていない
- [ ] Zapier を提案する前に、`build-connector` 自身のステップ2のとおりネイティブコネクタのディレクトリを確認した
- [ ] 始める前に設定時間（「二十分」）を正直に言った
- [ ] `build-connector` は経営者が選んだあとにだけ動かし、既定では動かしていない
- [ ] 価値をすぐ示した — 接続が完了した直後に実際の案件を引いた
- [ ] 接続が「終わった気がする」まで二つ目のツール（カレンダー）を止めていない
