# HubSpot のフィールドと活動タイプ

`crm-autopilot` スキルが読み書きする HubSpot のオブジェクト、プロパティ、活動タイプ。ここに挙げたフィールドだけがこのスキルの対象で、HubSpot のそれ以外には触れない。

## 連絡先 — 書き込み

| フィールド    | 用途                                                                                   |
|---------------|----------------------------------------------------------------------------------------|
| `email`       | 検索と重複排除の主キー。作成時は必ず設定する。                                          |
| `firstname`   | メール署名またはカレンダーの招待から取れれば設定する。不明なら空欄のまま。              |
| `lastname`    | メール署名またはカレンダーの招待から取れれば設定する。不明なら空欄のまま。              |
| `company`     | メール署名のドメインまたはカレンダーの所属組織から取れれば設定する。                    |

これ以外の連絡先プロパティは書き込まない。担当者、ライフサイクルステージ、リードソースは経営者が管理するフィールドであり、上書きしない。

## 連絡先 — 読み取り（検索用）

| フィールド    | 用途                                                               |
|---------------|--------------------------------------------------------------------|
| `email`       | 検索キー。大文字小文字を区別しない完全一致。                        |
| `firstname` · `lastname` · `company` | あいまいさの解消時に経営者へ表示する。        |
| `hs_object_id`| 商談や活動との関連付けに使う。                                      |

## 商談 — 読み取り（整備と特定のすべての経路）

| フィールド                  | 用途                                                     |
|-----------------------------|----------------------------------------------------------|
| `dealname`                  | 経営者へ表示。メールの件名や打ち合わせのテーマとのあいまい一致に使う |
| `dealstage`                 | 整備中は読み取り専用。相違はフラグを立てるだけで変更しない |
| `amount`                    | 整備中に読む。直近のメールや打ち合わせが変更を示唆すればフラグ |
| `closedate`                 | 整備中に読む。古ければフラグ                              |
| `hs_next_step`              | 読み取り、整備中は更新を提案する                          |
| `hubspot_owner_id`          | 経営者へ表示。変更しない                                  |
| `notes_last_updated`        | 止まっている商談の検出に使う。商談オブジェクトで HubSpot が「最終活動日」と表示するものがこれ。`hs_lastactivitydate` というプロパティは存在しない。探さない |
| 関連付けられた連絡先        | 直近のメールや打ち合わせの参加者が商談に載っているかの判定に使う |

## 商談 — 書き込み（整備の経路のみ、承認付き）

| フィールド      | ルール                                                           |
|-----------------|------------------------------------------------------------------|
| `hs_next_step`  | 更新を提案する。経営者の明示的な承認があるときだけ書き込む        |
| `closedate`     | 更新を提案する。経営者の明示的な承認があるときだけ書き込む        |
| `amount`        | 更新を提案する。経営者の明示的な承認があるときだけ書き込む        |
| 連絡先の関連付け | 不足している商談参加者の追加を提案する。承認があるときだけ書き込む |

整備中に `dealstage`、`pipeline`、`hubspot_owner_id`、およびカスタムプロパティを**書き込まない**。これらは経営者が管理する。

## 活動 — 書き込み

| 活動タイプ                     | 使う経路       | 設定するフィールド                                                       |
|--------------------------------|----------------|--------------------------------------------------------------------------|
| メール（`EMAIL`）              | メールの経路   | `hs_email_subject`（スレッドの件名）、`hs_email_text`（要約。スレッド全文ではない）、`hs_timestamp`（最新メッセージの日時）、関連付ける連絡先と商談 |
| 電話（`CALL`）                 | 電話の経路     | `hs_call_title`（予定のタイトル）、`hs_call_body`（要約）、`hs_call_duration`（カレンダーから）、`hs_timestamp`（予定の開始時刻）、関連付ける連絡先と商談 |
| メモ（`NOTE`）                 | 整備の経路     | `hs_note_body`（フィールド更新に収まらない、後で確認すべき事項のフラグ用） |

HubSpot 標準のエンゲージメント語彙を使う。独自の活動タイプを創作しない。

## 関連付けのルール

- すべての活動は商談と、少なくとも1件の連絡先の両方に関連付ける。
- 活動の記録中にその場で連絡先を作成した場合は、同じ操作の中で商談にも関連付け、連絡先と商談の両方のタイムラインに活動が表示されるようにする。
- 活動の記録の流れの中で、そのメールスレッドや打ち合わせに実際に参加していない連絡先を商談に関連付けない。
