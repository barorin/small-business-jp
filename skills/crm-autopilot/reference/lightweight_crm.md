# 簡易 CRM

CRM をまったく持っていない経営者のために。この規模の事業者の多くがそうだ。「HubSpot を契約してください」は答えにならず、そこで止まればこのスキルは役に立たなくなる。

スプレッドシートまたは Notion に CRM を作り、まったく同じやり方で維持する。

---

## 置き場所

**Google スプレッドシートまたは Excel** — 既定。どの経営者でも開けて、共有でき、持ち出せる。

**Notion** — すでに使っているなら。メモには向くが、数値には向かない。

**Monday.com** — すでに使っているなら。この3つの中で最も強い。ボードのアイテムがレコードとして
機能し、列単位の更新ができ、連絡先のタイムラインにメール・電話・打ち合わせ・メモがすでに入る。
読み書き両方。経営者が毎日 Monday.com にいるなら、開くのを忘れるシートを作るより、
そのボードを維持するほうがよい。

**ローカルファイル** — 何も接続されていないとき。それでも機能する。

一度聞いたら、それ以上聞かない。

---

## 構造

4つのタブ。増やしたくなっても我慢する。列が増えるほど古くなる列が増え、シートが宿題のように感じられる。

### 連絡先

| 列 | 備考 |
|---|---|
| 会社名 | |
| 部署・役職 | |
| 担当者名 | |
| 敬称 | 「様」が既定。「先生」「御中」など先方に合わせる |
| 電話 | |
| メール | |
| 名刺交換日 | 初回接触日。日付 |
| 最終接触日 | 活動を記録するたびに自動更新 |
| 備考 | |

### 商談

| 列 | 備考 |
|---|---|
| 商談名 | 経営者がすぐわかる短い名前 |
| 会社名 | |
| 担当者名 | |
| 商談金額（税抜） | 消費税を含めない。表示形式は `#,##0"円"` |
| ステージ | 4つに絞る：新規、見積提出、受注、失注 |
| 次回アクション | 最も重要な列 |
| 次回期日 | |
| 最終接触日 | 自動更新 |
| 流入経路 | どうやってこの会社を知ったか（紹介、Web 問い合わせ、展示会、既存取引先 など） |
| 備考 | |

**ステージは4つ。8つではない。** CRM を持っていない経営者にパイプラインの分類体系は要らない。次に何をするかがわかればよい。ステージが増えるほど、間違ったステージに置かれたままのレコードが増える。

### 活動

| 列 | 備考 |
|---|---|
| 日付 | 起きた日。記録した日ではない |
| 種別 | メール、電話、訪問・打ち合わせ、メモ |
| 担当者名 | |
| 商談 | |
| 要約 | 3〜5行 |
| 次回アクション設定 | 有 or 無 |

追記のみ。履歴を編集しない。このタブは、何を合意したか思い出せないときに経営者が頼る記録だ。

### 待ち行列

4つ目のデータではなく、フィルタ表示。次回アクションがない、または次回期日を過ぎた進行中の商談すべて。経営者が実際に開くタブはここだ。

---

## 維持の仕方

HubSpot の経路と同じ。同じモード、同じ承認ゲート、同じルール。

- メール、カレンダー、文字起こしから活動を記録する
- 最終接触日を自動で更新する
- フィールドの変更は提案する。ステージと金額は承認なしに書き込まない
- 止まっている商談にフォローアップを下書きする
- 待ち行列を最新に保つ

唯一の本当の違いは、連絡先の特定が API 検索ではなく行の一致になること。まずメールアドレスで、次に担当者名と会社名で一致させる。あいまいなら推測せず聞く。誤って統合した行を元に戻すのは、CRM よりスプレッドシートのほうが難しい。

---

## 紹介の仕方

格下げとして提示しない。多くの経営者にとって、パイプラインが頭の中以外の場所に初めて存在する瞬間だ。

```
CRM が接続されていないので、スプレッドシートに作りますね。タブは4つ。
連絡先、商談、活動、それから「次のアクションが必要なもの」の待ち行列です。

おもちゃではありません。HubSpot と同じように最新に保ちます。電話やメールを
自動で記録し、商談が止まったらフォローアップを下書きし、次のアクションが
ないものにはフラグを立てます。将来ちゃんとした CRM に移るときも、そのまま
きれいにエクスポートできます。
```

最後の一文が大事だ。経営者がスプレッドシート運用を避けるのは、そこに閉じ込められるのを恐れるからだ。

---

## 移行を勧めるタイミング

データがそう言っているときだけ。そして一度だけ：

- 進行中の商談がおよそ 150 件を超えた
- 同時に編集する必要のある人が2人以上になった
- シートではできない集計や分析を求め始めた

```
進行中の商談が 180 件になって、鈴木さんも編集していますね。このあたりが、
スプレッドシートの手間が節約分を上回り始めるところです。HubSpot を
検討する価値があります。ここにあるものはそのまま取り込めます。
```

一度だけ言う。繰り返さない。CRM を使わないと決めた経営者にはたいてい理由があり、しつこく勧めることで役に立つスキルが煩わしいものになる。
