# 定期モード

定期スイープ。これがあって、このスキルは「経営者が思い出して使うツール」から「CRM を自分で最新に保つツール」になる。

---

## 1回の実行で行うこと

1. 前回実行以降のすべてを取得する。社外の連絡先との送受信メール、終了したカレンダーの予定、新しい通話の文字起こし
2. それぞれを連絡先と商談に特定する
3. 活動を記録する
4. 構造化フィールドを抽出し、更新を提案する
5. 止まっている商談を見つけ、次の一手を下書きする
6. 次のアクション待ち行列を更新する
7. 経営者の判断が必要なものを報告する

実行時刻を記録し、次のスイープがどこから始めればよいかわかるようにする。同じ打ち合わせを二重に記録するのは目に見える誤りで、経営者が頼りにする記録を汚す。

---

## 通話の文字起こしからの抽出

このスキル全体で最も価値の高い入力。録画された営業電話には、経営者が3日後に記憶を頼りに、しかも不正確に入力するはずだったことがすべて入っている。

次を抜き出す：

| フィールド | 何を探すか |
|---|---|
| 次のアクション | 何をいつまでに、と合意したか。たいてい最後の2分で言われる |
| 次のアクションの担当 | 経営者側か顧客側か |
| 予算の手がかり | 口にされた数字はすべて。ついでの一言でも |
| 時期 | 日付、季節、「今期中に」「年度内に」 |
| 反論 | 何に難色を示したか。最も役に立つフィールドであることが多い |
| 他の人物 | 通話にいなかったのに名前が挙がった人。たいてい決裁者だ |
| 言及された競合 | 他にどこと話しているか |

**反論は一言一句そのまま引用する。** 言い換えると、役に立っていた部分が失われる。「価格ではなくて、工場を2日止めないといけないのが問題なんです」は経営者が解決できる具体的な問題だ。「導入に懸念あり」はそうではない。

要約は3〜5行で書く。文字起こしは残しておく。読まれるのは要約だ。

```
通話要約 — ローズウッド不動産、7月27日、34分

田中様が対象6棟すべてを確認。棟ごとではなく一括の保守契約を希望。
予算の手がかり：「前回は 800万くらい払った」（それは2棟分で、6棟分ではない）。

反論、本人の言葉：「上に通しにくいのは、また業者の切り替えになる点です。
前回の切り替えが大変だったので」。

次のアクション：岡本が水曜までに提案書を送付。田中様は決定前に佐藤部長
（施設管理部長、通話には不参加）に共有する。
```

この要約のすべてが、経営者の次の行動を変えるか、商談が決まらないかもしれない理由を説明している。

## 止まっている商談を見つける

14 日以上活動がない、または完了予定日を過ぎてまだ進行中の商談が「止まっている商談」だ。

何がかかっているかで並べる。金額が先、次に沈黙の長さ。経営者は止まっている商談3件なら動くが、20件の一覧は無視する。

**フラグを立てるだけでなく、次の一手を下書きする。** フラグは仕事を増やす。下書きは仕事を減らす。

各下書きを最後に実際に起きたことに根拠づける。最後のやり取り、何を約束したか、何が未解決か。「先日はありがとうございました。その後いかがでしょうか」は汎用版で、反応が悪い。「切り替えの時期について佐藤部長にご確認いただく件、その後いかがでしょうか」は本物のメッセージだ。

下書きが経営者の文体になるよう[共有の文体プロファイル](../../../shared/voice-profile.md)を読む。すべて承認を待つ。

---

## 次のアクション待ち行列

進行中の商談すべてに3つが必要だ。担当者、次のアクション、期日。どれかが欠けている商談が静かに消えていく。

それを表に出すことが定期実行の価値の大半だ：

```
次のアクション未設定 — 止まっていく商談はこれ：
  藤本商事         1,400,000円   最終活動 7月11日
  大和パーク管理   3,300,000円   最終活動 7月19日
```

2行で、経営者は1分で両方を直せる。

---

## 定期実行の報告

経営者の判断が必要なものから始める。記録した全件の一覧で始めない。それはノイズに読め、読み飛ばす癖をつけさせる。

```
## CRM — 月曜以降

### 判断が必要

  止まっている商談3件にフォローアップを下書き — ローズウッド不動産、
  コーウィン商会、大和パーク管理。確認して送りますか？

  藤本商事の完了予定日（7月18日）を過ぎてまだ進行中です。日付を延ばすか、
  失注にするか？

### 自動で記録済み

  メール 11件 · 打ち合わせ 4件 · 通話の文字起こし 2件（商談 9件）

### 提案するフィールド更新

  ローズウッド不動産  次のアクション：水曜までに提案書（木曜の通話より）
  コーウィン商会      予算：約 140万円 の言及あり（火曜のメールより）

### 次のアクション未設定

  藤本商事 1,400,000円 · 大和パーク管理 3,300,000円
```

経営者は最初の節を読んで動く。その下は確認したいときのためにある。

---

## 頻度

毎日はたいてい多すぎる。新しい活動が足りず、報告がノイズになって経営者が開かなくなる。

週2回か週1回がほとんどの事業に合う。実際に顧客と話す頻度に合わせる。

初期設定で一度聞き、その後は触れない：

```
毎週月曜、それとも週2回にしますか？ ほとんどの方は週1回で十分です。
毎日だと空の報告ばかりになりがちです。
```

---

## 定期モードが単独でしてはならないこと

- 商談ステージの変更。経営者が他者に報告する予測の元になる。
- 商談を完了または失注にする。
- 商談を作成する。
- フォローアップを送信する。
- 何かを削除する。

この一覧のすべては提案して待つ。定期実行の要点は、経営者が1週間放置しても取り返しのつかないことが何も起きない点にある。
