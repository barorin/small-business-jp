# 実例 — 岡本設備工業、6月の「梅雨前エアコン点検キャンペーン」

岡本 亮さんは、さいたま市で空調・給排水設備工事の岡本設備工業（株）を営んで
いる。8名（現場 5名、事務 1名、経営者夫婦）、月商は約 1,400万円。Canva Pro が
接続済み。Shopify はない（小売ではなく工事・保守のサービス業）。HubSpot は
Starter プランなのでソーシャル投稿への準備は使えず、CSV の経路を使う。
LINE公式アカウントは `build-connector` で接続していないので手動投稿用コピーで渡す。

声プロファイルは作成済みで、`../../../../shared/voice-profile.md` にあるもの：
短い文、「工事」「点検」と言い「ソリューション」「ご提案」とは言わない、
「ぜひお気軽にお問い合わせください」は使わない、結びは「岡本」の姓のみ。

## 1回目 — 継続カレンダー

```
経営者: 「インスタが3か月止まってます。梅雨前の点検キャンペーンを6月に
やりたいので、また投稿を回してもらえますか。対象はさいたま市の店舗と
オフィスです。」
```

既存のカレンダーを開く。まだないのでそう言い、何かを下書きする前に投稿
頻度を決める：

```
まだ何も記録がないので、これが最初のカレンダーです。

現場 5名と事務の方がいる規模なら、週3本は現実的で、週2本なら無理が
ありません。週2本から始めて、定着したら3本目を足すのをお勧めします。
いかがですか？
```

岡本さんは 30日間、週2本、Instagram と LINE公式アカウントを選ぶ。投稿 8本と、
保守契約の更新案内のメール 1通、店舗・オフィスに手渡しする A4 チラシ 1枚。

パス列が仕事をした状態でカレンダーを提示する：

テキストのみです。これで確定してよいですか？

## 生成予算

```
このバッチの生成予算:
  Canva 行:            7
  1行あたりの候補数:   3
  デザイン総数:        21
  API コール（概算）:  約105

Canva の上限は毎分 100 リクエストです。1行ずつ 30 秒の間隔を空けて
回すと、約 2 分で終わります。進めてよいですか？
```

岡本さんは既定のまま「はい」。セッション中は候補 3 で固定する。

## スロットの棚卸し — 最初の問題が出たところ

6月9日の実績投稿は、清掃前後の2画像テンプレートを使う。岡本さんが送って
きた写真は1枚。

```
清掃前後のテンプレートには画像スロットが 2 つあります — Before_Image と
After_Image。いただいた写真は 1 枚（omiya_after.jpg）です。Before_Image
はどうしますか？

  1. 清掃前の写真を送ってもらう
  2. この投稿は1画像のテンプレートに変える
```

清掃前の写真が見つかる。両方のアップロードを成功までポーリングし、両方の
アセット ID を記録し、それから初めて生成を始める。これをしなければスロット2
はストックの風景を描画し、投稿は完成して見えたはずだ。

チラシの行は A4 テンプレートで、画像スロット1つ（現場写真）と文字スロット4つ
（見出し、料金、期間、連絡先）。料金「1台 8,800円（税込）」は税込であることを含めて確認してから入れる。

---

## 生成、1行ずつ

1行目は候補3つを並列で投げ、3つとも恒久 PNG にエクスポートし、1つずつ目で
見る。候補2は見出しがテンプレート既定のダミーテキストのまま — その候補1つ
だけを再生成し、行全体は再生成しない。良い候補3つを1つのカルーセルとして
提示し、岡本さんが1つ選び、30 秒待ってから2行目へ。

4行目で Canva がレート制限エラーを返す。このセッションでは最初のヒットなので
60 秒待ってその候補1つを再試行する。成功する。一時的なスパイクのことは
岡本さんに何も言わない。1分かかるだけで、判断は要らない。

2回目のヒットなら、実行を止めて聞いていた：

```
Canva のレート制限にかかっています。現在の状況：
  生成済み:  投稿 1〜4（12 デザイン）
  残り:      投稿 5〜7（9 デザインが未生成）

  1. 残りの3行は候補1つずつにする — 今すぐ終わります
  2. 1時間休んで、上限が回復してから再開する
  3. ここで止めて、あるものでキャプション作成に進む
```

## 文章、岡本さんの声で

キャプションごとにプロファイルを確認し直す。最初の1本だけではない。

6月2日、Instagram：

```
エアコンをつけた時のガラガラ音は、たいてい送風ファンです。コンプレッサー
ではありません。早く見つければ安く直ります。放っておくと安くは済みません。

うちのも鳴ってる、という方は動画を送ってください。音でだいたい分かります。

#エアコン点検 #さいたま市 #業務用エアコン #hvac
```

短い文、2行目で本題に入る。書いていないこと：「ぜひお気軽に」「この度」
「ソリューション」。どれも「絶対に使わない言い回し」にあり、最初に指摘
されていたはずの語だ。法規の確認：自社アカウントの投稿で対価はないので
「PR」表記は不要。「No.1」「最安」なし。効能表現なし。

6月2日、LINE配信（6月2日 IG の流用、200字以内、リンク1つ）：

## 準備

HubSpot Starter なのでソーシャル投稿への準備は使えず、CSV の経路を回す。
LINE は手動投稿用コピー、チラシは PDF：

```
HubSpot のプランにソーシャルの予約が含まれていないので、Buffer や Later、
Meta Business Suite に取り込める CSV を用意しました。日付・キャプション・
画像は承認いただいたものと同じです：

  content-calendar-2026-06.csv

取り込む前に3点：
  - 投稿時刻はすべて JST の 12:00（昼休み前、店舗・オフィスの担当者が
    見る時間帯）で、すべて未来の日付であることを確認済みです
  - LINE配信の 2 行は CSV には入れていません。下の手動投稿用コピーを
    LINE Official Account Manager の「メッセージ配信 → 予約配信」に
    貼ってください
  - 取り込んで予約ボタンを押すまで、何も公開されません

6月5日のメールは上にあります。準備ができたらメールツールに貼ってください。
こちらではどこにも予約していません。

チラシは印刷用に PDF でエクスポートしました（A4、塗り足し付き）：
  tenken-chirashi-2026-06.pdf
印刷会社への入稿、または社内プリンターでの印刷はお任せします。
```

## 2回目 — 3週間後

カレンダーは作り直さず、まず開く：

```
前回以降：
  公開:         6件（6月2日〜6月19日）
  予約済み:     2件（6月26日まで）
  空き始める日: 6月27日

大宮の飲食店の清掃前後の投稿が、コメント数で圧倒的に一番でした。
6月27日から実績投稿を増やして延ばしますか？頻度は同じ週2本で。
7月は海の日の三連休（7月18〜20日）の営業案内と、猛暑の「効きが悪い」
問い合わせ向けのお役立ち投稿を入れるのをお勧めします。
```

これが、キャンペーン生成器とコンテンツ運用の違いだ。
