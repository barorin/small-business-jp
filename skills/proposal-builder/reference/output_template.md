# 出力テンプレート

経営者は送る前に二つを確かめる：金額と作業範囲。確認をその二つの周りに組み立て、あとは邪魔をしない。

---

## 構成

```
## 提案書 — <顧客>、<案件を一言で>

**<合計（税抜）／（税込）>** · <どう価格を決めたかを一行で>

根拠：<使った類似案件を、日付と金額とともに>

### 未確定の前提

- <前提> — <違っていたらどうなるか、円で>

### 送る前に知っておくべきこと

- <リスクを平易な言葉で>

<成果物の所在：確認用ページ、または設定・電子契約に応じて DOCX／PDF>

<送信の質問>
```

成果物の所在より上はすべて経営者だけのためのものだ。顧客はリスクの節を決して見ない。

---

## 記入例

```
## 提案書 — ローズウッド不動産、6棟の空調保守契約

**1,860,000円（税抜）／2,046,000円（税込）** · 佐藤運輸の案件をもとに、
棟数の増加と C棟の屋上の出入りで調整。

根拠：佐藤運輸株式会社、2026年3月 — 4棟、同じ作業範囲、1,200,000円（税抜）
      （300,000円/棟）。株式会社コーウィン商会、2025年11月 — 8棟、
      2,400,000円（税抜）（300,000円/棟）。1棟あたりの単価は安定している。

### 未確定の前提

- 屋上への出入りは既存の外部はしご。高所作業車が要るなら 180,000円 追加。
  これは提案書に書いてあるので、口論ではなく追加・変更になる。
- 既存の受電容量で足りる。検査で否と出れば別途お見積り。

### 送る前に知っておくべきこと

- この案件のリスクは C棟の屋上。写真3でははしごのみに見えて、パラペットの
  高さが確認できなかった。高所作業車が要るなら 60,000円 の割増では足りない。
- 田中様は通話で「前は 60万くらいでした」と言っていた。それは 2棟分なので、
  6棟で 186万円 は整合している — でも添え状で一言触れる価値がある。頭の
  数字が記憶の三倍だから。
- 通常は年額前払い。今回は上期・下期の 2回払いにしてある。準常連の顧客
  だから。戻したければ変えてください。
- 先方の希望は「検収後 90日払い」。中小受託取引なら受領から 60日以内が
  取適法の要請。条件交渉の材料に。

確認用のページはこの上に。送付用の DOCX・PDF は DocuSign に回す段階で
作ります（出力形式の設定が docx ならいま作る）。

田中様に DocuSign で送りますか、それとも先に何か変えますか？
```

二つ目のリスクは案件を勝ち取る種類のものだ。それは価格ではなく文字起こしから来ていて、どんなテンプレートもそれを浮かび上がらせはしなかった。

---

## 金額の行が空いているとき

その一か所を除いて完成した提案書を見せ、依頼は取るに足らないものにする：

```
## 提案書 — 株式会社コーウィン商会、中央監視の更新

**1,240,000円（税抜）＋ 制御連携** · 一行を除いてすべて金額入り。

4行目 — 中央監視（制御）との連携: ______円

履歴に類似案件がなく、単価表にもありません。数字をいただければ出せます。
他はすべて組み上がっています。
```

## RFP・公募への回答

要件適合が先頭に来る。要件に合わない提出は、価格が完璧でも負けるからだ：

```
## 公募回答 — さいたま市 文化センター 空調設備保守点検業務委託（公告番号 26-114）

**年額 3,000,000円（税抜）** · 3年の長期継続契約、商業施設の保守契約の
実績から積算。

### 要件適合チェック

✓ さいたま市の入札参加資格（役務）登録済 — 有効期限 2027年3月
✓ 建設業許可（管工事業）有効
✓ 施設賠償責任保険 1億円 — 7月12日付で増額済み
✓ 同種業務の実績 3件、いずれも延床 3,000㎡以上、2年以上の継続
⚠ 積算は市の設計労務単価によると指定。標準の人日単価より約 22% 高い単価
  で積算した。これでよいか確認。
⚠ 一級管工事施工管理技士の配置が要件。鈴木さんが該当するが、他の現場との
  兼務が認められるか要確認。

提出期限 8月8日 14時、電子入札システム経由。質問受付は 7月25日 17時まで。
指定様式 1〜5、提案書は A4 で 15ページ以内。いま 12ページ。

### 送る前に知っておくべきこと

- 緊急対応の応答時間（2時間以内）を超えると 1回あたり 50,000円 の違約金。
  保守契約としては厳しく、人員に自信がなければ見送る主な理由になる。
- 予定価格 3,300,000円（税込）が公表され、最低制限価格の設定あり。安すぎ
  れば失格、高すぎれば落札できない。
```

---

## ルール

**金額を先頭に。** 経営者がメッセージを開く理由がそれだ。税抜と税込の両方を出す。

**類似案件を常に見せる。** 経営者が十秒で承認できる価格と、ゼロから作り直す価格の違いがそれだ。

**リスクの節は正直に、そして分けて。** 顧客向けの文書には決して現れない。励ますために和らげると、それが存在する唯一の理由が消える。

**最後に送信の質問を一つ。** 選択肢のチェックリストではない — 「はい」か「直す」かの一つだけ。

**明示的な「はい」なしに決して送らない。** 金額の入った文書は、経営者の資金、予定表、評判を拘束する。
