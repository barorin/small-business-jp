# 商談材料の抽出

商談の材料は、経営者が現場の合間に残せた形で届く。以下はどれも普通の入力であって、劣化した入力ではない。

このステップの出力は、何が入ってきても常に同じ構造だ：

```
顧客:          <誰か、そして誰が発注（押印・署名）するか>
要望:          <仕事の内容を、相手の言葉で>
範囲（明確）:  <確実に含まれるもの>
範囲（曖昧）:  <示唆されているが明言されていないもの>
制約:          <立入・時間帯・法令・現場の条件>
対象外:        <明示的に除外されたもの>
日程:          <期限、着手できる時期>
予算の手がかり: <お金について言われたこと>
不足:          <欠けていて、金額を変えうるもの>
```

「不足」の行が経営者を守る。他の行は仕事を描写するが、この行は何が狂いうるかを描写する。

---

## 通話・会議の文字起こし

もっとも豊かな入力。全文を読む — 役に立つ細部はたいてい要約ではなく中盤にある。出所が Zoom でも Notion でも、Google Drive や Microsoft 365 に置かれた議事録でも、経営者のものだと確認してから読む（`../../../shared/tenant-scope.md`）。

**Zoom の制約。文字起こしがないことを、空の会議と取り違えないために。** 読み取り専用だ。
経営者が主催または参加した会議にしか届かない。そして録画の一覧は一回の呼び出しで
一か月分なので、それより古い履歴には二回目の、さらに前の期間の要求が要る。会議に
届かないときは、どの会議かを言い、経営者に録画かメモを求める — 読めなかった通話の
上に提案書を組み立てることは決してしない。

探すもの：

- **要望についての直接の発言。** 相手の言葉を提案書に使う。顧客は自分の言い回しに気づき、それは聞いてもらえたという合図になる。
- **さらりと触れられた制約。** 「入れるのは 18 時以降だけなんです」は、作業範囲の一覧には決して現れない費用の要因だ。
- **実際に決めるのは誰か。** 「本部に通さないといけなくて」は、日程とフォローアップを変える。
- **予算の手がかり。** 「前回は 60 万くらいでした」が文字起こしの中でいちばん価値のある一文だ。
- **前の業者に何を不満だったか。** 提案書がさりげなく応えるべきことがそれだ。

## ボイスメモ

車の中で、考えながら、しばしば誰も書き残さないような細部とともに録られる。

言い直しや途中の訂正を本物として扱う。経営者が「室外機は 4 台 — いや 5 台だ、裏の屋上にもう一台ある」と言えば答えは 5 台で、危うく見落としたという事実は、裏の屋上に注記を付ける価値があるということだ。

音声の数字が聞き取れなければ、推測しない。フラグを立てる：「0:47 の馬力（能力）が聞き取れませんでした — 出す前にご確認ください」。

## 写真

写真はあることには優れ、あることにはまったく役に立たない。どちらがどちらかを正直に言うことが、経営者をトラブルから守る。

**写真から分かること：** 銘板からの機器のメーカーと型番、見える範囲の状態と年数、立入の制約、目に見える障害物、おおよその配置、すでに設置されているもの。

**写真から分からないこと：** 基準となる物がないときの寸法、何かの裏や上、隠蔽された部材の状態、法令適合（建築基準法・消防法・フロン排出抑制法）、能力。

写っている中に大きさの分かる物がない限り、写真から数量を決して導かない。写真から推定した面積は、案件が赤字になるもっとも多い経路だ。

各写真が何をもたらし、何を開いたままにしたかを述べる：

```
写真3：屋上のダイキン製パッケージエアコン室外機。銘板は判読でき、型番と製造年
が読める。架台の根元に錆が見える。屋上への出入りは外部はしごのみに見える —
要確認。高所作業車やクレーンが要ると金額が大きく変わる。
```

## 図面・平面図

まず表題欄を読む：図面番号、改訂記号、日付、縮尺、そして施工用（承認図）か計画段階かの区分。古い改訂に対する見積は、別の案件に対する見積だ。

数量は機器表や凡例から取る。図面を測って出さない。機器表がなく数えるしかないなら、そう言い、数えた結果を前提として明記する。

「別途工事」「他社施工」「支給品」「既存流用」と書かれたものはすべて記録する — それは作業範囲の境界で、対象外の節にそのままの文言で入る。

## RFP・RFQ・公募要領・入札公告

これらは価格の文書である前に、要件適合の文書だ。要件に合わない回答は、価格が完璧でも負ける。

この順で抽出する：

1. **提出の手続き** — 提出期限、質問受付期限、指定様式（様式番号）、ページ制限、提出方法（電子入札システム、持参、郵送）、押印の要否。どれか一つでも外せば、他は何も意味を持たない。
2. **必須の参加資格** — 建設業許可などの許認可、全省庁統一資格や自治体の入札参加資格、保険の加入額、有資格者（技術者）の配置、同種業務の実績件数、社会保険の加入
3. **実際の業務の範囲**
4. **評価基準と配点** — 回答で何を強調すべきかを教えてくれる（価格点と技術点の比率、加点項目）
5. **費用を伴う条件** — 違約金・遅延損害金、契約保証金、支払時期（検収後の締めと支払サイト）、契約不適合責任の期間、積算基準（設計労務単価）、最低制限価格

**何かを書く前に、参加するかしないかの判断を通す。** 経営者が必須資格を満たせないなら、すぐそう言う。失格の RFP に回答をまるごと書くのは夜が一晩無駄になるということで、この層に余った夜はない。

```
参加可否：施設賠償責任保険 1 億円以上の加入が要件ですが、現在は 5,000 万円
です。8 日までに増額の手続きができなければ失格です。
残りを書く前に確認しておきますか？
```

## 走り書きのメモ

スマホで打った四行だけ、ということもある。始めるにはそれで足り、経営者がゼロから提案書を書くよりはずっといい。

あるものを抽出し、足りないものを直接の質問として並べる — 金額が本物になるための最小限の一式：

```
形を作るには足りています。数字が意味を持つ前に、三つだけ：
  - 室外機の台数と設置場所（屋上か地上か）
  - 既存の配管とダクトは流用しますか？
  - 分かっている期限はありますか？
```

三つの質問であって、記入用紙ではない。経営者はこれにスマホで答える。

## 不足の扱い

不足はどれも二通りのどちらかで解決し、三つ目は決してない：

**聞く。** 答えが金額を大きく変え、経営者がすぐに手に入れられるとき。

**前提として書く。** 案件を前に進める必要があるとき。前提は提案書そのものに、顧客に見える文章として入れる：

```
本見積は、屋上への出入りが既存の外部はしごで可能であることを前提としています。
高所作業車またはクレーンが必要な場合は 180,000円（税抜）を追加いたします。
```

この一文は、どんな価格の精緻化より粗利を守ってきた。争いを、事前に合意した明細に変える。

**黙って推測しない。** 見えない前提を背負った数字こそ、儲かるはずの案件が赤字になる仕組みだ。
