# 提案書の構成

経営者自身のテンプレートがあればそれを使う。この構成はそれがないときの代替であり、テンプレートを一度も持ったことのない経営者に「テンプレートとして保存しましょうか」と申し出るときの中身でもある。

---

## 節の順序

**1. 表紙・ヘッダー**

宛名（顧客の社名・部署・担当者名、敬称は「御中」「様」）、発行者（経営者の屋号・住所・連絡先、適格請求書発行事業者の登録番号）、見積日（発行日）、見積番号（提案書番号）、件名、有効期限。有効期限は材料費や機器価格が動くときに経営者を守る。

**2. ご提案の背景（課題の整理）**

商談の材料から拾った、顧客自身の言葉での要望を二〜三文で言い直す。埋め草ではない — 顧客は業者が本当に仕事を理解しているかを流し読みで確かめ、たいていの提案書は最初の段落でその試験に落ちる。

**3. ご提案内容（作業範囲）**

作業範囲を具体的に。数量、機器、場所、重要なら順序。

第三者が読んでも作業が完了したか判定できるように書く。「空調設備を更新」は作業範囲ではない。「屋上の室外機 5 台をダイキン製パッケージエアコンに更新し、既存の冷媒配管と電源に再接続、旧機器はフロン回収のうえ撤去・処分」が作業範囲だ。

**4. 対象外（含まれないもの）**

この文書でもっとも価値のある節。作業範囲の争いはサービス業が損をする場所で、誰も書き残さなかったことから始まる。

常識的な顧客が含まれていると思い込みそうなものをすべて入れる：

```
対象外：
  - 再接続の範囲を超えるダクトの更新・改修
  - 検査で必要と判明した場合の受電容量の増設（電気工事）
  - 架台の貫通部を超える屋上防水の補修
  - 屋上への出入りが困難な場合の高所作業車・クレーン（前提条件を参照）
  - 夜間・休日の作業
```

一行ごとに、あとの口論の代わりに、いま会話が起きる。

**5. 前提条件**

金額が依存している条件を、顧客に見える言葉で、違っていたらどうなるかとともに：

```
本見積は次を前提としています：
  - 屋上への出入りは既存の外部はしごで可能。高所作業車またはクレーンが必要な場合は 180,000円（税抜）を追加。
  - 既存の受電容量で足りる。増設が必要な場合は別途お見積り。
  - 作業は平日の通常時間帯に実施。
```

結果を名指しすることで、争いが事前に合意した追加・変更に変わる。

**6. お見積り（見積書）**

金額を、顧客が「決めごと」として認識できる明細に分ける。選択肢があるなら明確にラベル付けした松竹梅で、推奨案を名指しする。

見積書として成り立つために揃える項目：明細（品名・数量・単位・単価・金額）、小計（税抜）、消費税（税率ごとに 10%・8% を分けて）、合計（税込）、納期、支払条件、振込先（銀行名・支店・口座種別・番号・名義）、適格請求書発行事業者の登録番号、備考（有効期限、振込手数料の負担）。積算は税抜で行い、税込合計を必ず併記する。

**7. スケジュールと体制**

着手できる時期、工期、それが何に依存するか。何が動かすかを言う — 官庁への届出、機器の納期、顧客側の立入手配。依存関係のないスケジュールは、経営者が守れない約束だ。担当者（現場責任者、有資格者）と連絡窓口も一行で。

**8. お支払条件・契約条件**

着手金（前受金）、支払スケジュール（締め日と支払サイト）、振込手数料の負担、追加・変更の手続き、保証（契約不適合責任の期間）、見積の有効期限。

**9. 次のステップ**

一文で。「ご検討のほどよろしくお願いいたします」ではなく、実際の指示：

```
同封の注文書にご記入のうえご返送いただければ、機器を発注いたします。
納期はご入金（着手金）から 3 週間です。
```

**10. 会社概要・実績と発注欄**

会社概要（所在地、許認可、有資格者）と同種の実績を簡潔に。最後に発注欄：注文書／注文請書の様式、または双方の記名・押印欄と日付。DocuSign で回すときは電子署名のフィールドがここに入る。紙の注文請書や請負契約書は課税文書（第2号文書）で収入印紙が要り、電子契約なら不要 — 区分は税理士に確認。

## 分量

中小企業の提案書は、たいてい 2〜4 ページに収まるべきだ。

RFP・公募への回答は要領が求める長さになる — そこでは要件適合が簡潔さに勝ち、ページ制限や指定様式はたいてい強制だ。

定常業務の常連客なら 1 ページでよい。同じ仕事を 6 回買った顧客に、フル装備の提案書を読ませない。

## 文体

[共有のボイスプロファイル](../../../shared/voice-profile.md)に合わせる。経営者のメールとまるで違う調子の提案書は違和感があり、顧客はたいていすでに経営者とメールを交わしている。

**そのファイルにまだプロファイルがなければ**、「サンプルがないとき」の指示に従う — 経営者が満足したメールを三通もらう。断られたら、平易で中立に書き、この提案書は声を合わせていないと言う。人格を決して捏造しない。

全体を平易な言葉で。この読者層は、現場の合間にスマホで読む人に売っている。

提案書にありがちな水増しは避ける：経営理念、「選ばれる理由」の節、握手のストック写真。この層の経営者は明快さと反応の速さで勝つのであり、水増しした文書はその両方を損なう。

## 書式

- 出力形式は `../../../shared/document-format.md` に従う。HTML アーティファクトが既定。DOCX と PDF は設定が `docx` のとき、または電子契約に回すときに両方作る — 顧客は PDF を望み、経営者はときどき編集用に DOCX が要る
- テンプレートやブランド資産から取れるなら、経営者のロゴと色
- 見積の表は数値を右揃え、金額は `1,860,000円` の書式で、税抜・税込を明記
- フッターにページ番号と見積番号。ページがばらけないように
- 文書が 2 ページを超えるなら、発注欄（注文書・署名欄）は独立したページに

## テンプレートとして保存する申し出

経営者にテンプレートがなく、提案書の出来がよければ、一度だけ申し出る：

```
このレイアウトを標準の提案書テンプレートとして保存しましょうか？次回は
ゼロからではなく、ここから始められます。
```

「はい」なら、以後の実行が揃うように保存する。それが、一晩を一度だけ節約するスキルと、毎週節約するスキルの違いだ。
