# 価格の決め方

この経営者が実際に請求してきた金額から価格を決める。一般的な見積からでも、業界平均からでもなく、もっともらしく聞こえる数字からは決してない。

根拠が見えれば、経営者は価格を十秒で確かめられる。どこからともなく現れた数字は確かめられないので、全部を手で作り直す — それはこのスキルが取り除くはずだった作業そのものだ。

---

## 方法

**1. 類似案件を見つける。**

似た仕事の過去の請求書と提案書を引く：

- 会計ソフト（freee会計、マネーフォワード クラウド会計、弥生会計 など）の取引先別の売上 — 実際に請求した金額であり、それが比較可能にする。マネーフォワード クラウド会計は補助科目付きの残高試算表で取引先・品目別の売上を、`getJournals` を取引先で絞って個々の売上仕訳を読み、明細行はマネーフォワード クラウド請求書または請求書 CSV から。freee会計は取引（収入）を取引先・品目で絞る。弥生会計は売上帳・請求書の CSV。Zoho Books など海外製も同格
- 決済サービスの顧客別の決済履歴（PayPal、Square、Stripe） — 会計ソフトが未接続のとき。合計額だけなので、明細の計算は経営者から来る
- Google Drive または Microsoft 365 にある過去の提案書・見積書
- アップロードされた価格表・単価表（人日単価、機器の標準価格、外注単価）
- 経営者が貼り付けたもの

よい類似案件は、仕事の種類、おおよその規模、顧客の種類が一致する。二つか三つで十分。一つは薄いが、近ければ使える。

**2. 類似案件から組み立て、違いを調整する。**

計算を示す：

```
類似案件：佐藤運輸株式会社、2026年3月 — 4棟、同じ作業範囲。
          1,200,000円（税抜）、1棟あたり 300,000円。

本案件：  6棟、うち 1棟は屋上への出入りが外部はしごのみ。
          6 × 300,000円 = 1,800,000円
          + 60,000円 高所作業車の割増（C棟 屋上）
          = 1,860,000円（税抜）
          消費税（10%）186,000円 → 合計 2,046,000円（税込）
```

経営者はこれを読んで、同意するか、数字を一つ直す。それがすべてだ。

**3. 単価表があれば、それと照らす。**

導いた価格が単価表から 15% 程度以上離れていたら、そう言い、どちらを使ったか、なぜかを説明する。黙った食い違いが、市場に二つの価格が出回る原因だ。

---

## 類似案件がないとき

創作しない。空欄を残し、何が要るかを具体的に言い、提案書の残りをその周りに組み立てる：

```
3行目 — 中央監視（制御）との連携:  ______円

制御の仕事は履歴に類似案件がなく、単価表にも項目がありません。
他はすべて金額が入って準備できています。この行の数字をいただければ
提案書は完成です。
```

これは五秒の依頼だ。捏造した 420,000円 は、経営者が気づき、疑い、置き換えなければならない数字で — 気づかないかもしれない。

---

## 決して創作してはいけないもの

| 決して創作しない | 理由 |
|---|---|
| 人日単価・労務単価 | 経営者の経済の核心 |
| 材料・機器の価格 | 常に動き、仕入先で変わる |
| 納期 | 顧客への約束 |
| 写真からの数量 | 推定した面積は案件が赤字になる古典的な経路 |
| 外注先の価格 | 経営者が出せる数字ではない |
| 値引き | 値引きは常に経営者の判断 |

---

## 価格の構成

**顧客が理解できる明細に分ける。** 一つの数字は一つの反論を招く。四つの明細は作業範囲についての会話を招き、そのほうがよい会話だ。

ただしネジの一本まで細分化しない。明細は、顧客が「決めごと」として認識できるものに対応させる：

```
良い例：
  空調保守点検 — 6棟、年 4回の定期点検              1,500,000円
  フィルター清掃・消耗品                               240,000円
  高所作業車の割増（C棟 屋上）                          60,000円
  緊急対応（年 2回まで）                                60,000円
                                                    ------------
  小計（税抜）                                       1,860,000円
  消費税（10%）                                        186,000円
  合計（税込）                                       2,046,000円

悪い例：
  材料費                                             1,124,000円
  労務費                                               736,000円
```

良い例なら、顧客は高所作業車の割増を削ったり、緊急対応を外したりできる。悪い例では「高い」としか言えない。消費税は税率ごとに別記し、税抜と税込を混ぜない。

---

## 選択肢が役に立つとき

顧客の予算が読めないときは、二つか三つの松竹梅がよく効く。三つを超えると決められなくなる。

推奨案を軸に据え、どれがそれで、なぜかを一行で言う。ラベルのないメニューは、経営者の仕事を顧客にさせる。

経営者が本当はやりたくない選択肢を決して出さない。悪い結果を生む安い案は、顧客がそれを選んだときに経営者を傷つける。

---

## 取引条件

経営者の標準の条件は、創作せず過去の提案書から引く。何もなければ保守的な既定値を使い、確認のためにフラグを立てる：

- 着手金（前受金）：材料・機器の比重が大きい工事は 30〜50%、労務中心なら少なめ。年間の保守契約は年額前払いまたは半期ごとの前払いが多い
- 支払：翌月 15 日払いまたは月末締め翌月末払いで、経営者の請求書がすでに言っているものに合わせる。振込手数料の負担（先方負担が慣行だが、経営者の標準に従う）も明記
- 有効期限：30 日。機器や材料の価格が動いているときはもっと短く
- 追加・変更：着手前に書面（メール可）での合意
- 消費税：税抜で積算し、税率ごとの消費税額と税込合計を併記
- 支払サイト：中小受託取引なら受領から 60 日以内（取適法・フリーランス新法）。顧客の条件がそれを超えるなら経営者にフラグ。経営者が外注先に発注する側でも同じ

**通常より弱い条件にフラグを立てる。** 経営者の標準が着手金 50% で、この提案書が 25% なら、顧客に出る前に声に出して言う価値がある。

---

## 結果の記録

提案書を送ったあと、何が起きたかを記録する — 受注、失注、返答なし — 最終金額と、分かれば理由とともに。

受注した提案書は明日の類似案件になる。失注も同じだけ価値がある：1,860,000円 でローズウッド不動産の案件を 160万円 の競合に取られた、と知ることだけが、次の見積を鋭くする。プラグインの他のどこもそれを捉えておらず、経営者自身はまず記録しない。
