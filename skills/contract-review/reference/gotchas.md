# 落とし穴

契約書分析の際どい場面。良い例・悪い例の対。

---

## 落とし穴: 標準的な定型条項に赤信号を立てる

**なぜ大事か:** フラグの立てすぎは、経営者に要約を無視することを教える。すべてが赤信号なら、何も赤信号ではない。

### ✗ 悪い例

```
契約書に、標準的な双務の秘密保持条項がある。期間 2 年。
Claude: 「🔴 赤信号: 秘密保持条項が両当事者に義務を課しています。」
```

標準的な双務の NDA は市場の標準だ。赤信号にすると、シグナルとノイズの比率が壊れる。

### ✓ 良い例

```
契約書に、標準的な双務の秘密保持条項がある。期間 2 年。
Claude: [飛ばす。フラグを立てない]
```

赤信号は本当に標準的でない条項のために取っておく。定型で公平な条項は省く。

---

## 落とし穴: 欠けている条項を分析から欠かさない

**なぜ大事か:** 中小企業にとって、標準的な保護（損害賠償の上限、変更手続き、間接損害の免責）がないことは、不利な条項よりしばしば危険だ — 穴は法律の原則（民法の任意規定）で埋まり、たいてい相手方に有利に働く。

### ✗ 悪い例

```
契約書に損害賠償の上限がない。
Claude: [言及なし。存在する条項だけを分析する]
```

経営者は責任が限定されていると思って押印する。されていない。

### ✓ 良い例

```
契約書に損害賠償の上限がない。
Claude: 「🔴 欠落: 損害賠償の上限がありません。この契約書には責任制限の条項が
ありません。民法の原則では、御社の賠償責任に上限はありません。標準的な実務は、
過去 12 か月に支払われた報酬額を上限にすることです。追加の提案:
『各当事者の本契約に基づく損害賠償責任の総額は、請求の原因となる事由が生じた
日から遡って 12 か月間に支払われた、または支払われるべき報酬の額を上限とする。』」
```

欠けているが標準的な条項は赤信号として扱う。明示的に「欠落」と表示する。

---

## 落とし穴: 大きな PDF が分析の途中で切れる

**なぜ大事か:** 20〜30 ページを超える契約書は、最も危険な条件が末尾の別紙、付属書、「申込書」や「利用規約（約款）」にあることが多い。PDF を 15 ページまでしか読んでいなければ、主要な条件は黙って抜け落ちる。

### ✗ 悪い例

```
スキルが 40 ページの基本契約書の 1〜10 ページを読む。別紙 A〜D（28 ページから）に
知的財産の譲渡と損害賠償の上限がある。スキルは「問題なし」の要約を出す。
```

### ✓ 良い例

```
PDF を分割して読む: 1〜10、11〜20、21〜40 ページ。要約を出す前にすべての
塊を分析する。見出しに「別紙」「付属書」「約款」「Schedule」「Exhibit」とあれば
明示的にフラグを立て、読んだことを確かめる。
```

必ず文書を全部読む。大きな PDF は `pages` パラメータで分割する。

## 落とし穴: 相手方の雛形と、交渉済みの草案

**なぜ大事か:** 提案は交渉の文脈に合っていなければならない。スタートアップの初稿に強く押し返すのと、大手企業（上場企業）の購買部門の雛形に押し返すのは違う — 後者は条件の 8 割が交渉の余地なしということが多い。

### ✗ 悪い例

```
大手企業の、標準的な購買条件の取引基本契約書。
Claude: 「🔴 この翌々月末払いの条件は翌月末払いに再交渉すべきです。
         先方の法務は変更を受け入れるでしょう。」
```

現実味のない提案は、経営者の交渉の元手を無駄にする。

### ✓ 良い例

```
Claude: 「🟡 翌々月末払い。典型より長い（翌月末払いが標準）ですが、大手の購買
         雛形では珍しくありません。妥協案として翌月 20 日払いや検収後 45 日を
         求める価値はあります — 継続的な取引なら特に。
         注: この取引が取適法（旧・下請法）・フリーランス新法の対象なら、受領から
         60 日以内の支払いが法定で、月末締め翌々月末払いはこれを超える月が出ます。
         その場合は交渉の材料ではなく、相手方が守るべきルールとして指摘できます。
         対象かどうかは公正取引委員会の資料か弁護士に確認を。
         注: 大手の雛形なら、初回の取引では支払条件は交渉の余地がないことが多いです。」
```

提案を力関係に合わせる。赤ではなく黄にする。現実を認める。
