# AI 臭チェック（スロップテスト）

経営者に見せる前に、すべての下書きをこれに通す。以下は、文面を「機械が書いた」と読ませる特定のパターンだ。経営者は全部を瞬時に見抜く。自分の受信箱がこれで埋まっているからだ。

---

## 4 つの即席チェック

**1. 経営者はこの文を声に出して言うか？**

経営者の声で音読する。パンフレットに聞こえるなら書き直す。誰も口にしない「ビジネスメール文体」は、最もよくある印だ。

**2. 社名を入れ替えれば別の会社にも送れるか？**

送れるなら、それは差し込み項目付きのテンプレートであって、パーソナライズではない。相手は今月それを 40 通受け取っている。

**3. 相手の事業への褒め言葉で始まっているか？**

削る。「貴社の Web サイトを拝見し、大変感銘を受けました」は営業メールで最も見分けやすい書き出しだ。誰もが使うので、一斉送信の合図になる。

**4. 経営者が一度も使ったことのない言い回しがあるか？**

共有ボイスプロフィールの「絶対に使わない」一覧と突き合わせる。よそ者の言い回しが一つあるだけで、良いメールが台無しになる。

## 禁止の書き出し

何が続いても、生成物として読まれる。

- 「貴社ますますご清栄のこととお慶び申し上げます」（時候の挨拶・祝詞は営業メールに不要。定型文は読み飛ばされる）
- 「日頃より大変お世話になっております」（面識がないのに書けば嘘になる。初対面は「突然のご連絡失礼いたします」の一文だけでよい）
- 「ご多忙のところ恐れ入りますが」（冒頭に置くと本題が遠のく。使うなら、お願いの直前に一度だけ）
- 「貴社の Web サイトを拝見し、大変感銘を受けました」
- 「業界をリードされている貴社に、ぜひ」
- 「本メールは〇〇のご案内です」（自分から広告だと名乗る）
- 「お忙しいとは存じますが、少しだけお時間をください」
- 「突然のご連絡で恐縮ですが、ぜひ一度、貴社のお役に立てればと」（詫びの後に空虚な願望を続ける形）

**代わりに何で始めるか:** 書いている具体的な理由。管理受託のお知らせ。共通の顧客。起きた出来事。

```
悪い: 日頃より大変お世話になっております。貴社の Web サイトを拝見し、商業施設
      管理における豊富な実績に大変感銘を受け、ご連絡いたしました。

良い: 貴社サイトのお知らせで、7 棟目となる大宮西口ビルの管理受託を拝見しました。
```

---

## 禁止の常套句

場所を取るだけで意味を運ばない言い回し。

| 削る | 理由 |
|---|---|
| 「シナジー」「ソリューション」「DX を推進」 | 経営者は口に出して言わない。カタカナの抽象語は中身がない印 |
| 「〜させていただきます」の連発 | 一通に 3 回以上あれば AI か新人。「〜します」「〜いたします」に戻す |
| 「ぜひ一度」「ぜひとも」 | 具体的な日時に置き換える |
| 「〜ではないでしょうか」の連打 | 相手の悩みを勝手に決めつける形。事実か、一つの質問にする |
| 「多くの企業様にご好評いただいております」 | 根拠のない実績。社数か固有名詞を書くか、書かない |
| 「貴社のさらなる発展に貢献」「お力になれれば幸いです」 | 誰にでも言える。何をするかを書く |
| 「最適なご提案」「課題解決」「ワンストップ」「寄り添う」 | 中身のない売り文句 |
| 「拝見させていただきました」「お伺いさせていただきます」 | 二重敬語。「拝見しました」「伺います」 |
| 「ご検討のほど何卒よろしくお願い申し上げます」 | お願いが曖昧。日時と所要時間のある本物のお願いに |

## 構造上の癖

**きれいに揃った 3 点の箇条書き。** 本物の人は一つだけ書くか、雑な列挙をする。完璧に均衡した三つ組は生成の痕跡だ。

**前の文を言い換えただけの文。** 生成物は水増しする。経営者はしない。

**段落がすべて同じ長さ。** 本物の文章はでこぼこしている。

**敬語の階層を上げすぎた一文。** 「ご確認いただけますと幸いに存じます」が三つ続けば、現場の合間に書いた文ではない。経営者は「ご確認ください」と書く。

**装飾記号と絵文字。** 「■」「★」「！！」、絵文字。経営者の営業メールには出てこない。

**言ったことを要約する結び。** 300 字のメールでは、定義上これは水増しだ。

## お願い

すべてのメッセージに必ず一つ、しかも小さいものを。

```
悪い: もしご興味をお持ちいただけましたら、貴社の設備管理のお困りごとについて、
      ぜひ一度お話しさせていただければ幸いです。

良い: 来週の木曜か金曜に、15 分ほどお時間をいただけないでしょうか。
```

曖昧なお願いは曖昧な無反応を生む。具体的で小さなお願いは「はい」か「いいえ」を生み、どちらも役に立つ。

---

## 長さ

| メッセージ | 上限 |
|---|---|
| 新規、初回 | 400 字 |
| フォローアップ | 250 字 |
| 紹介・つながりあり | 500 字 |
| 商談後 | 300 字 |

上限を超えたら、締めるのではなく削る。最初に消えるべきは、時候の挨拶、自社紹介の段落、末尾の要約 — どれもその場所に値しない。

## 書き直しの実例

**前 — 約 450 字、すべてのチェックに落ちる:**

```
件名: 空調設備の保守ソリューションのご提案

大宮ビル管理株式会社
田中様

突然のご連絡で恐縮でございます。日頃より大変お世話になっております。
貴社の Web サイトを拝見させていただき、商業施設の管理における豊富な実績に
大変感銘を受けました！

私ども岡本設備工業株式会社は、複数棟を管理される管理会社様の課題に寄り添い、
最適な空調保守ソリューションをワンストップでご提供させていただいております。
多くの企業様にご好評いただいており、貴社のさらなる発展にも必ずや貢献できる
ものと確信しております。

貴社におかれましても、棟ごとの契約管理にお手間を感じていらっしゃるのでは
ないでしょうか。設備の老朽化にご不安をお持ちではないでしょうか。

ご多忙のところ恐れ入りますが、ぜひ一度お打ち合わせの機会をいただけますと
幸いです。ご検討のほど何卒よろしくお願い申し上げます。

岡本設備工業株式会社
岡本 亮
```

**後 — 約 330 字、岡本本人の声:**

```
件名: 大宮西口ビルの空調保守の件（岡本設備工業）

大宮ビル管理株式会社
施設管理部 田中様

突然のご連絡失礼いたします。さいたま市で空調保守をしている岡本設備工業の
岡本と申します。

貴社サイトのお知らせで、7 棟目となる大宮西口ビルの管理受託を拝見しました。

率直に申し上げると、当社は市内の管理会社 6 社で、複数棟をまとめた保守契約を
お引き受けしています。棟ごとの個別契約より費用を抑えられることがほとんどです。

来週の木曜か金曜に、15 分ほどお時間をいただけないでしょうか。

岡本設備工業株式会社 岡本 亮
〒330-0000 さいたま市大宮区〇〇 1-2-3 / 048-XXX-XXXX
今後のご案内が不要な場合は、本メールにその旨ご返信ください。
```

何が変わったか: 書き出しが実在の事実になった。自社紹介が、似た顧客についての具体的な主張になった。お願いが答えられるものになった。禁止の言い回しはすべて消えた。「〜ではないでしょうか」の決めつけと二重敬語が消えた。署名に住所と受信拒否の連絡先が入り、特定電子メール法の表示を満たした。そして岡本本人に聞こえる。本人の書き出し、本人の署名、本人の「率直に申し上げると」、本人の文の長さを使っているからだ。

## 下書きが通らないとき

本当にフックがないこともある — シグナルなし、つながりなし、具体的なものなし。

でっち上げない。短く、率直に冷たいメールを書き、経営者にそれが冷たいものだと伝える:

```
この会社は特定のきっかけがないので、率直な新規の自己紹介にしています。
意図的に短くしました — 触れるものがないのに、あるふりをするほうが悪いので。
```

正直な 150 字の新規メールは、温かいふりをした 400 字に勝る。しかも、相手同士が後で見比べても経営者の信用を損なわない。
