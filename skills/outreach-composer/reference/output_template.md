# 出力テンプレート

何かを送信待ちにする前に、一連のメッセージを承認のために提示する。経営者は 1 通目を精読し、残りは流し読みする — そのための構成にする。

---

## 構成

```
## 営業メール — <宛先>

声:    <何に合わせたか、またはプロフィールを今作ったことを一行で>
フック: <このメールが根ざしている具体的な事実と、その情報源>

### 1 通目 — すぐに送信

件名: <件名>

<本文全文>

### 残りの流れ

| # | 日 | 件名 | 切り口 |
|---|---|---|---|
| 2 | +7 | <件名> | <一行> |
| 3 | +14 | （電話） | <一行> |
| 4 | +21 | <件名> | <一行> |

<2〜4 通目の全文は必要なら出します — 一言ください。>

### 送信前の確認

<件数> 通を <宛先> へ、<アカウント> から、<n> 日間で。
<連絡先の確度に関する注意があれば。>
<特定電子メール法の表示（社名・住所・受信拒否の連絡先）が署名にあるか。>

修正しますか、それとも送信待ちにしますか？
```

## 一括の場合

一連のメッセージが一社ではなくリストに向かうときは、完全に書いた例を一つと、パーソナライズの方針を示す:

```
## 営業メール — 7月のリストから 12 社

声:        プロフィールに合わせました。
構成:      12 社すべて同じ 3 通＋電話の流れ。
パーソナライズ: 各社の 1 通目は、その会社自身のきっかけで始めます —
           共通の書き出しなし、差し込み項目のテンプレートなし。

### 完全に書いた例 — 大宮ビル管理株式会社

<1 通目の全文>

### 残り 11 社の書き出し

| 会社 | 1 通目の書き出し |
|---|---|
| 株式会社コーウィン商会 | 施設管理担当の求人、4月2日掲載 |
| 浦和ビルディング株式会社 | 2月に 2 か所目の事務所を開設 |
| 株式会社三芳ビル管理 | きっかけなし — 率直な新規の自己紹介、短め |
| ... | |

### 送信前の確認

メール 36 通＋電話 12 回を 12 名の担当者へ、21 日間で、okamoto@okamoto-setsubi.example.jp から。

⚠ 12 社中 3 社の連絡先は推定で、未確認です: コーウィン商会、デルタ不動産、サンフィールド。
  先にアドレスを確認することをおすすめします — 大量のバウンスは送信ドメインを
  何か月も傷つけ、顧客メールにも影響します。推定アドレスは名刺交換も Web 公開も
  されていないので、特定電子メール法の例外にも当たりません。

12 社すべて承認、確認済みの 9 社だけ承認、それとも修正しますか？
```

**承認では必ず確認済みと推定を分ける。** 経営者に全か無かではなく本当の選択肢を与える。ドメイン評価のリスクは、経営者が知っていて当然のことではない。

## 下書きのみモード

メールコネクタがないときの納品物は、貼り付け用に整えた文面だ。詫びずにそう言う:

```
メールコネクタが未接続なので、ご自身のメールに貼り付けて送る下書きです。
送信順と日取りは各メールに書いてあります — 送ったものを教えていただければ
記録します。
```

各メッセージに送信日を書いた簡潔な見出しを付け、経営者が手で流れを回せるようにする。

## 修正の後

すべての修正を `../../../shared/voice-profile.md` に反映し、一行で確認する:

```
反映しました。2 通目から「ご多忙のところ恐れ入りますが」を削り、ボイス
プロフィールに記録したので、今後は出てきません。
```

この最後の一節が、毎週同じ修正をされるのではなく学習していると感じさせるものだ。
