# 落とし穴

一度の悪い下書きで経営者がこのスキルを使わなくなる失敗パターン。

---

## 落とし穴: 声を学ぶ前に書く

**なぜ重要か:** 最初の下書きで信頼が決まる。汎用的にそつのないメールは「やっぱり AI っぽくなる」という経営者の懸念を裏付け、手書きに戻られる。

### 悪い例

```
経営者: 「この 12 社に挨拶のメールを書いて。」
Claude: [構成は良いが、まったく汎用的なメールを書く]
```

### 良い例

```
Claude: [共有ボイスプロフィールを読む — 空]
        「書く前に、あなたらしい文面にしたいです。お客様に送った直近 20 通の
        送信済みメールを読んでもいいですか？ または、気に入っている 3 通を
        貼り付けてください。」
```

一手間増えるだけで、以後の下書きすべてが引き継ぐ。

---

## 落とし穴: 電話番号しかない連絡先

**なぜ重要か:** メールアドレスのない相手にメールを下書きしても、送れないメッセージができるだけだ。そのために創作したりパターンから推測したりしたアドレスが、送信ドメインを迷惑メール扱いにさせる。

### 悪い例

```
経営者: 「12 社全部書いて。」
Claude: [電話番号しかない 3 社の分も含めて 12 通のメールを下書きする]
```

### 良い例

```
このうち 3 社は電話番号だけでメールアドレスがありません。その 3 社のメールは
書きません。選択肢は三つ:

  · 電話用のトークスクリプト — 同じ書き出し、同じ連絡の理由を、話す形に
  · 郵送の手紙（封書または FAX）— 同じ内容を紙で。決裁者に確実に届く
  · lead-finder に戻して、先にアドレスを探す

どれにしますか？
```

メールアドレスのない相手にメールを下書きしない。バッチを完成に見せるためにアドレスを推測しない。

---

## 落とし穴: 褒め言葉の書き出し

**なぜ重要か:** 「貴社の Web サイトを拝見し、大変感銘を受けました」は営業メールで最も見分けやすい一行だ。誰もが送るので、最初の一文で一斉送信だと分かり、それ以降は読まれない。

### 悪い例

```
貴社の Web サイトを拝見させていただき、商業施設の管理における豊富な実績に
大変感銘を受けました。
```

### 良い例

```
貴社サイトのお知らせで、7 棟目となる大宮西口ビルの管理受託を拝見しました。
```

事実は褒め言葉に勝る。しかも、誰かが実際に見たことの証明になる。

---

## 落とし穴: 中身のないフォローアップ

**なぜ重要か:** 「念のため再送いたします」は、送り手に足すものはないが注意は欲しい、と言っている。成約率は低く、好意を削る。

### 悪い例

```
件名: Re: 大宮西口ビルの空調保守の件
田中様 — 先日お送りしたメールの件、念のため再送いたします。ご検討状況を
お聞かせいただけますと幸いです！
```

### 良い例

```
件名: Re: 大宮西口ビルの空調保守の件
田中様 — 一つ書き忘れました。コーウィン商会様は昨年、9 本の個別契約を 1 本に
まとめて 14% 下がりました。貴社と同じ構成です。
岡本設備工業 岡本
```

すべての接触は存在理由を得るか、送らないか。

---

## 落とし穴: 差し込み項目の「パーソナライズ」

**なぜ重要か:** 相手はテンプレートを瞬時に見抜く。社名を入れ替えれば誰にでも送れるメッセージはパーソナライズされておらず、それをパーソナライズと呼ぶのは、素直に送るより悪い。

### 悪い例

```
{{company}} {{last_name}}様、{{industry}} 業界における貴社のご活躍を拝見し、
ご連絡いたしました。
```

### 良い例

各メッセージは、その会社自身のきっかけで始める。12 社なら 12 通りの一行目。きっかけのない会社があれば、その一通は短く、率直に冷たいものにする。

---

## 落とし穴: 明示の承認なしに送る

**なぜ重要か:** メールは経営者の名前で、本物の顧客や見込み客に届く。取り消せない。誤送信一つが、経営者が何年もかけた関係を壊しかねない。

### 悪い例

経営者が 1 通目に「うん、いいね」と言ったので、一連全体を送信待ちにする。

### 良い例

承認はバッチごと、段階ごと。何が起きるかを述べ、「はい」を待つ:

```
メール 3 通＋電話 1 回を田中 美咲 様へ、21 日間で、okamoto@okamoto-setsubi.example.jp から。
送信待ちにしますか？
```

1 通目の承認は、2〜4 通目の承認ではない。

---

## 落とし穴: 推定アドレスへの一斉送信

**なぜ重要か:** ここで最も損害の大きい失敗で、経営者には予見のしようがない。大量のバウンスは送信ドメインを迷惑メール扱いにさせる。本物の顧客メールが何か月も劣化し、誰もそれを 7 月の営業バッチと結びつけない。さらに、推定アドレスは名刺交換も Web 公開もされていないので、特定電子メール法の例外に当たらず、同意なしの送信になる。

### 悪い例

パターンから推測した 3 件を含めて 12 社全部に送る。

### 良い例

```
⚠ 12 社中 3 社の連絡先は推定で、未確認です。先にアドレスを確認することを
おすすめします — 大量のバウンスは送信ドメインを何か月も傷つけ、顧客メール
にも影響します。

12 社すべてに送りますか、それとも確認済みの 9 社だけにしますか？
```

経営者に本当の選択肢を与える。このリスクを知っていて当然とは言えない。

---

## 落とし穴: 返信の後に届くフォローアップ

**なぜ重要か:** 相手がすでに答えた 2 日後に「念のため再送」が届くこと以上に「自動送信」を明確に告げるものはない。

### 悪い例

返信の有無に関わらず、流れが予定どおりに走る。

### 良い例

どんな返信でも流れを止める。不在通知も、その期限が切れるまで。スレッドを経営者に渡す。

---

## 落とし穴: 創作した実績

**なぜ重要か:** 経営者が自分の名前で送るメールの「似た会社でコストを 30% 削減しました」は、電話で弁明を迫られる主張だ。事実でなければ、文体ではなく実害の問題になる。

### 悪い例

```
これまで数十社の管理会社様の空調コストを最大 30% 削減してまいりました。
```

30% はどこから来た？ どこからも来ていない。

### 良い例

```
コーウィン商会様は昨年、9 本の個別契約を 1 本にまとめて 14% 下がりました。
```

数字は実際の顧客データから取るか、主張を外す。経営者に引き合いに出せる実績がなければ、証拠を創作するのではなく、何をするかを書く。

---

## 落とし穴: 同じ修正を二度させる

**なぜ重要か:** バッチごとに「ご多忙のところ恐れ入りますが」を消さねばならない経営者は、このスキルは学習しないと結論して手書きに戻る。

### 悪い例

この下書きに修正を当てて、次へ進む。

### 良い例

当てて、共有ボイスプロフィールに書き込み、そう言う:

```
削りました。ボイスプロフィールに記録したので、今後は出てきません。
```
