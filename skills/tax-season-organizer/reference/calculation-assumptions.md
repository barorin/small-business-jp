# 納税額の計算前提 — 数値は令和8年（2026年）時点の目安

このファイルは、納税資金の見積もりで使う計算と前提を記録する。前提は必ず出力に
表に出し、税理士が調整できるようにする。

> **以下の税率、控除額、みなし仕入率、納付期限はすべて令和8年（2026年）時点の値だ。**
> 計算の形は古びないが、数字は古びる。このファイルの数字を使う前に、経営者が実際に
> 聞いている事業年度と照らす。
>
> **対象の年度が 2026年でなければ：** これらの数字を黙って流用せず、代わりの数字を
> 創作もしない。出力の中で、経営者の言葉でそう言う：
>
> > 「使った税率・控除額・期限は令和8年時点のもので、お聞きの年度は <年度> です。
> > これらは毎年変わります。現在の数字を教えていただくか、以下は大まかな形として
> > 見て、実際の数字は税理士さんに入れてもらってください。」
>
> 最新の数字が権威ある出典（国税庁サイト、各都道府県の税務サイト）から取れるなら、
> それを使い、出典と取得日を書く。取れなければ経営者に聞く。推測はしない。記憶から
> 作った税率表は、本物とまったく同じ見た目で紙に載る。

## 法人税等（法人）

法人税・地方法人税・法人住民税・法人事業税・特別法人事業税をまとめて「法人税等」と呼ぶ。
資本金 1億円以下の中小法人が前提。所得 800万円以下の部分には軽減税率がある。

**計算式（目安）：**
```
課税所得         = 税引前当期純利益 ± 申告調整（交際費の損金不算入、減価償却の超過 など）
                   （調整は税理士の領域。見積もりでは税引前利益 ≒ 課税所得とし、そう明記）
法人税等（目安） = 課税所得のうち 800万円以下の部分 × 約23〜25%
                 + 800万円超の部分 × 約33〜34%
                 + 均等割（赤字でも年 7万円程度〜。資本金と従業員数で変わる）
```

**例：**
```
課税所得：        1,120万円
800万円以下：     800万円 × 24%  = 192万円
800万円超：       320万円 × 33%  = 106万円（端数切り捨て）
均等割：                            7万円
法人税等（目安）：                305万円
```

実効税率は都道府県・市区町村の超過税率、資本金、事業年度の長さで変わる。出力には
「目安」と書き、税理士に確認と添える。

## 所得税・住民税・個人事業税（個人事業主）

### 事業形態と課税の対応

| 事業形態 | 課税のされ方 | 消費税 |
|---|---|---|
| 個人事業主（青色申告） | 事業所得 → 所得税（累進）＋住民税＋個人事業税 | 課税事業者なら別途 |
| 個人事業主（白色申告） | 同上。青色申告特別控除なし | 同上 |
| 合同会社・株式会社 | 法人税等（上記）。役員報酬は給与として本人が所得税 | 同上 |
| 一人社長の法人 | 法人税等＋役員報酬への所得税の二段構え。見積もりは法人側のみ | 同上 |

既定の前提：**事業コンテキストの `事業形態` に従う。** 無ければ聞く。必ず明記する。

### 所得税の速算表（令和8年分、超過累進）

| 課税所得 | 税率 | 控除額 |
|---|---|---|
| 195万円未満 | 5% | 0円 |
| 195万円以上 330万円未満 | 10% | 97,500円 |
| 330万円以上 695万円未満 | 20% | 427,500円 |
| 695万円以上 900万円未満 | 23% | 636,000円 |
| 900万円以上 1,800万円未満 | 33% | 1,536,000円 |
| 1,800万円以上 4,000万円未満 | 40% | 2,796,000円 |
| 4,000万円以上 | 45% | 4,796,000円 |

所得税額には **復興特別所得税 2.1%** が上乗せされる。**住民税は一律 10%**（所得割）＋均等割。
**個人事業税**は業種により 3〜5%（事業主控除 290万円を引いた後）。

**課税所得（見積もり用）：**
```
課税所得 = 事業所得（売上 − 経費）− 青色申告特別控除（最大 65万円）− 所得控除
           （基礎控除・社会保険料控除・小規模企業共済等は未反映。2025年の税制改正で
            基礎控除の額が変わっている — 税理士に確認）
```

所得控除は最終の税額を大きく変える。基本の見積もりには入れず、税理士が入れると注記する。

## 消費税（法人・個人共通）

課税事業者かどうかは基準期間（2期前）の課税売上高 1,000万円超か、インボイス登録の有無で
決まる。課税方式は事業コンテキストの `消費税` から読む。

```
本則課税：  消費税 = 課税売上に係る消費税 − 課税仕入に係る消費税
            （人件費・保険料・租税公課は不課税・非課税で仕入税額に入らない。
             免税事業者からの仕入は経過措置 80%（〜2026年9月30日）→ 50%（2026年10月1日〜））
簡易課税：  消費税 = 課税売上に係る消費税 × (1 − みなし仕入率)
2割特例：   消費税 = 課税売上に係る消費税 × 20%（2026年9月30日の属する課税期間まで）
免税事業者：0
```

| 簡易課税の事業区分 | みなし仕入率 |
|---|---|
| 第1種 卸売業 | 90% |
| 第2種 小売業 | 80% |
| 第3種 製造業・建設業 | 70% |
| 第4種 その他（飲食店 など） | 60% |
| 第5種 サービス業・金融・運輸 | 50% |
| 第6種 不動産業 | 40% |

税込経理の試算表では、売上高から消費税を取り出して計算し、そう明記する。**預かった消費税は
自社の資金ではない** — 納税見積の出力で必ず繰り返す。

## 年度累計の利益と年換算の利益

この二つは別の数字で、混同すると経営者に誤った額を渡す最短経路になる。各行がどちらを
使っているか明示する。

- **年度累計の利益** — 期首から直近の締め済み月末までに帳簿が実際に示す数字。事実。
- **年換算の利益** — 年度累計を通期に引き伸ばしたもの。見積もり、どこまでも見積もり。

```
年換算利益 = 年度累計利益 ÷ 経過月数 × 12
```

**税額計算は年換算の数字で走らせる。** 法人税等の軽減税率の 800万円、所得税の累進、
消費税の中間申告の判定はいずれも通期の数字に対して効く。年換算利益で税額を出し、
納付期限ごとに分ける。

**両方の数字を、必ずラベル付きで示す**。経営者が見積もりを見積もりとして見られるように：

```
年度累計の税引前利益（4月1日〜9月30日）：   560万円   実績、帳簿から
年換算の税引前利益：                       1,120万円   見込み、年度累計 ÷ 6か月 × 12
```

直線の年換算は、残りの期間がすでに終わった期間と同じに動くと仮定する。季節変動のある
事業ではそれは単に間違いだ。年が均等に動くかを **一度だけ聞き**、そうでなければ経営者
自身の通期感覚を使って「経営者の見込み、年度累計からの推計ではない」とラベルを付ける。

## 納付期限（令和8年時点）

| 区分 | 対象期間 | 納付期限 |
|---|---|---|
| 法人税等・消費税の確定申告（法人） | 事業年度 | 決算日から 2か月以内（3月決算なら 5月31日。休日なら翌営業日） |
| 法人税の中間申告（法人） | 期首から 6か月 | 6か月経過後 2か月以内（3月決算なら 11月30日） |
| 消費税の中間申告（法人・個人） | 前期の確定税額で回数が決まる | 年1回なら期首 6か月後の 2か月以内。年3回・年11回もある |
| 所得税の確定申告（個人） | 暦年 | 翌年 3月15日 |
| 消費税の確定申告（個人） | 暦年 | 翌年 3月31日 |
| 所得税の予定納税（個人） | 前年の実績 | 第1期 7月31日、第2期 11月30日 |
| 個人事業税（個人） | 前年の所得 | 8月・11月（都道府県から納付書） |
| 住民税（個人・普通徴収） | 前年の所得 | 6月・8月・10月・翌年1月 |

期限が土日祝に当たる年は翌営業日にずれる。当年の期限を確認し、この表をそのまま
持ち越さない。

## 納付期限をすでに過ぎているとき

今日の日付が納付期限を過ぎ、何も納めていないことがある。過ぎた分を黙って残りに混ぜない —
声に出して言う。延滞税は本来の期限の翌日から日割りでかかり、次の期限からではない。

三つに分けて扱う：

1. **何を落としたかを名指しする。** 「法人税の中間申告分は 11月30日が期限でしたが、
   納付の記録が見当たりません。」金額と日付で、ぼんやりした警告ではなく。
2. **追納分を今後の分と別に示す。** 遅れている分を一行、次の予定納付を一行。二つの判断、
   二つの数字。
3. **延滞税・加算税は税理士に送る。** 延滞税は日数と割合で、無申告加算税は申告の有無で
   決まり、このスキルはその前提を持たない。かかることをフラグし、金額は見積もらない。

今後の納付額の割り振りは、まだ先にある期限だけを対象にする。残っていなければ、確定申告と
同時に納付と書き、申告期限を添える。

## 中間申告・予定納税の要否

翌期の資金繰りを決めるのはこの判定なので、必ず出力に書く：
- **法人税：** 前期の法人税額が **20万円超** なら中間申告が必要（前期の税額の半分を
  予定申告で納めるか、仮決算）。
- **消費税：** 前期の確定消費税額（国税分）が **48万円超** で中間申告あり。48万円超〜
  400万円以下は年1回、400万円超〜4,800万円以下は年3回、4,800万円超は年11回。
- **個人の所得税：** 予定納税基準額が **15万円以上** なら 7月31日・11月30日に 1/3 ずつ。
  業績が落ちていれば減額申請（7月15日・11月15日まで）ができる。

前期の確定税額は経営者または税理士に確認する。判定を推測で置かない。

## 見積もりに含まないもの

出力のたびに必ず列挙する：
- 都道府県・市区町村の超過税率（法人住民税・法人事業税の自治体差）
- 申告調整（交際費・役員給与の損金不算入、減価償却の超過・不足）
- 所得控除（基礎控除、社会保険料控除、生命保険料控除、配偶者控除 など）
- 小規模企業共済・iDeCo・経営セーフティ共済の掛金（所得や損金を大きく減らす）
- 少額減価償却資産の特例（30万円未満、年 300万円まで）、中小企業投資促進税制などの特別償却・税額控除
- 賃上げ促進税制などの税額控除
- 繰越欠損金（前期以前の赤字の控除）
- 消費税の仕入税額控除の細部（インボイス経過措置の按分、非課税売上の按分）

これらは最終の数字を大きく動かし得る。税理士が入れられるようにフラグする。
