# 実例：標準的な流れの仕分け — 7 件のリード

岡本設備工業（空調・給排水設備工事、さいたま市）の HubSpot。連絡先 12 件を取得 →
ライフサイクルが `Customer` の 2 件（既存の保守契約先）と `hs_lead_status` = `Unqualified` の
3 件を除外 → 残り 7 件 → 全件表示（10 件以下のルール）。今日の折り返しは上位 3 件を推奨。
経営者の ICP：さいたま市内のオフィス・店舗・クリニック、従業員 10〜50 名。

---
