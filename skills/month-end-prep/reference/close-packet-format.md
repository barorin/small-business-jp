# 月次締めパック 書式リファレンス

月次締めパックは二つのファイル：xlsx ブックと 1ページの PDF サマリー。顧問税理士に
渡す前提で作るが、**税理士に送るのは経営者が内容を確認して承認した後**。

## ファイル命名

```
close-packet-2026-03.xlsx
close-packet-2026-03-summary.pdf
```

ファイル名は ISO 8601 の年月（`YYYY-MM`）。既定の保存先はデスクトップ。経営者の指定が
あればそのパスを使う。

---

## xlsx ブック — 5シート

### シート1：試算表

会計ソフトの残高試算表（損益計算書）を対象月について整形したもの。二列構成：
**科目** と **金額**。

必須の行（この順で）：
1. 売上高 小計
2. 売上原価 小計
3. **売上総利益**（太字）
4. **粗利率 %**（太字、% 表示）
5. 販売費及び一般管理費（科目ごとに一行）
6. 販売費及び一般管理費 計
7. **営業利益**（太字）
8. 営業外損益と **経常利益**（太字。借入利息がある事業者はここが経営者の見る数字）

前月のデータがあれば前月比の列を入れる。金額は円の書式で、通貨記号ではなく「円」を
付ける：`#,##0"円"`（`../../../shared/currency-and-locale.md`）。税込か税抜かをシートの
見出しに書く。負の値は赤。

### シート2：推移表

期首から対象月までの月次推移（マネーフォワードなら `getReportsTransitionProfitLoss`）。
行は試算表と同じ科目、列は月。最右列に「前月比」と「前月比 %」。全項目 0 の科目は
会計ソフトから返らないので、返らなかった科目は行を作らず、脚注に「動きのない科目は
省略」と書く。

### シート3：決済突合

会計データの着金と決済サービスの入金を並べて比較する。

列：
| 列 | 出典 |
|---|---|
| 日付（会計データ） | 会計データの着金日 |
| 金額（会計データ） | 会計データの着金額 |
| 決済サービス | PayPal ／ Shopify ／ Square ／ Stripe |
| 日付（決済サービス） | 決済サービスの着金予定日 |
| 金額（決済サービス） | 決済サービスの入金額（手数料差引後） |
| 差異 | 会計データの金額 − 決済サービスの金額 |
| ステータス | RECONCILED ／ MISSING_IN_LEDGER ／ UNMATCHED_DEPOSIT ／ DATE_MISMATCH ／ UNRECONCILED_IN_LEDGER |

`UNRECONCILED_IN_LEDGER` は口座連携のケース：入金は明細として会計データにあるが、
まだ仕訳（売上との突合）が済んでいない（マネーフォワード・freee会計でよくある形）。

ステータス列を色分けする：
- RECONCILED → 緑の塗り
- DATE_MISMATCH または UNRECONCILED_IN_LEDGER → 黄の塗り
- MISSING_IN_LEDGER または UNMATCHED_DEPOSIT → 赤の塗り

### シート4：未処理一覧

チェックリストで開いたままのフラグ。列：
| 列 | 注意 |
|---|---|
| 区分 | 要対応（未仕訳・未処理・税区分なし）／ 証憑なし ／ 重複 ／ 決済突合のフラグ ／ 未払費用・前払費用 ／ 減価償却 |
| 日付 | 取引日 |
| 金額 | 円 |
| 取引先 | 名前 |
| 内容 | 何が問題で、何をすべきか |

未処理がなければ一行だけ：「未処理項目なし — 帳簿は整っています。」

### シート5：資金繰り概況

貸借対照表の試算表（マネーフォワードなら `getReportsTrialBalanceBalanceSheet`）から、
月末時点の残高。列は **項目** と **月末残高** と **前月末残高**：

| 行 | 出典 |
|---|---|
| 現預金 | 現金・預金科目の合計。口座ごとに補助科目で内訳 |
| 売掛金 | 残高と、補助科目があれば取引先別の上位 5件 |
| 買掛金・未払金 | 残高と、取引先別の上位 5件 |
| 借入金 | 短期・長期の残高。今月の返済額 |
| 預り金（源泉所得税・社会保険料・消費税の預り分） | 自社の資金ではないと脚注に書く |

### シート6：給与（給与計算データがあるときだけ）

ステップ5a の合計を、会計データの計上額の横に並べる。支給回ごとに一行、外注先への
報酬の行、合計の行。列：

| 列 | 出典 |
|---|---|
| 支給回 | 支払日。外注先の行は「外注・報酬」 |
| 総支給額 | 給与計算 CSV の総支給額 |
| 社会保険料（会社負担） | 給与計算 CSV の会社負担分（法定福利費） |
| 控除計（本人負担） | 社会保険料（本人負担）＋源泉所得税＋住民税 |
| 差引支給額 | 給与計算 CSV の差引支給額。外注先の行は源泉徴収後の支払額 |
| 会計データの計上額 | 当月の給与手当・役員報酬・法定福利費・外注費の仕訳額（日付で対応） |
| 差異 | 会計データ −（総支給額＋会社負担分）。1円でも差があればフラグ |

合計のみ。このシートに従業員の氏名や個人別の金額は載せない — 税理士に必要なのは
支給回数と月の合計だ。外注先の行があるときの脚注：「外注先への報酬は会計データの
外注費・支払報酬から。源泉徴収税額は預り金と突合。」

## PDF サマリー — 1ページ

レイアウト（上から下へ）：

```
[屋号・社名]                          月次締めパック — [YYYY年M月]
────────────────────────────────────────────────────────────
主要数値
売上高          XX,XXX,XXX円
粗利率          XX%
営業利益        X,XXX,XXX円
現預金残高      X,XXX,XXX円
給与            X,XXX,XXX円（X回）      [給与計算データがあるときだけ]

損益の要約
[ステップ7 の 400〜600字の説明文]

未処理項目
要対応 X件 · 証憑なし X件 · 未解決のフラグ X件
[すべて片付いていれば「未処理項目なし — 帳簿は整っています。」]

────────────────────────────────────────────────────────────
作成日 [YYYY年M月D日] · 月次締め が生成 — 中小企業向けビジネスアシスタント
```

用紙は A4。日本語フォント（BIZ UDPGothic または Noto Sans JP、なければ IPAexゴシック）を
埋め込む — フォントを埋め込まないと日本語が空白になる。ロゴは不要。余白は四辺とも
20mm 以上にして、印刷しても切れないようにする。金額は税込・税抜のどちらかを
「主要数値」の見出し脇に書く。

**PDF の生成：** スクリプトを実行できるなら Python の `xlsxwriter`（ブック）と `reportlab`
（PDF。日本語 CID フォントまたは TTF を登録する）を使う。あるいは Claude が内容を描画し、
Desktop コネクタの「PDF に印刷」で出力する。スクリプトが使えなければ、経営者が xlsx の
試算表シートから PDF を印刷してもよい。
