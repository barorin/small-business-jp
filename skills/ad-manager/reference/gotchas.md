# 落とし穴

経営者の広告予算を無駄にする失敗パターン。どれも現実には円の金額が付いていて、だからこのスキルは実行をこれほど固くゲートで守っている。

---

## 落とし穴: 円を言わずに割合の変更を実行する

**なぜ重要か:** 「30% 削る」は経営者が肌で感じられない数字だ。承認し、請求を見て、思い描いていなかったものに同意していたと気づく。実行するすべての変更は、変更前と変更後の月額を円の絶対額で述べる。

### 悪い例

```
リターゲティングの予算を 30% 減らすことを提案します。実行しますか？
```

### 良い例

```
変更:        「リターゲティング — 全訪問者」の日予算を減額
現在の費用:  月 120,000円（1 日 4,000円）
変更後:      月 84,000円（1 日 2,800円）
差引:        月 36,000円 の節約。リードは月およそ 4 件減る見込み。
取り消し:    可。すぐに
実行しますか？
```

割合は残してよい。ただし一人で歩かせない。

## 落とし穴: 一つの承認の後ろに複数の変更を束ねる

**なぜ重要か:** 「計画」に「はい」と言った経営者は、五つの別々のお金の判断に「はい」と言っていない。束ねることで、6万円の調整が、誰も同意した覚えのない 30万円の調整に変わる。

### 悪い例

```
計画はこうです：緊急修理を停止、春の点検を 1 日 11,000円 に増額、
配信地域を絞り、新しい広告を 2 本公開。よろしいですか？
```

### 良い例

四つの別々のブロック、四つの別々の「はい」、優先順。お金を節約するものから始める。承認が最も易しく、残りの原資になるからだ。

経営者が「全部まとめてやって」と言ったら、合計の円の影響額を一行で言い直し、その数字に対する「はい」を取る — 「129,000円 の節約と 61,000円 の追加、差引で月 68,000円 の節約、変更は四つです。よろしいですか？」

## 落とし穴: 一つの ROAS を事実として報告する

**なぜ重要か:** 経営者は「キャンペーンごとの正確な ROAS」を求める。正直な答えは、そんな数字は存在しない、だ — 媒体と CRM は別のものを測っていて、必ず食い違う。自信ありげな一つの数字は作り話で、経営者はその数字を金融機関や取引先に持っていく。

### 悪い例

```
Meta広告の ROAS: 4.2 倍
```

### 良い例

```
Meta広告 — 春の点検、広告費 276,000円（税抜）
  媒体の申告     コンバージョン 34 件
  CRM の記録     流入元がこの広告のリード 19 件、受注 6 件、受注額 141万円（税抜）
  CRM で見ると   5.1 倍、受注 1 件あたり 46,000円
  媒体の数え方   もっと良く見える。広告を見てクリックせず、後で電話した人まで
                 数えるから。
  舵を取る数字   CRM の数字。保守的で、実際に入金したお金に結びついている。
```

## 落とし穴: 税込と税抜を混ぜて ROAS を出す

**なぜ重要か:** 管理画面の広告費は多くの媒体で税抜、カード明細と請求書は税込、Shopify の売上は税込表示が既定だ。混ぜると ROAS が **1 割ずれる**。10% は「順調」と「注意」の境目をまたぐ幅で、月末の請求と合わない数字は信用を失う。

### 悪い例

```
ひかり珈琲焙煎所、EC 広告: 広告費 80,000円（管理画面）、売上 376,000円（Shopify）→ ROAS 4.7 倍
```

カード明細は 88,000円（税込）、376,000円 は税込売上。分子と分母の基準が違う。

### 良い例

```
基準を揃える: 広告費も売上も税抜。
  広告費   80,000円（税抜。カード明細は 88,000円 税込）
  EC 売上  341,800円（税抜。Shopify の表示は 376,000円 税込）
  ROAS     4.3 倍（税込同士で計算しても 4.3 倍。混ぜると 4.7 倍に見える）
```

どちらの基準かを毎回明記する。以後の比較はすべて同じ基準で行う。

## 落とし穴: 飽和しつつあるチャネルへの増額を勧める

**なぜ重要か:** 広告費が増えながら成果単価も上がっているなら、オーディエンスが尽きかけている。「効いているから増やそう」は有料広告で最も高くつく誤判断だ。

### 悪い例

```
春の点検はリード 34 件で、21 件から増えました。予算の倍増を提案します。
```

広告費は 135,000円 から 276,000円 に増え、リード 1 件あたりは 6,500円 から 8,100円 になった。

### 良い例

```
件数が増えたのは広告費が増えたからです。同じ期間にリード 1 件あたりは 6,500円 から
8,100円 になったので、追加の 1 円が買えるものは減っています。増やすなら 20% まで、
月 330,000円 にして、2 週間リード単価を見ます。9,000円 を下回ったままなら、
もう一段上げる。10,000円 を超えたらオーディエンスは尽きていて、新しい予算より
新しいクリエイティブが効きます。
```

## 落とし穴: 測れるように設定されていないキャンペーンを判定する

**なぜ重要か:** コンバージョンイベントなしで走るキャンペーンは多い。クリックで採点すれば、何もない上に自信ありげな評決が生まれ、予算がそれで動く。

### 悪い例

```
認知拡大: クリック 2,400 回、1 クリック 25円。最も成績の良いキャンペーン — 拡大を。
```

### 良い例

```
認知拡大: 広告費 60,000円、クリック 2,400 回、コンバージョン計測ゼロ。評決なし —
このキャンペーンは成果を報告するように設定されていないので、何を生んだかは
誰にも言えません。アカウントで最も安いクリックで、それはたいてい最も安い
注目という意味です。最初の提案はコンバージョンイベントの追加、その後 30 日。
```

## 落とし穴: コンバージョンが中間指標なのに受注として読む

**なぜ重要か:** LINE広告の「コンバージョン」は友だち追加、Google 広告の「通話」は電話番号のタップ、Meta の「リード」はフォーム送信であることが多い。どれも受注ではない。さらに、Googleビジネスプロフィールの電話タップは広告と無関係な MEO の成果で、広告の管理画面には出ないのに、経営者は「広告で電話が増えた」と感じる。

### 悪い例

```
LINE広告: コンバージョン 120 件、1 件 500円。受注単価 500円、最も効率の良いチャネル。
今月は電話が 40 件増えたので、検索広告が効いています。
```

### 良い例

```
LINE広告: 友だち追加 120 件、1 件 500円。友だち追加から購入への転換率が
分からないうちは、受注単価は出せません。Shopify の注文に LINE 経由のタグが
付いているものを数えてから言います。
電話 40 件のうち、広告の通話コンバージョンは 8 件。残り 32 件は
Googleビジネスプロフィールの電話タップで、広告費とは別の経路です。
```

成果の定義を先に書き、受注は CRM か Shopify で追い、経路の違う数字は別の行に置く。

## 落とし穴: 経営者が言っていない主張を広告に載せて公開する

**なぜ重要か:** 広告文は公開の約束で、経営者が法的責任を負う。創作した保証や価格は負債であって、表現の彩りではない。「No.1」「最安」「必ず」は景品表示法の優良誤認・有利誤認に当たり得る。

### 悪い例

```
見出し: 満足度 100% 保証 — さいたま市 No.1、必ず即日対応
```

保証も No.1 も「必ず」も、経営者が言ったことのどこにもない。

### 良い例

```
見出し: 点検9,800円（税込） ／ さいたま市・即日対応
```

経営者が実際に提供しているものだけ。より強い主張が効きそうなら、書いて期待するのではなく、それが事実かを聞く。

## 落とし穴: 2 週間を推移として読む（祝日週の前週比を含む）

**なぜ重要か:** 小さなアカウントは週ごとに大きく振れる。「広告が効かなくなった」という慌ての半分は通常の変動で、反応すると媒体の学習が壊れて結果が本当に悪くなる。ゴールデンウィーク、お盆、年末年始を含む週の前週比は、広告ではなく暦を読んでいる。

### 悪い例

```
リード単価が今週 8,100円 から 13,400円 に跳ねました。キャンペーンを停止します。
```

### 良い例

```
今週のリード単価は 13,400円 で、平均 8,100円 に対して高い — ただし GW の
週でリード 6 件の話で、このアカウントの通常の振れ幅の内側です。まだ何も
しません。連休明けの 3 週連続で 10,500円 を超えたら、それは本物で、動きます。
```

## 落とし穴: Yahoo!広告を忘れる

**なぜ重要か:** 日本の検索広告は Google 広告と Yahoo!広告の二本柱で、Yahoo! JAPAN 経由の検索は中高年の層で特に厚い。Google 広告の CSV だけ読んで「検索広告は把握した」と言えば、広告費の 3 割が見えていないまま予算の判断が動く。

### 悪い例

```
検索広告は Google 広告の 30 日分を読みました。合計 465,000円、リード 41 件です。
```

実際には Yahoo!広告に月 180,000円 出ていて、リード 15 件がそこから来ている。

### 良い例

最初に一度聞く。「検索広告は Google 広告のほかに Yahoo!広告も出していますか？」出しているなら両方の CSV を頼み、同じ列構造（キャンペーン、広告グループ、表示回数、クリック数、費用、コンバージョン）で別々の行にして読む。除外キーワードと広告文の変更は両方に入れる。

## 落とし穴: 代理店運用で管理画面が見えないまま判断する

**なぜ重要か:** 広告代理店に運用を任せている経営者は、管理画面の権限を持っていないことが多い。手元にあるのは代理店の月次レポート PDF だけで、「費用」に代理店手数料（媒体費の 20% が相場）が含まれているかどうか、コンバージョンの定義が何かは書かれていない。アカウントの所有者が代理店なら、契約を終えたときに履歴ごと失う。

### 悪い例

```
代理店のレポートでは費用 500,000円、コンバージョン 60 件です。1 件 8,300円 で順調です。
```

### 良い例

```
代理店のレポートは媒体費と手数料を分けていません。次の二つを頼んでください：
  1. 広告アカウントの閲覧権限（Google 広告は「閲覧のみ」、Yahoo!広告は
     「閲覧権限」、Meta はビジネスマネージャの「アナリスト」）
  2. 媒体の管理画面からの生の CSV（キャンペーン別、直近 30 日）
それまでは、手数料込みの 500,000円 と媒体費 417,000円 の両方で成果単価を
書きます。経営者の本当の費用は手数料込みのほうです。
```

アカウントの名義が代理店なら、そのことを一行でフラグする。

## 落とし穴: CSV の道筋を格下げとして扱う

**なぜ重要か:** ほとんどの経営者は広告のコネクタを持たない。エクスポートの道筋が言い訳のように聞こえたら、このスキルは使う人の大半にとって壊れている。

### 悪い例

```
広告アカウントにアクセスできないので、限定的なレビューしかできません。
```

### 良い例

```
このアカウントには広告のコネクタがないので、エクスポートから進めます —
分析はどちらでも同じです。広告の管理画面で、直近 30 日をキャンペーン別に
CSV でエクスポートしてください。そのファイルをいただければ、読みと提案する
変更を、それぞれの正確な操作手順つきでお返しします。
```
