# 変更プレイブック

やる価値のある変更と、それを実行する前に必要な承認ゲート。

このファイルの変更はどれも、経営者のお金を使う、止める、または向け直す。提案は無料。実行には毎回新しい「はい」が要る。**予算の変更、入札の変更、停止は必ず承認後。**

---

## 承認ブロック

毎回同じ形で、金額が先。経営者がスクロールせずに決められること。

```
変更:        <広告アカウントに表示されている名前そのままで、何を>
現在の費用:  <今の設定での月額（円）>
変更後:      <変更後の月額（円）>
差引:        <月額の増減（円）と、成果への予想される影響>
取り消し:    <可／不可、その方法>
実行しますか？
```

これを機能させるルール：

- **一つの変更、一つのブロック、一つの「はい」。** 束ねない。「計画」を承認した経営者は、五つの別々の支出を承認していない。
- **常に絶対額の円で。** 割合は円の横に添えてよいが、代わりにはならない。
- **日額ではなく月額。** 広告媒体は日予算で話し、経営者は月の請求で考える。換算し、意味のある差があれば両方示す。
- **失うものも書く。** キャンペーンを止めて月 14万円を節約すれば、月およそ 12 件の問い合わせも止まる。節約だけ聞いた経営者は 3 週間後に怒る。
- **「はい」には期限がある。** 会話が別の話題に移って戻ってきたら、もう一度聞く。
- **変更は一度に一つ、効果測定は 1〜2 週間。** 同じ週に二つ変えると、どちらが効いたか誰にも分からない。
- **祝日を含む週と大型連休（年末年始、GW、お盆）の前後は判断を保留する。** その週の数字は季節を映していて、広告を映していない。

## 予算の変更

**増やすとき。** 成果単価が安定または改善しており、フリークエンシーが 3 未満で、キャンペーンに 30 日以上の履歴がある。一度に増やすのは 20〜30% まで — それ以上の跳ね上げは媒体の学習をリセットし、良くなる前に結果が悪くなる。これを言う。言わなければ経営者は「なぜ倍にしないのか」と聞く。

**減らすとき。** 成果単価が直近平均より 40% 以上悪い、またはフリークエンシーが 4 を超えて CTR が落ちている。

**放っておくとき。** `diagnostics.md` の最低ラインを下回っている。ほとんどの週、正しい答えは「変更なし」だ。

```
変更:        「春の点検」の日予算を 9,000円 から 11,000円 に増額
現在の費用:  月 276,000円
変更後:      月 337,000円
差引:        月 +61,000円。今の 1 件 8,100円 なら月あたり約 7 件のリード増、
             効率が保てれば。たいてい少し落ちる。
取り消し:    可。すぐに
実行しますか？
```

**入札の変更も同じゲート。** 手動入札の上限クリック単価を上げる、目標コンバージョン単価（tCPA）を変える、自動入札に切り替える — どれも費用を動かす。目標値の変更は 20% 以内ずつ、学習期間の 1〜2 週間は次の変更をしない。

## 停止と再開

停止は最も安全な変更で、経営者が最も望むものでもある。それでもゲートは要る。リードの流れを止めるからだ。

成果を出している唯一のキャンペーンは、高く見えても、「これが唯一動いているものだ」と明言せずに止めることは絶対にない。

再開も無料ではない。再開したキャンペーンは学習期間に入り直し、数日は成績が落ちる。そう言う。

---

## ターゲティングの変更

予算の変更より危険度が高い。効果が見えにくく、実務上すぐには元に戻せない — オーディエンスのデータがリセットされるからだ。

やる価値があるもの：

- **地域を実際の対応エリアに絞る。** 対応エリアから車で 90 分の人に使う費用は純粋な無駄で、地域密着のアカウントで最も多い直せる漏れだ。
- **既存顧客を除外する。** 新規獲得のキャンペーンから。
- **疲弊したオーディエンスを広げる。** フリークエンシーが 4 を超えているとき — 燃え尽きたオーディエンスに新しいクリエイティブを当てるより、広いオーディエンスのほうが効く。
- **除外キーワードを追加する（検索広告）。** 検索語句レポートで、意図の合わない語句（「自分で」「やり方」「求人」「無料 図面」）に費用が流れていれば、除外に入れる。費用は変わらず、成果単価が下がる。Google 広告と Yahoo!広告の両方に入れる — 片方だけ直しても漏れは残る。

やる価値がないもの：狭い興味関心フィルタの重ね掛け。小さなオーディエンスは成果単価が高く、媒体自身のターゲティングのほうが手組みの層より効くことが多い。

```
変更:        「緊急修理」の配信地域を半径 40km から半径 20km に絞る
現在の費用:  月 129,000円、リード 7 件、1 件 18,400円
変更後:      同じ 129,000円 の予算を、狭い地域に使う
差引:        費用の変化なし。表示のおよそ 30% が対応エリア外だったので、
             1 件あたりの費用は下がる見込み。再学習の 1 週間は件数が
             落ちることがある。
取り消し:    可。ただしオーディエンスの学習はやり直し
実行しますか？
```

## 新しい広告を公開する（広告文の差し替え）

**このスキルで最も危険度の高い操作。** 公開され、経営者のブランドを背負い、公開した瞬間から費用が発生する。

ゲートの前に、掲載されるままの完全な広告を経営者に見せる：見出し、本文（説明文）、画像またはブリーフ、リンク先、行動喚起、オーディエンス、予算。

```
変更:        新しい広告「点検 — 率直な答え v2」を「春の点検」に公開
見出し:      <正確な文言>
本文:        <正確な文言>
画像:        <Canva の素材。Canva 未接続ならブリーフ>
リンク先:    <正確な URL>
現在の費用:  0円 — 新規広告
変更後:      既存の月 276,000円 のキャンペーン予算を分け合う
差引:        新しい費用なし。すでに走っている 2 本の広告と予算を分ける。
取り消し:    可。いつでも停止できる
実行しますか？
```

公開前に毎回、三つの確認：

1. **リンク先が動き、広告の約束どおりの場所に着く。** 壊れたリンクは予算全部を無に燃やす。
2. **広告文の主張がすべて事実。** 価格（税込）、保証、対応時間、資格・許認可。広告の内容に法的責任を負うのは経営者だ。景表法・薬機法の表現は `ad_copy.md`。
3. **経営者が言っていない主張はない。** 文言を強くするために、保証、割引、資格を創作することは絶対にない。

## CSV モードのとき

同じブロック、同じ円、同じ一つずつの規律。違いは最後の行だけ。「実行しますか？」の代わりに、クリックの手順になる。

```
この変更をするには:
  1. Google 広告の管理画面で「キャンペーン」
  2. 「春の点検」をクリック
  3. 「設定」から「予算」
  4. 1 日の平均予算を 9,000円 から 11,000円 に変更
  5. 保存
```

そのうえで、2 週間後にもう一度確認して次のエクスポートを読むことを提案する。
