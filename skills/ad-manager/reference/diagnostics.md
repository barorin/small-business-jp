# 診断

自分をだまさずに広告アカウントを読む方法。判定ライン、最低限のデータ量、各シグナルが本当に意味すること。

---

## 結論を出す前に必要な最低限のデータ

小さなアカウントの数字はぶれる。悪い広告助言の大半は、2 週間の振れを推移として読んだものだ。

| 判断 | 判断する前の最低ライン |
|---|---|
| キャンペーンを停止する | 30 日、または成果 50 件のどちらか早いほう |
| クリエイティブの勝者を決める | バリエーションごとに表示 1,000 回と成果 15 件 |
| 成果単価の推移を本物と呼ぶ | 3 週連続で同じ方向 |
| 新規キャンペーンを評価する | 最低 7 日 — 媒体には学習期間が要る |
| キャンペーン間で予算を移す | 両方が 30 日走っている |

これを下回るならそう言う。「2 週間でリード 9 件では、まだ判断できません。今のところの見え方と、何かを変える前に欲しいものをお伝えします。」

季節性は経営者が思うより効く。6 月の梅雨前と 7 月の猛暑のエアコン修理のアカウントは、10 月の同じアカウントとは別物だ（暖房なら 11 月）。年末年始、ゴールデンウィーク、お盆、3 月の決算期、6〜7 月と 12 月のボーナス月、EC ならお歳暮と年末商戦も同じ。データがあれば前年の同じ週と比べ、なければそう言う。**祝日を含む週の前週比は、季節を読んでいるのであって広告を読んでいるのではない。**

## 指標と、それが本当に教えてくれること

| 指標 | 答える問い | 誤解を招くところ |
|---|---|---|
| 広告費 | いくらかかったか | 単独では何も |
| 表示回数 | 何回表示されたか | 安くて価値のないオーディエンスが有利に見える |
| フリークエンシー（表示頻度） | 平均で一人が何回見たか | 月に 3〜4 回を超えるとオーディエンスは疲弊している |
| クリック率（CTR） | クリエイティブが注目を得ているか | 出来の悪いランディングページへの高い CTR は、何も生まない |
| クリック単価（CPC） | 注目の値段 | 質については何も言わない |
| 成果単価（CPA） | 実務で使う数字 | 成果の定義がキャンペーン間で同じときだけ意味がある |
| 受注 1 件あたりの広告費 | 本当に大事な数字 | CRM のデータが要る。ないことが多い |
| ROAS（広告費に対する売上） | 売上 ÷ 広告費 | 購入計測が信頼できる EC だけ。税込・税抜を揃える |
| 品質スコア（Yahoo!広告は品質インデックス） | 検索広告でキーワード・広告文・ランディングページが噛み合っているか | 目的ではなく手がかり。低ければ CPC が上がる |

計測があるなら成果単価を先頭に。CRM が出せるなら受注 1 件あたりの広告費を先頭に。表示回数を先頭にすることは絶対にない。

---

## ステータスの判定ライン

業界のベンチマークではなく、そのアカウント自身の直近 90 日平均に対して判定する。ネットで拾ったベンチマークは、この経営者の商圏を知らない。

| ステータス | ルール |
|---|---|
| 順調 | 成果単価が直近平均の 15% 以内かそれより良く、件数が横ばいか増加 |
| 注意 | 成果単価が 15〜40% 悪化、またはフリークエンシーが 3 超、または件数が 2 週連続で減少 |
| 問題 | 成果単価が 40% 超の悪化、または 14 日以上費用が出ているのに成果ゼロ |
| 評決なし | コンバージョン計測がない、または上の最低ラインを下回る |

**「評決なし」は正規のステータスだ。** 使う。何もない上に自信ありげな判断を立てるよりはるかに良い。

## 本当に意味を持つシグナル

**広告費が増えながら成果単価も上がっている。** オーディエンスが尽きかけている。予算を足しても、同じものが増えるのではなく悪い結果が増える。この分野で最も多い誤読だ。

**フリークエンシーが上がりながら CTR が落ちている。** クリエイティブの疲弊。同じ人が同じ広告を繰り返し見て、気づかなくなった。直すのは新しいクリエイティブであって、追加の予算ではない。

**CTR は強いのにコンバージョンが弱い。** 広告は仕事をしている。ランディングページかオファーがしていない。広告には触らない。

**CTR が落ちながら CPC が上がっている（検索広告）。** 品質スコアの低下か、競合の入札強化。検索語句レポートを先に見る — 「エアコン 自分で 掃除」のような **意図の合わない検索語句** に費用が流れていれば、原因は入札ではなくキーワードで、除外キーワードが直す。

**「予算による制限」で日中に予算が尽きている。** 夕方に電話する客に広告が出ていない。問題は予算額ではなく配分のこともある。予算を足す前に、どの時間帯・曜日に成果が出ているかを見る。

**一つのキャンペーンがアカウントを支えている。** 成果の何割が最上位のキャンペーンから来ているかを見る。70% を超えるならアカウントは脆い — ポリシー違反のフラグ一つ、オーディエンスの疲弊一つで全部が止まる。

**成果は横ばい、成果単価はゆっくり上昇。** たいていはオークションの圧力 — 競合の入札強化 — で、キャンペーンが壊れたのではない。チャネルが高くなっていると言っているのであって、それは価格の話であり、最適化の話ではない。

**数字は問題なさそうなのに電話が鳴らない。** 電話を信じる。リードフォームが壊れていないか、リードが誰も読まないメールボックスや LINE に届いていないか、計測が二重に数えていないかを確認する。

## 実例の読み

岡本設備工業、30 日間、Meta広告:

```
アカウント         広告費 465,000円、リード 41 件、1 件 11,300円
                   直近 90 日平均: 1 件 8,700円。30% 悪化。注意。

春の点検           276,000円、リード 34 件、1 件 8,100円。フリークエンシー 2.1。順調。
緊急修理           129,000円、リード  7 件、1 件 18,400円。フリークエンシー 4.6。問題。
                   フリークエンシーが言っているのは、このオーディエンスが
                   使い切られたことであって、オファーが間違っていることではない。
認知拡大            60,000円、リード  0 件。このキャンペーンにコンバージョンイベントがない。
                   評決なし — そもそも測れるように設定されていない。
```

一文で言えば：アカウントはいつもより 30% 悪く見えるが、そのほぼ全部は飽和した一つのキャンペーンと、誰も測っていないどこかへ毎月消えている 6万円だ。
