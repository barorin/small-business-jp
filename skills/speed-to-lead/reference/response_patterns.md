# 返信の型

区分ごとの返信構成と、スケジュール実行のダイジェスト書式。

共通の規則：まず相手の実際の質問に答える。返信の他の要素はすべて、「本物の人が読んで書いた」ことを示すことに比べれば二の次だ。

---

## 有望 — 標準の返信

四つの部分、300 字以内。営業時間内なら 1 時間以内、営業時間外なら翌営業日の朝一に出せる下書きにする。

```
<ボイスプロファイルに従った宛名・挨拶>

<相手の具体的な質問への答え。>

<対応できることを一行で確認。>

<カレンダーから引いた実際の候補を二つか三つ。>

<ボイスプロファイルに従った結び・署名>
```

**記入例：**

```
ローズウッド不動産 田中様

お問い合わせありがとうございます。岡本設備工業の岡本です。

はい、複数棟をまとめて一つの保守契約でお受けしており、6 棟は十分に
対応できる規模です。

費用については率直に申し上げると、機器の年式と点検口へのアクセスに
よりますが、この規模であれば棟ごとの個別契約より安くなるのが通常です。

現地の確認に、木曜の午前中か金曜の 13 時以降に伺えます。ご都合は
いかがでしょうか。

岡本設備工業 岡本 亮
```

見込み客は「複数棟を扱えるか」と「費用はいくらか」を聞いた。両方に答えている。候補日時は実際のものだ。全体で 230 字ほど。

---

## ホット — 同じ返信を、より速く、人を添えて

ホットな案件も返信構成は同じ。違うのは、人にすぐ知らせることと、次の一手がより直接的になることだ。

```
株式会社コーウィン商会 佐藤様

お問い合わせありがとうございます。岡本設備工業の岡本です。

延床 4,000㎡ のフロアで冷房が止まっているとのこと、当日対応が必要な
状況と承知しました。はい、対応できます。

本日午後に担当者を向かわせられます。住所と入館方法の確認のため、
数分以内にお電話いたします。

岡本設備工業 岡本 亮
```

続いて、経営者への引き継ぎメッセージ：

```
🔥 至急 — 株式会社コーウィン商会 佐藤様
冷房停止、延床 4,000㎡ の商業フロア、当日対応が必要。
管理物件 9 棟、複数棟契約につながる規模の見込み客。
数分以内にお電話すると返信済み（下書き）。
→ 今すぐ 048-000-0142 に電話。
```

引き継ぎメッセージは指示一つで終わる。要約でも、選択肢でもない。

## 不明 — 一つの質問

```
鈴木様

お問い合わせありがとうございます。岡本設備工業の岡本です。

喜んでお手伝いいたします。一点だけ先に確認させてください。
対象は事業用の建物でしょうか、それともご自宅でしょうか。
お伺いする担当者と費用の目安が変わってまいります。

岡本設備工業 岡本 亮
```

質問は一つ、仕分けを決めるものだけ。ここで四つも聞く質問票を送るとリードを失う。狙いの正反対だ。

---

## 対象外 — 正直に、そして紹介する

```
高橋様

お問い合わせありがとうございます。岡本設備工業の岡本です。

率直に申し上げますと、業務用厨房の冷凍冷蔵設備は当社の資格の範囲外
のため、お引き受けするとかえってご迷惑をおかけしてしまいます。

この分野は大宮冷凍設備さんが得意です。担当の寺田さんに、岡本からの
紹介とお伝えください。確かな方です。

岡本設備工業 岡本 亮
```

30 秒。狭い市場ではこれが戻ってくる。返信しなければ「誰も返事をくれなかった」という口コミになる。

紹介先がなくても返信する。「あいにく当社では承っておりません。お返事が遅れてはと思い、取り急ぎご連絡いたしました」のほうが沈黙よりよい。

## すべての返信に共通する規則

**300 字以内。** 相手は同じ席で競合にも問い合わせている。

**実際の日時だけ。** カレンダーを読む。埋まっていた枠を提示すると、速さが肝心な瞬間に二度目のやり取りが発生する。

**自動返信の断り書きを入れない。** 「これは自動返信です」は利点をすべて打ち消す。経営者として素直に書く。

**親しさを捏造しない。** 相手が実際に書いたことだけを参照する。誰も見ていないのに「御社のご活躍を拝見しております」と書くのは見抜かれる。

**相手の温度に合わせる。** 三語の問い合わせには短い返信。詳しい問い合わせには、より充実した答え。

**人が返信した下に重ねて返信しない。** まずスレッドを確認する。

**丁寧さは日本のビジネスメールの定型で。** 「お世話になっております」または「お問い合わせありがとうございます」で始め、社名と名前を名乗り、「よろしくお願いいたします」で結ぶ。相手が砕けた文体でも、初回の返信は丁寧語を崩さない。

## スケジュール実行のダイジェスト

```
## 問い合わせ — <期間>

<件数> 件 · 下書きまでの時間の中央値 <時間> · 最も古い下書きの待ち時間 <時間>

🔥 <n> 件、今すぐ対応
   - <名前、会社> — <一行> → <アクション>（<時刻> に <チャンネル> へ通知）

✎ <n> 件、下書き済み、承認待ち
   - <名前> — <相手の要望> · 下書きは <日程候補> を提案
   - <名前> — 不明、下書きは <質問> を確認
   - <名前> — 対象外、下書きは <紹介先> を紹介
   「有望なものを送って」または「全部送って」でこの一括分を承認。

⚑ <n> 件、保留、下書きなし
   - <名前> — <メッセージが求めたもの> → <登録済みの連絡手段> で確認
   - <差出人> — 売り込み（<自称の業種>） → 返信不要、必要なら迷惑メール扱い

✓ <n> 件、前回のダイジェスト以降に承認・送信済み
   - <名前> — <相手の要望> · <押さえた日程があれば>

<この実行で利用できなかったもの。>
```

**記入例：**

```
## 問い合わせ — 夜間、2026年7月26〜27日

7 件 · 下書きまでの時間の中央値 4 分 · 最も古い下書きの待ち時間 6 時間 40 分

🔥 1 件、今すぐ対応
   - 佐藤様、株式会社コーウィン商会 — 冷房停止、延床 4,000㎡、当日対応
     → 048-000-0142 に電話。23:52 に #sales-hot へ通知済み。まだ誰も
     引き取っていません。下書きでは朝一にお電話すると伝えています。

✎ 5 件、下書き済み、承認待ち
   - 田中様、ローズウッド不動産 — 6 棟の保守契約 · 木曜 9:00 を提案
   - 伊藤様、フェアモント商事 — 屋上機の更新見積 · 金曜 13:30 を提案
   - 渡辺様 — 年間保守の更新 · 木曜 15:00 を提案
   - 鈴木様 — 不明、下書きは事業用か住宅かを確認
   - 高橋様 — 対象外、下書きは大宮冷凍設備（寺田さん）を紹介
   「有望なものを送って」で上の 3 件を送信、または「全部送って」。

⚑ 1 件、保留、下書きなし
   - 「山本」を名乗る差出人 — 本日中に新しい口座へ着手金の振込を要求
     → 送信元ドメインが 1 文字違い。登録済みの電話番号で確認を。
   - 「〇〇 Web 制作」 — フォーム経由のホームページ制作の売り込み
     → 問い合わせではありません。返信不要。

✓ 0 件、前回のダイジェスト以降に承認・送信済み
```

**二つの時間を先頭に。** 下書きまで 4 分が、このスキルが夜間に機能している証拠。最も古い下書きの待ち時間は一括承認を促す数字で、返信時間を正直に保つのはこの数字だ。経営者が承認するまで、ダイジェストのどこにも「返信済み」「日程確定」とは書かない。

---

## ダイジェストがなってはいけないもの

仕分けのない、起きたことすべての一覧。経営者は最初の節を読んで行動する。ホットな案件が時系列の一覧に埋もれていたら、ダイジェストは唯一の仕事に失敗している。

ホットが常に先頭。それが唯一の記載のある節であっても。
