# 資格判定

経営者の基準を一度だけ保存し、実行のたびに再利用する。**何かを聞く前にこれを読む。** 実行のたびに経営者に基準を聞き直すと、速さのために作られたスキルが遅く感じられる。

---

## 聞き取りなしで基準を導く

基準がまだなければ、質問票から始めない。証拠から下書きを作り、経営者に直してもらう。

HubSpot の受注済み商談と、会計ソフト（freee会計、マネーフォワード クラウド会計、弥生会計 など）の取引先別の売上から引く：

- 受注した案件は実際にどのサービスか
- どんな規模・種類の顧客か
- どの地域（対応エリア）で、現実的にどこまで出向くか
- どのくらいの案件規模なら時間をかける価値があるか
- 失注・返金になった案件に共通するパターンは何か

次に下書きを見せ、一回だけ修正を頼む：

```
直近 40 件の受注を見ると、お受けしているのはこのあたりのようです：
  法人・3 棟以上、さいたま市から車で 1 時間圏内、概ね 30万円超の案件。
  個人宅の緊急対応も受けていますが、リピートはほとんどありません。

違っているところはありますか？
```

一つの質問、一つの答え、終わり。設定はそれだけだ。

**CRM も会計ソフトも接続されていなくても**、同じ形で動く。二つの道を、この順で：

1. 経営者に、二行ほどの大まかな感覚を聞く — 何を受けるか、誰から受けるか、どこまで出向くか、どのくらい小さいと割に合わないか。仕分けには二行で十分。質問票にしない。
2. 答えたくなければ、問い合わせそのものから基準を下書きする — 聞かれているサービス、場所、規模 — そして下書きを一度だけ確認する。

どちらも終わり方は同じ：書かれた下書き、一回の修正、そしてこのファイルに定着する。コネクタゼロは正式に対応している道であって、劣化した道ではない。

## 四つの区分

**ホット — 今すぐ人に回す**

条件に合い、急ぎの兆候がある。兆候：

- 明示的な時期：「今週中に」「至急」「エアコンが止まっている」
- 予算の明示、または承認済みの案件
- 空き状況や着工可能日を聞いている
- 既存顧客、または名前の挙がった紹介
- 案件規模が経営者の平均をはっきり上回る

**有望 — 返信して日程を押さえる**

条件に合い、時間の圧力はない。良い問い合わせの多くはここに入る。

**不明 — 一つの質問で返信する**

仕分けるための情報が足りない。返信では、仕分けを決める一つの質問 — 答えによって結果が変わる質問 — だけを聞く。質問票にしない。四つも聞かない。

もっとも多い決め手の質問：どのサービスか、どこか、いつか。

**対象外 — 正直に答え、他社を紹介する**

サービス違い、エリア外、小さすぎる、または経営者がやっていないこと。

**それでも返信する。** 狭い市場での 30 秒の誠実さは、その問い合わせの価値を上回る。合わないことを素直に言い、可能なら合う会社を名指しで紹介する。経営者には実際に紹介の流れが戻ってくるし、返信しなければ「誰も返事をくれなかった」という口コミが公開される。

**問い合わせに見せかけた売り込みは、どの区分にも入れない。** 自称「Web 制作会社」「SEO 業者」「助成金コンサル」からの営業メールは、フォーム経由で届いても問い合わせではない。下書きせず、ダイジェストの「保留」に列挙する。判断に迷えば（本文に具体的な依頼内容や現場の情報があるか）、「不明」ではなく保留にして経営者に見せる。

## 仕分けの規則

**振り分けでは、条件適合より緊急度が優先。** 条件がぎりぎりでも「空調が壊れて明日開店」と言っていればホットだ。条件適合は何を言うかを決め、緊急度は人がどれだけ早く見るかを決める。

**二つの区分で迷ったら、より手厚いほうを取る。** 有望をホットとして扱っても、経営者が一瞥する手間が増えるだけ。ホットを有望として扱うと、案件を失いかねない。

**対象外は条件の話であって、口調の話ではない。** 無礼な問い合わせでも、条件に合えば有望だ。振り分けて、経営者に判断してもらう。

**一つの問い合わせに、一つの区分。** 三つのことを聞かれたら、もっとも価値の高いもので仕分ける。

## 基準の書式

```
## 資格判定の基準 — <経営者または事業名>
作成:   <日付>  ·  根拠: 受注 <n> 件、顧客 <n> 社
更新:   <日付> — <何を変えたか>

受ける案件:
  サービス:   <一覧>
  顧客:       <種類と規模>
  対応エリア: <半径または地域>
  案件規模:   <下限があれば>
  時期・決裁: <着工希望時期の目安、決裁者と直接話せるか>
  相見積:     <相見積の案件を受けるか、その条件>

受けない案件:
  <一覧 — 受ける条件と同じくらい重要>

既定に加えるホットの兆候:
  <経営者固有 — 例: 「大宮駅周辺の再開発地区への言及」>

紹介先:
  <よくある対象外の依頼に対する会社名・担当者>
```

## 記入例

```
## 資格判定の基準 — 岡本設備工業
作成:   2026-07-27  ·  根拠: 受注 40 件、顧客 340 社
更新:   2026-07-27 — 初版

受ける案件:
  サービス:   業務用空調の設置、保守契約、緊急修理
  顧客:       不動産管理会社と商業ビル、3 棟以上の管理物件が望ましい
  対応エリア: さいたま市から車で 1 時間圏内（さいたま市・川口市・上尾市・春日部市）
  案件規模:   概ね 30万円超。それ未満は既存顧客のみ
  時期・決裁: 3 か月以内の着工希望が中心。管理会社の担当者が決裁者
  相見積:     受ける。ただし 3 社以上の相見積は現地調査後に判断

受けない案件:
  個人住宅の新築
  冷凍冷蔵（業務用厨房） — 資格なし
  群馬・栃木方面より遠方

既定に加えるホットの兆候:
  空調停止、冷暖房が効かない — 条件に関係なく常にホット
  複数棟の管理物件への言及

紹介先:
  冷凍冷蔵 → 大宮冷凍設備、担当は寺田さん
  住宅新築 → 小林ホーム設備
```

「受けない案件」と「紹介先」の節が仕事の大半をする。行き止まりの問い合わせを、評判を築く 30 秒の返信に変える。

## 基準を最新に保つ

経営者が仕分けを覆したら、理由を記録する：

```
更新:   2026-08-09 — 個人宅の緊急対応を対象外から有望に変更。
        岡本さん：「思ったより法人の紹介につながっている。」
```

二度起きた上書きは例外ではなく、基準の変更だ。経営者に毎週同じ仕分けを直させるのではなく、ファイルを更新する。
