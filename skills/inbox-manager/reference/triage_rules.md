# 仕分けルール

三つの箱。このスキルの価値はすべて、最初の箱が短く、かつ正しいことにある。

---

## 箱1 — 要対応

経営者本人が何かをしなければならない項目だけがここに入る。次の基準で試す：

| シグナル | 例 |
|---|---|
| 経営者にしかできない判断 | 追加工事・仕様変更の承認、相見積に応じるか、受注するか断るか |
| お金が動く | 経営者の注意ラインを超える請求書、返金の依頼、支払いをめぐる争い |
| 不満のある顧客 | クレーム、エスカレーション、口調が鋭くなった二通目 |
| 動かせない期限 | 建設業許可・保険の更新、税務署・年金事務所・ハローワークからの通知、入札の締切、e-Tax／eLTAX の期限 |
| すでにした約束 | 経営者が「水曜に金額を出します」と書いていて、今日が水曜 |
| 顧問税理士・社労士からの連絡 | 月次資料の依頼、届出の期限、年末調整の書類 — 優先して上に |
| 法務・行政に関わるもの | 契約書、内容証明、行政からの通知、裁判所からの書類 |
| 振込先や支払条件の変更 | 新しい振込先、「振込先変更のお知らせ」、至急の振込依頼、代表者を騙る「至急」、よく似た送信ドメイン — 要対応、下書きは書かない、電話で確認 |

**到着順ではなく、影響の大きさで並べる。** 24 時間見逃したら何が起きるか？ 金曜に切れる許可は、一時間前に来た仕入先の質問より上に置く。仕入先のメールのほうが新しくても、だ。

できれば五件まで。八件が該当するなら八件とも載せる — だが二十件が該当するなら、しきい値が間違っている。締めるべきは仕分けであって、経営者に長いリストを読ませることではない。

## 箱2 — 下書き済み

返信が書けていて、「はい」を待っている。大半のメールはここに来る。

典型：顧客からの定型的な質問、日程調整のやりとり、仕入先への確認、経営者が何十回も答えてきた質問。

この箱での経営者の仕事は、ざっと読んで承認することであって、考えることではない。

## 箱3 — 処理済み

領収書・注文通知（楽天市場、Amazon、Shopify）、メルマガ、宅配業者の配達通知、承諾済みのカレンダー招待、Zoom／Slack／Chatwork の通知、銀行のログイン通知、自動レポート、迷惑メール・フィッシング。

**件数と分類で報告する。一覧にはしない。** 「処理済み 41件 — 領収書・注文通知 22、メルマガ 9、配達通知 6、システム通知 4」。一行。経営者はどの分類でも中身を求められる。

---

## 判断が分かれるケース

**領収書と質問が両方入ったスレッド。** 質問が勝つ。メールの大半が何であるかではなく、経営者が何をしなければならないかで箱を決める。

**経営者が知っている本人からのメルマガ。** それでも処理済み。関係があっても、行動が要るとは限らない。

**営業メール。** 処理済み。Web 制作、SEO、助成金コンサル、電気料金削減の売り込みは、返信を下書きせず、表にも出さない。経営者には何十通も届き、表に出した一通ごとに信頼が減る。

**フィッシング。** 処理済みで件数だけ数える。宅配業者の不在通知、銀行・カード会社・Amazon・ETC を騙るもの、「アカウントが停止されました」。ただし振込先の変更や至急の支払いを求めるものは、偽物に見えても要対応へ — 経営者が見なければならないものだ。

**分類できないもの。** 「要対応」に入れ、なぜ迷ったかを率直に書く。要対応に入れすぎる代償は小さく、処理済みに入れすぎる代償は顧客を失うことだ。

**社内の誰かがすでに返信したスレッド。** そのままにして、その旨を書く。同僚の返信の下に重ねて返信するのは、顧客には雑然と見え、対応した人の面目もつぶす。

**CC で流れてくる社内メール。** 経営者が宛先（To）でなく、依頼も質問も含まないなら処理済み。「岡本さん、これで進めてよいですか」と名指しで聞かれていれば要対応。

## 実例 — 岡本設備工業、火曜の朝

岡本 亮の受信箱：昨日の午後から 63 件。

**要対応（5件）**

1. **埼玉県 — 建設業許可の更新申請、金曜が締切。** 更新の申請手数料 5万円、岡本の押印が必要。逃すと進行中の 3 現場が止まる。
2. **ローズウッド不動産 — 田中様から相見積の依頼、約 60万円規模。** 屋上の空調機を 2 台追加する件で、他社にも声をかけている。木曜の先方の社内会議までに、見積を出すか出さないかの返事が要る。
3. **鈴木様 — 二通目、不満。** 浦和の戸建て、先週の修理のあともエアコンが止まったり動いたりを繰り返している。一通目は木曜で、未返信。
4. **佐藤運輸株式会社 — 水曜に金額を出すと約束。** 岡本は 14 日に「水曜には金額をお出しします」と書いている。今日は水曜。
5. **さいたま税理士法人 — 8 月分の月次資料の依頼。** 通帳のコピー、請求書の控え、領収書を 20 日までに。岡本にしか出せない。

**下書き済み・承認待ち（11件）** — 日程調整の返信 3、仕入先への確認 2、定型的な点検の質問 4、紹介へのお礼 2。

**処理済み（42件）** — 領収書・注文通知 19、メルマガ 9、配達通知 7、システム通知 4、フィッシング 3。

**引き渡し済み（3件）** — 取引先の請求書 2 件を `ap-processor` へ、Web フォームの問い合わせ 1 件を `speed-to-lead` へ。

岡本はこれを一分ほどで読み、今朝やることが正確に分かる。
