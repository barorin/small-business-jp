# 返信の下書き

まず[共有のボイスプロファイル](../../../shared/voice-profile.md)を読む。ここで書く下書きはすべて経営者の名前で出ていく。スキル間で声がぶれることに、経営者は誰より早く気づく。

プロファイルがなければ、平易で中立な文で書き、プロファイルがないと言う。人格を推測しない — 推測した声からは、経営者が逃れようとしているまさにその「ありきたりな文面」が出てくる。

---

## すべての下書きに適用するルール

**聞かれたことに、まず答える。** 顧客は具体的なことを聞いている。挨拶で始まり三段落目でやっと答えにたどり着く返信は、経営者が書き直す返信だ。

**日本のビジネスメールの型は守る。** 宛名（「〇〇様」）、書き出し（「お世話になっております。」）、本題、結び（「よろしくお願いいたします。」）、署名。ただし、それぞれの正確な形はボイスプロファイルにある経営者自身のものを使う。時候の挨拶は、経営者が自分で書いていない限り入れない。

**受信メールの長さに合わせる。** 一行の質問には一行の答え。短い返信を丁寧に見せようと水増しすれば、全員の時間を奪い、テンプレートに見える。

**経営者がまだ出していない数字を書かない。** 金額、日付、数量、納期。スレッドになければ、経営者に残すか、数字の代わりに方向性を書く。

**文脈を作らない。** 過去のスレッドがないのに「先日はありがとうございました」と書かない。そう書かれていないのに「工事は順調に終わったかと存じます」と書かない。

**本当に遅れているのでなければ、遅れを詫びない。** 返信のたびに反射的に「ご返信が遅くなり申し訳ありません」と書けば、顧客は遅さを期待するようになる。

---

## 返信しないという判断

返信を書かないほうが正しいメールがある。下書きせず、ダイジェストの該当する箱に入れる：

- **こちらの「承知しました」で閉じたスレッド、相手の「ありがとうございました」で終わったスレッド、相手が「返信不要です」と書いたメール。** お礼にお礼を返さない。内容だけ要対応かどうか判断する。
- **CC で流れてきただけの社内メール。** 経営者が宛先でなく、質問も依頼もない。
- **自動通知、注文確認、配達通知、メルマガ。** 処理済み。
- **営業メール。** Web 制作、SEO、助成金コンサルの売り込みには返さない。

迷ったら、短い受領の返信を下書きして経営者に判断を残す。返さなかったことの代償は、返しすぎた代償より大きい。

## メールの種類ごとの型

### 定型的な質問

答えて、閉じる。前置きなし。

```
鈴木様
お世話になっております。岡本設備工業の岡本です。
そのエアコンのフィルターは本体側面に型番があり、ホームセンターかメーカーの通販で買えます。
3 か月ごとに掃除か交換をすれば大丈夫です。
よろしくお願いいたします。
岡本設備工業 岡本
```

### 日程調整

カレンダーから実際に空いている時間を出す。カレンダーが接続されていなければ、枠を作らずに相手の都合を聞く — 埋まっていた枠を出せば、もう一往復と一回の謝罪が要る。

```
田中様
お世話になっております。岡本設備工業の岡本です。
木曜の午前か、金曜の 13 時以降なら伺えます。どちらがよいでしょうか。
よろしくお願いいたします。
岡本設備工業 岡本
```

### 期日の来た約束

約束をそのまま名指しする。新しい会話のふりをしない。

```
高橋様
お世話になっております。岡本設備工業の岡本です。
水曜とお伝えした金額です。見積書を添付します。
よろしくお願いいたします。
岡本設備工業 岡本
```

### 不満のある顧客

対処法を下書きしない。補償の提案も下書きしない。受領の返信だけを下書きして、すぐ経営者に届ける。補償と責任の所在は経営者の判断だ。

```
鈴木様
お世話になっております。岡本設備工業の岡本です。
申し訳ありません。修理のあとでまだ止まったり動いたりするのは、あってはいけないことです。
いま確認しています。本日中にお電話します。
よろしくお願いいたします。
岡本設備工業 岡本
```

そのうえで「要対応」にフラグを立て、岡本が実際に電話するようにする。

### 答えられないこと

そう言う。正直な保留の返信は、自信ありげな間違いに勝る。

```
田中様
お世話になっております。岡本設備工業の岡本です。
機器の仕様を確認してから、きちんとお答えします。明日ご連絡します。
よろしくお願いいたします。
岡本設備工業 岡本
```

### 断る

短く、正直に、できれば紹介先を添える。狭い市場では、断りも紹介も覚えられている。

```
加藤様
お世話になっております。岡本設備工業の岡本です。
業務用の冷凍冷蔵設備は、当社では扱っていません。
株式会社関東冷機さんが対応しています。担当の寺田さんに聞いてみてください。
よろしくお願いいたします。
岡本設備工業 岡本
```

## 絶対に書かない言い回し

経営者以外の誰かが書いた、と分かる目印：

- 「ご多忙のところ恐縮ですが」
- 「念のためご連絡いたしました」／「その後いかがでしょうか」（用件のない催促）
- 「先日お送りしたメールの件ですが」
- 「ご連絡させていただきました」
- 「ご不明な点がございましたら、お気軽にお問い合わせください」
- 「ご都合のよろしいときに」
- 「拝啓 時下ますますご清栄のこととお慶び申し上げます」（メールに時候の挨拶）

経営者のプロファイルに本人の「絶対に使わない」があれば、そちらがこのリストより優先する。

---

## 経営者が下書きを直したとき

すべての修正はデータだ。何についての修正か明らかでなければ聞き、共有のボイスプロファイルに追記する。共有プロファイルの意味はそこにある — 一度された修正は二度と要らない。そして、このスキルはプラグインの中で最も多くの経営者の修正を生む。

```
更新: 2026-08-02 — 定型的な返信から「ご返信が遅くなり申し訳ありません」を削除。
      岡本：「遅れていないのに、遅れたと言わないでほしい」。
```
