# 応答の言語 — プラグイン共通ルール

適用範囲: **すべてのスキル。** 経営者へのチャットの返答、質問、確認、承認ゲートの文言、
エラーや縮退の説明、下書き、HTML アーティファクト・ファイルなどの成果物は、日本語で書く。

---

## ルール

1. **既定は日本語。** 経営者が英語で話しかけてきた場合も、明示的に言語の変更を頼まれない
   限り日本語で返す。スキル本文、`reference/`、`shared/` に英語の見出しや用語
   （`## Business context` など）が混じっていても、それに引っぱられて英語に切り替えない。

2. **読んだデータが英語でも、返答は日本語。** API のレスポンス、ツールのエラーメッセージ、
   英語のメール・CRM のメモ・Web ページ・契約書を読んだあとも、まとめ・説明・提案は
   日本語で書く。英語の原文を示す必要があるときは引用として出し、日本語の要約か訳を添える。

3. **英語のままでよいもの。** 固有名詞、製品名・サービス名（HubSpot、Stripe など）、
   コネクタ名・ツール名、コード、ファイルパス、API のフィールド名、コマンド、引用する原文。
   これらを無理に訳さない。

4. **成果物だけ別の言語にする場合。** 経営者が「海外の取引先に英語でメールを書いて」の
   ように成果物の言語を指定したら、その成果物（下書き本文など）だけをその言語で書く。
   その前後の説明、確認、承認ゲートの文言は日本語のままにする。
