# ボイスプロファイル

**プラグイン全体で共有。** 経営者の文体を実際のサンプルから一度だけ学び、経営者の名前で何かを書くすべてのスキルが再利用する。

**経営者の名前で書く前に、このファイルを読む。** 下にプロファイルがあればそれを使う。実行のたびに作り直すのは経営者の時間の無駄で、スキルごとに文体がぶれる原因になる。そのぶれに経営者はすぐ気づく。

このファイルを読むスキル：

| スキル | 書くもの |
|---|---|
| `outreach-composer` | 見込み客への営業メールとフォローアップの一連 |
| `speed-to-lead` | 問い合わせへの即時返信 |
| `invoice-chase` | 未入金の督促 |
| `review-reputation` | 口コミへの公開返信と休眠顧客向けの提案 |
| `inbox-manager` | メールの返信と下書き |
| `social-content-engine` | 投稿のキャプションと文面 |
| `ticket-deflector` | 顧客対応の返信 |
| `hiring-screener` | 応募者への返信と不採用通知 |
| `grant-rfp-writer` | 送付状と申請書の本文 |
| `inventory-planner` | 仕入先へのメールと発注書の送付文 |
| `lead-triage` | フォローアップの下書き |

**ここで一度直せば、すべてのスキルが直る。** 共有にしている意味はそこにある — 「念のためご連絡いたしました」を一度消した経営者は、どのスキルからも二度とそれを見ないべきだ。

SKILL.md からは相対パスで参照する：`../../shared/voice-profile.md`

## 作り方

**ソース。質の高い順：**

1. 経営者が顧客・見込み客に送ったメール — 15〜30 通。これに勝るものはない。
2. CRM に記録されたメールとメモ
3. Web サイト、メールマガジン、SNS の投稿
4. 本人が「これは良かった」と貼り付けてくれた 3 通

**何を取り出すか。** 真似できる程度に具体的に。「丁寧で親しみやすい」では役に立たない。それはこれまで書かれたあらゆるビジネスメールに当てはまる。

| 特徴 | 何を記録するか |
|---|---|
| 書き出し | 「お世話になっております」の有無と正確な形。「いつもお世話になっております」か「お世話になります」か、社名・名前を名乗るか |
| 宛名 | 「〇〇株式会社 〇〇様」か「〇〇様」だけか「〇〇さん」か。部署名・役職を付けるか |
| 結び | 正確な形。「よろしくお願いいたします」「何卒よろしくお願い申し上げます」「取り急ぎ」「以上」など |
| 署名 | フルネームか姓のみか、役職・電話番号・住所を付けるか、区切り線の有無 |
| 敬語の水準 | 丁寧語のみか、「伺う」「拝見」などの謙譲語まで使うか。「〜させていただく」の頻度 |
| 一文の長さ | 平均の文字数と、長く続くか短く切るか |
| 改行の癖 | 一文ごとに改行するか、段落でまとめるか、空行で話題を区切るか |
| 表記 | 漢字とひらがなの比率（「出来る／できる」「頂く／いただく」）、カタカナ語の頻度 |
| 「！」と絵文字 | 頻度。メール一通に一つ使う経営者もいれば、決して使わない経営者もいる |
| 本題の位置 | 用件が 2 行目に来るか 6 行目に来るか。時候の挨拶や前置きの長さ |
| 自社サービスの呼び方 | 自社の商品・サービスを本人の言葉で何と呼ぶか |
| 方言・業界用語 | 地域の言い回し、職人言葉、業界の符丁、その人らしい表現 |
| 絶対に使わない言い回し | どのサンプルにも出てこない語や構文 |

**絶対に使わない言い回しが最重要。** 経営者が一度も「ご多忙のところ恐縮ですが」「ご検討のほど何卒」「〜させていただきたく存じます」と書いていないなら、その言い回しは「誰か別の人が書いた」と一目で分かる目印になる。

## プロファイルの書式

```
## Voice profile — <経営者名>
作成:     <日付>  ·  ソース: 送信メール <n> 通、<その他のソース>
更新:     <日付> — <変更内容>

宛名:           <正確な形>
書き出し:       <正確な形>
結び:           <正確な形>
署名:           <正確な形>
敬語の水準:     <丁寧語のみ／謙譲語まで>
一文の長さ:     <短い／中くらい／長い>、平均 <n> 文字
改行:           <一文ごと／段落ごと／ほぼ改行なし>
表記:           <漢字多め／ひらがな多め、カタカナ語の頻度>
「！」と絵文字:  <使わない | まれ | 頻繁>
本題の位置:     <本題が入る行番号>
自社の呼び方:   <自社の商品・サービスを何と呼ぶか>
方言・業界用語: <特徴的な言い回し>

よく使う言い回し:
  <実際に使っている言い回しを、そのまま>

絶対に使わない:
  <どのサンプルにも出てこない言い回し>

サンプル（原文のまま）:
  <本人の実際の短いメールを一通、基準として>
```

## 記入例

```
## Voice profile — 岡本 亮（岡本設備工業）
作成:     2026-07-27  ·  ソース: 送信メール 22 通、Web サイト
更新:     2026-07-27 — 初回作成

宛名:           「田中様」— 既存客には社名を付けず、姓＋様。初めての相手だけ「〇〇株式会社 〇〇様」
書き出し:       「お世話になっております。岡本設備工業の岡本です。」— 毎回この一文。時候の挨拶はなし
結び:           「よろしくお願いいたします。」— 「何卒」「ご査収」は使わない
署名:           「岡本設備工業 岡本」— 姓のみ、役職なし、電話番号は付けない
敬語の水準:     丁寧語が中心。「伺う」「拝見」程度の謙譲語は使うが「〜させていただく」は避ける
一文の長さ:     短い。平均 28 文字。体言止めも多い
改行:           一文ごとに改行。空行で話題を区切る
表記:           ひらがな多め（「出来る」ではなく「できる」、「頂く」ではなく「いただく」）。カタカナ語は少なく、機器の型番以外はほぼ使わない
「！」と絵文字:  「！」は 22 通中 2 回、いずれも工事完了の報告。絵文字はゼロ
本題の位置:     2 行目か 3 行目。前置きなしで本題に入る
自社の呼び方:   「工事」「点検」「保守契約」— 「ソリューション」「サービスプラン」とは言わない
方言・業界用語: 「現場」「段取り」「一式」「様子を見る」。方言はほぼ出ない

よく使う言い回し:
  「結論から言いますと、」
  「伺って現物を見ます」
  「ご都合のよい日をお知らせください」
  「急ぎではありません」

絶対に使わない:
  「ご多忙のところ恐縮ですが」 · 「ご検討のほど」 · 「〜させていただきます」 · 「ご査収ください」
  「ご提案させていただきたく」 · 「ソリューション」 · 「シナジー」 · 「取り急ぎ」
  60 文字を超える一文

サンプル（原文のまま）:
  田中様

  お世話になっております。岡本設備工業の岡本です。
  結論から言いますと、6棟すべてを1本の保守契約にまとめられます。
  今の2本より安くなります。
  木曜に伺って内容をご説明できます。ご都合のよい日をお知らせください。

  よろしくお願いいたします。
  岡本設備工業 岡本
```

このプロファイルを読めば、誰でも岡本として書ける。それが基準だ。

## 最新に保つ

**経営者の修正はすべてシグナルだ。** 下書きが直されたら、何を変えたのかを聞いて記録する。一度された修正を、二度させてはならない。

「更新」は上書きせず追記し、理由が見えるようにしておく：

```
更新: 2026-08-14 — フォローアップから「念のためご連絡いたしました」を削除。岡本：
      「催促しているみたいで嫌だ」。毎回、連絡する具体的な理由を書く形に置き換えた。
```

## サンプルがないとき

そう率直に伝え、本人が「これは良かった」と思うメールを 3 通もらう。推測しない。

推測した文体からは、経営者がここに来た理由そのものである「ありきたりな文面」がそのまま出てくる。最初の下書きこそ、このスキルへの信頼が決まる場面だ。
